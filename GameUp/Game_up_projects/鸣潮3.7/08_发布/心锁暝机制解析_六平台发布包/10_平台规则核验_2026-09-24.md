# 六平台发布规则核验（2026-09-24）

> 平台规则会持续调整。本文件把“官方公开硬规则”和“当前前端/创作者实测”分开写。遇到账号级权限差异，以发布当天账号页面的实时校验为最终准绳。

## 1. Bilibili

### 发布时需要准备/填写

- 视频文件
- 封面
- 标题
- 稿件类型：自制 / 转载
- 分区
- 标签
- 简介
- 粉丝动态
- 合集/系列（可选）
- 话题/活动（可选）
- 评论、弹幕、二创/转载等权限
- 可见范围 / 定时发布
- CC 字幕（发布后字幕管理）
- 分段章节（公开后个性化配置）
- 创作者声明 / 商业声明（按页面实际显示）

### 当前可验证限制

【当前投稿接口/社区维护文档】
- 标题：最多 **80 字**
- 标签：最多 **10 个**
- 简介：最多 **2000 字**
- 当前 Web 投稿封面使用 **4:3** 入口；不同前台展示位仍可能裁切，因此保留 16:9 安全区版本。

【官方功能确认】
- B站官方客服仍提供「分段章节操作指南」与「投票弹幕操作指南」。
- 官方公开静态页面未找到 2026 年统一的章节最大数量说明。本包按用户要求控制为 **10 章**。

来源：
- Bilibili 客服《投票弹幕操作指南》：https://www.bilibili.com/video/BV1rP41137E6/
- Bilibili 客服视频功能教程合集（含分段章节）
- 当前投稿接口社区维护文档：https://github.com/BACNext/bilibili-API-collect-backup/blob/master/docs/creativecenter/upload.md
- 封面 4:3 变更历史参考：https://www.bilibili.com/read/cv11029957/

## 2. YouTube

### 发布时需要准备/填写

- Video
- Thumbnail
- Title
- Description
- Playlist（可选但建议）
- Audience（Made for kids / Not made for kids）
- Age restriction
- Paid promotion / branded content
- Altered / synthetic content
- Automatic chapters / manual chapters
- Tags
- Video language
- Caption certification
- Recording date / location（可选）
- License / distribution
- Shorts remixing
- Category / Game title
- Comments
- Visibility / Schedule
- Subtitles

### 官方硬限制

- Title：最多 **100 characters**
- Description：最多 **5,000 characters**
- 手动章节：
  - 第一条必须从 **00:00** 开始
  - 至少 **3 个**时间戳
  - 按升序排列
  - 每章至少 **10 秒**
- 手动章节会覆盖自动章节。

来源：
- YouTube Help - Upload videos：https://support.google.com/youtube/answer/57407
- YouTube Help - Video chapters：https://support.google.com/youtube/answer/9884579

## 3. 抖音

### 发布时常见字段

- 视频
- 作品标题 / 描述
- 封面
- 话题
- @用户
- 地点
- 合集
- POI / 小程序 / 游戏等锚点（账号/路径支持时）
- 相关热点（可选）
- 原创 / 内容声明
- 评论、下载/保存等权限
- 可见范围
- 定时发布
- 音乐
- AIGC / AI 相关声明（若当前页面提供）

### 官方开放平台可验证限制

- 推荐常用格式：MP4 / WebM
- 视频文件：不超过 **4GB**
- 时长：**15 分钟以内**
- 推荐 720p 及以上
- 官方明确提醒不合规品牌 Logo / 水印可能影响审核与推荐。

手动创作者中心与 OpenAPI 并非完全同一条发布链路。当前创作者页面上的标题/正文计数与账号功能可能变化，所以本包把标题压在 30 字以内、正文远低于 1000 字，但不把某个前端计数冒充所有路径统一的官方硬限制。

来源：

## 4. TikTok

### 发布时需要/常见字段

- Video
- Caption
- Cover / cover frame
- Privacy
- Comments
- Duet
- Stitch
- Tag people（可选）
- Location（可选）
- Link（账号支持时）
- Branded content
- AI-generated content
- Copyright check
- Schedule（Studio/账号支持时）

### 官方硬限制 / API 字段

TikTok Content Posting API（2026-08-24 更新）：
- Caption / `title`：最多 **2200 UTF-16 runes**
- Privacy：按账号实时可用选项
- Comments / Duet / Stitch：独立开关
- 支持 `video_cover_timestamp_ms`
- 支持 branded content 标志
- 支持 `is_aigc` AI-generated content 标志
- **最大视频时长不是所有账号固定值**：应读取账号的 `max_video_post_duration_sec`

### 当前前端可观察校验（非腾讯公开静态规范）

近期视频号助手前端实现可观察到：
- short_title：**6–16 字**
- 可选 mpTitle：**≤30 字**
- description：**≤1000 字**，topics 会占描述额度
- 常见视频权限：3 秒–2 小时、≤4GB
- 常见建议：MP4 / H.264、720p+；账号和发布路径仍可能有差异

由于腾讯没有公开一份稳定静态网页列全这些创作者后台校验，本包将它们标为“当前前端观察值”，正式发布以账号页实时提示为准。
