# 六平台发布规则核验（2026-09-24）

本文件区分三类信息：
- 【官方确认】：平台官方帮助 / 开放平台文档明确写出。
- 【当前接口/前端确认】：平台当前投稿接口、前端校验或开放 API 可观察到。
- 【创作者实测】：官方未公开静态数字时，用近期实际界面/创作者资料补足；发布时仍以账号页面实时提示为准。

## Bilibili

【当前接口确认】
- 标题：最多 80 字。
- 标签：最多 10 个。
- 简介：最多 2000 字。
- 投稿核心字段包括：视频、封面、标题、原创/转载类型、分区、标签、简介。
- 当前接口还包含：粉丝动态、是否允许二创/转载、评论/弹幕开关、可见性、话题、创作者声明等。
- 投稿接口已有独立 4:3 封面字段。
- 来源：
  - https://github.com/BACNext/bilibili-API-collect-backup/blob/master/docs/creativecenter/upload.md
  - https://gitea.s1f.ren/shiran/bilibili-API-collect/src/commit/97289e1c45bf291d337f4827aff5d61be9074000/docs/creativecenter/upload.md

【官方确认】
- Bilibili 有「分段章节」与「投票弹幕」功能；官方客服/创作教程存在对应操作指南。
- 分段章节通常在稿件公开后，从内容管理/个性化配置继续设置。
- 投票弹幕官方教程：
  https://www.bilibili.com/video/av302830088/

【创作者实测】
- 2025 必剪端的章节功能有“最多 5 段、每段不少于 5 秒”的实测限制；Web 个性化配置未检索到 2026 官方公开静态页给出统一最大段数。因此本包同时准备 10 段详细版与 5 段兼容版。
- 实测来源：
  https://www.bilibili.com/video/BV1NRu3zmERr/

【字幕】
- B站 CC 字幕可在稿件发布后进入字幕管理上传字幕文件。2025 创作者教程仍显示该流程。
- https://www.bilibili.com/opus/1137255263518064660

## YouTube

【官方确认】
- Title：最多 100 characters。
- Description：最多 5,000 characters。
- Tags：API 属性总长最多 500 characters，逗号和带空格标签的引号计入。
- Thumbnail：YouTube API 的 maxres 为 1280×720；16:9 为标准封面方向。
- 上传页还包括：Playlist、Audience、Age restriction、Branded content、Altered content、Automatic chapters、Tags、Language、License、Category、Comments、Visibility/Schedule 等。
- 章节：第一条必须 00:00；至少 3 个；每章至少 10 秒。手动章节点会覆盖自动章节。
- 来源：
  - https://support.google.com/youtube/answer/57407
  - https://support.google.com/youtube/answer/9884579?hl=zh-Hant
  - https://developers.google.com/youtube/v3/docs/videos

## TikTok

【官方确认】
- Direct Post API 的 caption/title 最大 2200（官方文档按 UTF-16 计数）。
- TikTok Studio 网页上传：MP4/WebM，720×1280 或更高，最长 30 分钟，文件小于 10GB。
- 上传后可设置：Caption、Cover、Who can watch、Duet/Stitch/贴纸/Story reuse、Comments、Copyright check。
- App 发布页还可见：hashtags、tag people、location、link、privacy。
- 来源：
  - https://developers.tiktok.com/docs/en/content-posting-api-reference-direct-post
  - https://support.tiktok.com/en/using-tiktok/creating-videos/creator-tools-on-tiktok
  - https://support.tiktok.com/en/using-tiktok/creating-videos/stitch

## 抖音

【官方确认】
- 内容发布方案：常用格式，推荐 MP4/WebM；视频总大小不超过 4GB；时长 15 分钟以内。
- 发布能力支持话题、@、POI/小程序/游戏等锚点能力，具体取决于发布路径和账号权限。
- 小程序发布视频的 TitleConfig 文档给出标题 60 字限制；另一套 video.create 后端接口对 title 的错误校验上限为 1000。手动 App 发布页可能与 API 路径不同，因此本包标题控制在 60 字以内，保证兼容。
- 来源：
  - https://open.douyin.com/platform/resource/docs/ability/content-management/douyin-publish-solution/
  - https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/open-interface/video-capacity/upload-douyin-video
  - https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create

## 小红书

【官方确认】
- 官方分享 SDK 明确：视频笔记标题可选、正文可选、视频必传 1 个、封面可选 0–1 张。
- 来源：
  - https://agora.xiaohongshu.com/doc/harmony
  - https://agora.xiaohongshu.com/doc/android

【当前 UI / 创作者资料】
- 当前发布界面普遍按标题不超过 20 字、正文不超过 1000 字使用；官方分享 SDK 静态页没有公开这两个手动发布页硬上限，因此本包严格控制在 20 / 1000 以内，不把第三方数字冒充成官方规则。
- 正片时长 06:36 需要账号实测：近期资料仍显示普通账号与长视频/视频号账号存在 5 分钟 / 15 分钟权限差异。
- 参考：
  - https://www.zishutongji.com/xiaohongshu
  - https://www.php.cn/faq/2194532.html

## 微信视频号

【当前前端确认，非官方公开静态文档】
- 视频号助手当前前端校验的常见字段：
  - short_title：6–16 字
  - 可选 mpTitle：≤30 字
  - description：≤1000 字；topics 会占用描述额度
  - 默认账号视频：3 秒–2 小时，≤4GB
  - MP4 / H.264，宽高比约 1:3–3:1，建议 720p+
  - 还包含：封面、topics、location、schedule、visibility、music 等字段
- 这些来自对视频号助手前端的当前解析，不是腾讯公开静态规范；发布时以你的账号页面实时校验为准。
- 参考：
  https://github.com/liuxuehao/weixinshipinhao_publisher
