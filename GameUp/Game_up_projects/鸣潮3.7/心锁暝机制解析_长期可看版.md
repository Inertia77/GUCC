# 《心+锁暝机制解析》

锁暝开完共鸣解放，协奏已经触发，前台也换人了，但她没有消失。

下一名角色已经开始自己的动作，锁暝还在场上继续攻击。

心和锁暝的联动，基本就在这个瞬间发生。

先把心自己的循环理清。

心常态上场以后，会靠机巧和环状攻击推进共鸣回路。资源达到条件后，就能获得玄方核；消耗玄方核以后，进入岁主状态。

进岁主以后，战斗节奏会直接换一档。大型机巧开始参与攻击，心继续推进第二段资源；等第二段满足条件，再接特殊技能和强化共鸣解放，把这一轮推到最高点。

她这一轮可以理解得很简单：

前半段把自己送进岁主，后半段再把岁主推到最终爆发。

这两个阶段都属于心自己的循环。

排轴时最先要看的，就是启动需要多少时间。前半段拖得越久，队友给她的增益就越容易还没进岁主先掉了；进了岁主以后，她自己还要继续做动作，整轮站场也不只集中在最后那一下爆发。

到了队伍层面，心还有两种共鸣模态：同奏和电磁效应。

先说同奏。

心进入同奏以后，队友的入场会被纳入这套机制。

放在鸣潮里，这件事分量很重。鸣潮本来就靠变奏、延奏、协奏和角色交换去组织一整轮队伍循环，谁先上、谁后上、什么时候切，都会直接影响排轴。

同奏又往这套交换逻辑里加了一层。

玩同奏心，除了要看她自己什么时候完成动作，还要看队友会在她这一轮的哪个位置进来。

队友进得早，心手上的动作有没有做完？

进来以后，上一名角色还有没有东西留在场上？

协奏触发以后，前后两个角色还能不能继续同时工作？

入场时点一变，整轮动作顺序也会跟着变。

电磁效应这条路线要直白很多。

敌人身上的电磁效应可以继续积累，心能够围绕已经积累的电磁效应进行集中结算。

它的组队需求也很直接：谁能稳定把电磁效应建立起来。

再来看锁暝。

锁暝自己也得上场做事。

她的常态攻击和共鸣技能都会推进共鸣回路，再通过强化动作把这一轮往后推。她不是切出来按一下技能、马上退场就完成工作的角色。

她跟整支队伍接起来的节点，在共鸣解放。

共鸣解放之后，锁暝进入同奏。随后切换角色，协奏效果触发，下一名角色登场。

但锁暝这一轮没有立刻结束。

她还能继续留在战场上，跟当前前台一起攻击。

很多角色把前台交出去以后，自己的主要站场动作也就告一段落了。锁暝把位置让出去以后，还有一段有效战斗时间留在场上。

留场持续时间、攻击频率，以及这段攻击最后能占多少份量，都会直接影响她的强度和排轴。

把两个人放进一条最简单的轴里，就很清楚了。

锁暝先在前台把自己的循环推到共鸣解放，进入同奏；随后切心，协奏触发，心接进来开始常态启动，去推自己进入岁主之前的那一段资源。

这个时候锁暝还没有退场，她的攻击仍然在继续。

心已经开始干自己的事，锁暝上一轮的工作还没完全收尾。

两个人的有效战斗时间，就在这里发生了重叠。

这段重叠最后能有多大收益，要看锁暝留场的持续时间和攻击质量；但从操作上看，排轴已经会多一个新的考虑方式。

以前经常问的是：

这个角色什么时候切掉最省时间。

到了这种机制里，还可以再问一句：

切掉以后，他还有多少工作能留在场上继续做？

放到心锁身上，这个问题特别直观。

心的同奏会处理队友什么时候进场；锁暝则能在进入同奏后把前台交出去，切换触发协奏，同时继续留在场上攻击。

这也是她们放在一起很顺的原因。

至于是不是绑定，光靠“搭得顺”还不够。

两个人的机制确实高度适配，但心自己的循环可以独立成立，而且她自己还留着电磁效应这条成队路线。

更准确的关系，就是机制高度适配的同奏搭档。

落实到抽卡，思路也不用搞得太复杂。

想进3.7这套新体系，可以先把心当成体系入口来看。两个人在队伍里的职责不同，直接比谁更强没什么意义。心自己有完整循环，同时摆出了同奏和电磁效应两个成队出口，资源规划自然可以从她开始。

锁暝和心搭配时，她的体系价值主要集中在同奏这一侧。前面那套协奏后继续留场的机制，正好能和心接起来。想把同奏这条路线玩得更完整，锁暝的价值自然会明显上升。

只想拿心的话，不需要默认把锁暝那份预算一起锁死；反过来，锁暝也不能简单理解成“没心就没用”。她和心发生联动时，最有辨识度的体系价值，确实集中在同奏、协奏和留场这一块。不准备玩同奏，抽她的时候就要更谨慎一点。

预算只够一个，也没必要给两个人硬排强度。提前留资源的话，可以先从心这个体系入口开始；锁暝更适合在明确自己要走同奏路线时再纳入预算。

已经有几套成熟队伍、只看账号强度的玩家，更不用因为机制新就急着锁资源。

机制新，不代表一定比成熟队伍强。完整循环要多久、实际伤害多少、锁暝留场能多贡献多少、整套同奏队最后能不能稳定跑顺，这些才决定她们对成熟账号有没有实质提升。

再往以后看，心的扩展空间来自两种共鸣模态，同奏和电磁都有继续补队友的可能；锁暝则更看后面的同奏体系，还需不需要这种“协奏以后继续留场”的能力。

这是机制上的扩展空间，不等于能直接给她们贷款保值。

回到开头那一幕。

锁暝已经把前台交出去了，人还在场上；心接进来，自己的启动已经开始。

锁暝这一轮还没结束，心的下一轮已经开始了。
