01素材与元素

1. 背景图

背景默认按 cover 智能铺满。开启背景拖动后，可拖动背景；滚轮可缩放。每个比例的背景位置单独保存。

2. 图片元素

第一张横向截图会自动铺满画布作为底图；竖向立绘、Logo 等保持为可移动主体。设计装饰始终压在截图上，文字位于最上层。

3. 文字元素

文字也可以添加多个：主标题、副标题、角标、吐槽、期数都分开做，后期改起来不挠头。

4. 自动设计模板

“无模板”只关闭设计叠层，不改变现有排版；其余模板会把素材重新编排到四个比例。模板不会删除素材，但会覆盖各比例的位置、大小和文字样式。

5. 元素列表

16:9 / 1920×1080 拖动元素移动，右下角缩放，顶部黄点旋转

既可以选择“无模板”完全自由排版，也可以先套模板再微调。建议以 16:9 检查横版主构图，最后检查 3:4 / 9:16 的人物与标题安全区。

02属性与导出

选中元素属性

当前没有选中元素。点击画布里的图片/文字，或点击左侧元素列表。

28 个文字设计模板

导出设置

默认尝试打包 ZIP；如果 CDN 没加载成功，会自动退回为逐张下载。外链图片若不允许跨域，浏览器可能禁止导出，请改用本地上传。

AI 封面 Prompt 工作区

适合“上传参考图 → 把 Prompt 发给图片 AI → 直接取得四张封面”的流程。十种风格分别成稿，Prompt 会明确要求 16:9、4:3、3:4、9:16 独立重构，不允许只裁同一张图。

使用时把参考图片和复制出的 Prompt 一起发给 AI。若模型不擅长中文，建议选择“无字底图”，再回到本生成器叠字。
