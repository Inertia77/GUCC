# GUCC Studio Changelog

## 5.0.0

- 将页面升级为明确的 `AI 区 / 工作区` 双区结构，模式可切换并记住上次选择。
- 工作区阶段导航移除重复的 AI 入口与字段角色图例；完整快捷操作移至桌面左侧窄栏，移动端继续使用底部操作面板。
- 修复结构区章节导航只显示首节的问题，改为逐项安全渲染；悬浮条移到页面根层级并真正固定在浏览器视口右下角，浏览整个 03 结构区时显示，离开后隐藏。
- AI 区按策划、结构与文案、发布与扩散、收口与交接四阶段重组 Prompt 模板。
- 工作区改为 JSON / Markdown 导入优先，新增文件拖放入口与导入后项目概览。
- 保留全部手动编辑、浏览器自动保存、WIP / DONE Markdown 与 JSON 导出能力。
- 继续兼容 v4 JSON、带隐藏数据标记的 Markdown 与无标记 Markdown 的尽力解析。
- 视觉统一到 GUCC v5 深色玻璃系统，移除浅色表单在主视觉中的支配效果，并重做移动端布局。

## 4.2.0

- 将 AI 区升级为可脱离模板使用的独立创作工作台，新增独立 HTML 策划稿、Workspace JSON 与 Workspace Markdown 收口 Prompt。
- 新增 AI 汇总结果粘贴导入，可直接接收 JSON 或按固定骨架生成的 Markdown；JSON 结构导入支持 `sectionsJson` 数组。
- 将默认 Prompt 从“证据编号驱动”调整为轻量创作协作：只核对会影响结论的关键事实，不再要求所有观点、章节与稿件段落编号。
- 重写中文与多语言发布包 Prompt：所有视频平台发布同一个完整视频，只分别适配标题、简介、话题、标签与置顶评论，不再生成抖音/视频号/TikTok 切片。
- 为 B站、抖音、小红书视频、微信视频号、YouTube 与 TikTok 增加分平台保守字数目标、元数据结构与反误导、反诱导、反导流安全检查。
- 后期扩散默认仅生成图文、社交帖和社区内容，不再默认制作视频切片。

## 4.1.0

- 将创作链路明确为 `06 正式发布 → 07 后期扩散 → 08 复盘 → 09 规则`。
- 正式发布新增主平台视频链接记录；后期扩散新增目标、复用素材、AI 扩散包和执行结果字段。
- 新增后期扩散 Prompt，并让复盘区分主视频自然表现与扩散增量。
- 状态与完成度新增“扩散中 / 待复盘 / 后期扩散完成”，旧项目的 `8-已归档` 会自动迁移为 `10-已归档`，并视为已完成旧流程对应的扩散步骤。
- Markdown / JSON 导入导出升级到 schema 2，同时保留旧版 07 进度、08 结项反思的无标记 Markdown 兼容读取。
- 加固 Markdown 导出：保留嵌套列表缩进和围栏代码原文，修复富文本表格、分隔线、链接与表格特殊字符造成的格式破坏。

## 4.0.3

- 更名为 GUCC WorkSpace，进入 4.0.x 版本线。
- Markdown 与 JSON 写入工作台版本和导出阶段。
- Markdown 内嵌完整项目数据，可作为可读存档再次导入。
- 支持旧版 INERTIA Project Forge 数据标记和浏览器草稿迁移。
- 改进 Markdown 换行、发布包层级、AI 结构导入和移动端操作。
- 仓库正式入口改为稳定路径 `apps/video-workspace/index.html`。
- 增加编辑后浏览器自动保存；导出文件仍是跨设备和长期归档依据。
- AI Prompt 模板拆到 `ai-prompts.js`，后续迭代 Prompt 不需要修改 `index.html`。
- 增加证据池字段，并把 AI Prompt 升级为证据驱动输出，减少空洞结论、泛素材建议和标题夸大。

## Legacy 3.8.x

- 只保留最后一个 3.x 模板 `legacy/project-forge-v3.8.9.html` 作为兼容入口。
- 更早版本由 Git 历史保存，不在工作树中重复存放。
