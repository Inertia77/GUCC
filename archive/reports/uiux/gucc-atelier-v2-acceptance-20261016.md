## CSS 归属与缓存

- Atelier tokens 合并到 `gucc-premium.css` 唯一 root；删除共享上下文中的重复定义与未使用间距 token。
- Dock 外观全部归 `gucc-shell-nav-v2.css` 管理，移除 premium、旧 theme、旧 UIUX 的竞争规则。导航文件 !important 从 146 处减少为 1 处，仅保留隐藏行为契约。
- 保留减少动效与隐藏正式平台面板的必要规则；没有为压缩行数删除画布细节或旧业务样式。
- 移动导航按工作区实际空间使用 700 / 1000px；全局 Dock 以 1024px 切换桌面，输入避让与之对齐。
- 更新 shell、premium、共享上下文、封面与发布样式 URL 版本；离线缓存升级到 static v46 / runtime v43。
