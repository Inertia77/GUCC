# 手机 DB 与资料页排版修复

基于 2026-10-16 最新 main `c23cdc796ccf3e80b6543aeb87a1d855c6afeeae`（PR #57），保留已有桌面 Dock 修复与全部业务功能。

## 截图复现与原因

用户截图中的 DB 底部文字竖排、黄色选中细条，以及剧情库字标 / 返回重叠，在实际 Chromium 页面中复现。

1. 旧 `gucc-zzz.css` 用 !important 将共享 Dock 设回六列、48px 宽，并覆盖链接颜色和字号。五个入口因此出现异常窄目标和竖排文字。
2. DB 使用 premium 后不再加载旧 UIUX 层，但筛选开关依赖旧层的收起规则，导致全部筛选默认展开；异步插入的机制页也没有可靠初始化该开关。
3. 资料页同时加载 inline、theme、reference、zzz、premium，返回按钮占满宽度挤压字标，部分手机网格依赖旧全局主题。
4. 1024px 横屏下 DB 主区宽度按 viewport 计算，未扣除桌面 Dock；“更多”的装饰编号也会挤压文本。
5. DB 专用字体和 AI Prompt 等宽代码没有继承本地中文字体，隔离 Chromium 中出现缺字方框。

## 修复

- 四个 Atelier 页面停止加载两套旧全局皮肤；旧皮肤中的 Dock 规则同时移除，共享导航外观只有一个所有者。
- 手机和桌面共用完整的横排标签契约，保留 PR #57 的 94px 桌面轨道及触控空间。
- DB 手机页头单行，退出按钮不再铺满整行；筛选默认收起，点击展开，执行搜索后回到结果；机制页初始化后显式刷新筛选控件。
- 角色、阵容、机制、版本四个搜索工作区均保留；研究 / 养成校准继续位于“更多”。
- DB 手机去除查询区、卡片上的低信息装饰标签，保留各游戏卡片的原色与材质。
- 资料页独立负责手机单列、字标 / 返回布局、目录与阅读动作；旧 !important 竞争规则清理，继承 Atelier tokens。
- 资料库三分类按钮不再逐字竖排；正文代码继承含中文回退的 GUCC 等宽字体。
- 主区按父容器宽度计算，避开桌面轨道；横屏“更多”保持单行。
- 更新样式 URL 与 static v48 / runtime v45 离线缓存。

## 验收

新增 `scripts/test-mobile-reference-browser.cjs` 并加入完整 GUCC CI。四页面：DB、剧情库、AI Prompt 资料、资料导航。

改造前记录 320×740、360×800、390×844、430×932、768×1024、1440×900、1920×1080，并增加 1024×768 横屏，前后各 32 张默认首屏；修复后另有 10 张交互截图。

断言包括五个 Dock 目标至少 44×44、文字单行且字号至少 12px、页头不重叠、标题不异常放大、无意外横向溢出、桌面主区不覆盖 Dock、DB 筛选展开 / 收起、结果首屏可见、编辑抽屉避让、六种游戏切换、四个 DB 分页、目录搜索 / 跳转、资料分类、短视口菜单及减少动效。

完整 npm test、新增手机验收与原十套 Chromium 回归已在本地通过。原 premium 套件同步使用新的“展开筛选再选择”的真实交互路径；没有绕过隐藏控件点击。所有新验收网络请求限定到隔离测试域，记录零业务写入。

## 数据与验证边界

本次没有数据库迁移或生产数据库操作。项目 / 视频身份、成果、Lock、历史、云端同步、角色状态与本机草稿逻辑不变。新增 DB 事件只初始化界面控件，不增加 API 请求或写入路径。

截图使用真实仓库 HTML / CSS / JS 和明确的合成 DB 行，不是正式账号截图。正式登录态依然需要有效会话；发布后只对公开网页与资源做回读，不绕过门禁，不创建测试用户。

## 正式缓存回读补修

PR #58 上线后，正式浏览器仍从缓存的 access-guard.js?v=14 引导旧 shell v15，并将样式退回 v5/v3。补修将全部 HTML 的门禁资源统一更新为 v15，加入静态预缓存，并推进 static v49 / runtime v46。验证门禁依旧有效，未改认证逻辑或存储。
