# 游戏信息中心

批量打开游戏研究页面，用于日常查看官方视频、角色资料和其他保留信息源。

当前六个重点游戏：崩坏：星穹铁道、鸣潮、绝区零、明日方舟：终末地、异环、阴阳师。

| 文件 | 用途 |
|---|---|
| `06-game-information-check.bat` | 六个重点游戏及其官方分号的 B站视频主页，不含动态页 |
| `07-game-character-pages.bat` | 官方角色/图鉴页；异环打开本地缺页提示 |
| `08-game-leak-character-pages.bat` | 测试服、内鬼站角色资料页；终末地打开本地官方参考提示 |
| `09-key-games-official-community-pages.bat` | 重点游戏的官方社区与资讯入口 |
| `10-other-games-bilibili-videos.bat` | 其他游戏与补充知名二游的 B站官方视频主页 |

这些脚本只打开网页，不读取账号数据，也不修改 GUCC 数据库。Bilibili 账号补充结果核对日期为 2026-08-14。
