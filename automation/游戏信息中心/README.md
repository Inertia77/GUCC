# 游戏信息中心

批量打开游戏研究页面，用于日常查看官方视频、角色资料和其他保留信息源。

| 文件 | 用途 |
|---|---|
| `game-information-check.bat` | 重点游戏及其官方分号的 B站视频主页，不含动态页 |
| `other-games-bilibili-videos.bat` | 其他游戏与补充知名二游的 B站官方视频主页 |
| `game-character-pages.bat` | 从原主脚本中拆出的官方角色/图鉴页 |
| `other-game-sources-archive.bat` | 低频使用的社区和资讯入口，作为保留归档 |

这些脚本只打开网页，不读取账号数据，也不修改 GUCC 数据库。Bilibili 账号补充结果核对日期为 2026-08-14。
