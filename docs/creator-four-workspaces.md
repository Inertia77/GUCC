# Creator OS v4 · 四工作区

正式入口：`apps/video-workspace/production-system/`。旧版固定 Studio 和 Publishing Console URL 继续可用。

| 工作区 | 日常用法 |
| --- | --- |
| 项目中枢 | 总览所有项目与各视频六项成果，选择视频后打开正式成果编辑；项目档案内编辑、完成、归档、恢复。 |
| 创作工作台 | 默认固定六成果 Prompt，按需切换灵活编排。复制 Prompt 交给 AI 执行；实际成果返回项目中枢核验。封面任务旁提供高级工具入口。 |
| 发布与复盘 | 选择具体视频，导入可编辑 MD 发布包，编辑六平台字段、预检、辅助投稿、人工确认发布记录，采集数据快照并复制复盘 Prompt。 |
| 规则与资料 | 内部标签切换长期硬规则/可调整建议、能力方法和公共资料。 |

## 新增项目的本地目录

「新建项目 → ＋ 新项目」和灵活编排的建立项目草案窗口，均提供可展开的「本地项目目录」命令。先在 Windows 创建并命名自己的项目文件夹，在该目录打开 PowerShell，再复制执行。只创建 01–08 八个标准一级目录，保留已有文件，不生成项目专属的子目录。

## 数据边界

- 正式成果只读取 `creator_deliverable_records`；Prompt/回执完成不会自动批准成果。
- 每条视频独立保留 Studio 草稿、发布单、数据快照和正式审核记录。
- 嵌入桥只同步已验证的项目/视频选择与可视区域信息，不传递成果完成状态。已有 RLS、CAS、人工确认及真实文件校验继续生效。
- 发布工具不会声称平台上传或发布成功；需用户实际审核和登记。
- 归档是可恢复的生命周期状态，不删除媒体、视频身份或正式成果。
