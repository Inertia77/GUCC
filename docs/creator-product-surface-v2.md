# GUCC Creator OS｜Product Surface v2 · 2026-11-10

## 目标与边界
以正式商用工作台的信息层级替代叠加的游戏 HUD 面板视觉。侧边导航／工作区 masthead 简化；项目与视频上下文分别选择；新增基于正式成果记录的「下一步」；六项成果保持原人工审核及 Supabase 真值，筛选仅改变本地显示。项目档案与历史、高级动态制作、发布控制台原行为保留。

## 交互
- 项目切换：仍使用原 `outcomeProjectSelect` / 云端记录。新项目动作保留。
- 视频切换：仍使用原正式 video ID，不合并或重命名已有视频。
- 下一步：仅依赖 `Outcomes.summary` 的已核验记录。未读取成功时不臆测；六项完成时只提供跳转发布；未完成时打开该成果原有编辑器，绝不自动确认。
- 成果筛选：`outcomePendingOnly` 只隐藏已确认卡片；不改变任何成果表、文件校验、状态或 Lock。
- 低频管理：本地目录与刷新迁入 More 操作菜单；按钮 ID 仍保留供原有监听使用。
- 设计：深色中性表面、克制的紫蓝与青绿状态色、统一圆角与边框、信息密度优先；去除装饰性巨大 `06`、稀疏大头图与重复彩色边框。

验证桌面、平板和 390/360px 手机的项目/视频切换、成果编辑、筛选、下一步跳转、Cloud Lock 不变与离线缓存版本。不得视前端提示为已发布或已验收。
