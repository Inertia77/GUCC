## 数据与行为边界

没有数据库迁移、生产写入或项目重建。未修改 Supabase RLS、RPC、Revision/CAS、表结构及正式身份算法。

继续保留 creator_projects、creator_video_workspaces、creator_deliverable_records、creator_deliverable_versions、Creator OS 快照和 Prompt Flow、Lock、审核记录、原有文件元数据、各工具的本机草稿及独立发布草稿。

共享模块仍使用同一 Project ID + Video ID、事件及工具适配器。文件登记仍读取实际字节，不上传媒体；AI 回执不会直接变成人工确认。冲突不静默覆盖。重开正式成果通过带原因的显式确认。

生产只读基线：4 项目、4 快照、2 正式视频、48 文件元数据；成果记录、成果版本与独立发布草稿各 0。保留 ZZZ-3.3-PHOENIX-PREVIEW / FIONI 与 ZZZ-3.3-SEVERIAN-PREVIEW / SEVERIAN 原映射。
