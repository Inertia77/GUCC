# GUCC Atelier

本次升级延续 GUCC 的深色工作区、薄荷绿／青色／紫色重点、G 品牌与切角任务区。统一底层令牌在 `assets/gucc-premium.css`；页面保留各自的功能布局和游戏主题。没有引入付费素材或新的运行时依赖。中文字体来自 PR #42 的 OFL Noto Sans SC（许可证随字体保留）；PR #41/#42 的本机素材状态表达经逐项提取，未合并旧分支覆盖最新 main。

## 视觉规范

- 背景 `#0c1013`，表面 `#141a1f`，升高表面 `#1b2329`；轮廓 `#303b43`。主要文字 `#e9eeeb`，次要文字 `#a7b4ba`。
- 主操作薄荷绿 `#a4e1c9`；青色 `#89c9da` 表示辅助信息；紫色 `#b2aad6` 用于 AI 导入。警告 `#e6bd81`、错误 `#f0a5a5` 配合明确文字，不能仅靠颜色传达状态。
- 中文以 GUCC Sans / Noto Sans SC 为主，系统字体回退。正文 14–16px，行距 1.7–1.95；元信息 12–13px；页面标题 28–56px。长 Prompt 保留原文与可选中复制能力。
- 空间采用 8px 节奏；面板通常 20–32px 内边距，阅读列优先；仅任务舞台使用品牌切角，普通输入与控件小圆角。
- 使用细分隔线组织信息，避免重复玻璃卡片。无粒子背景、大面积泛光和无目的动画。键盘焦点明显；原生 dialog 提供模态、Esc 与焦点行为；减少动效偏好关闭动画。
- 手机重新排列工作顺序：任务优先、横向阶段导航、画布在工具前、辅助工具折叠。底部统一五入口，页面为其预留空间。

## 页面变化

Portal 使用编辑式标题、品牌签名和分隔式功能索引；登录前可继续本浏览器上次项目，明确尚未核对云端。固定 Studio 是安静的编辑桌，七阶段和成熟 Prompt 完整保留。Creator OS 把当前任务、项目资料、多视频分支与路线分开；编排、本机目录等辅助系统渐进展开。Command Center 保留游戏主题，统一表格与筛选、登录及编辑表面。封面以画布为中心，模板与 AI 辅助工具按需展开；缩放只影响视图，各比例有真实缩略预览，画布和导出共用同一个 Canvas 渲染器。浏览器测试逐字节比较预览 Canvas 与导出的 PNG（16:9、4:3、3:4），同时核对像素尺寸与独立布局。发布单保持平台流程，并按项目／视频身份存储独立草稿；新增 owner RLS 与版本校验的独立云端发布草稿表，兼容项目级旧发布接口。资料库采用清晰的资料分层和舒适的阅读排版。

## 数据与事实边界

1. 历史去重仅作用于历史快照中的重复长文本，原始项目 JSON 可无损还原。保留全部已有回退、修订与冲突历史；不主动裁剪。
2. 云端共同基线存 SHA-256 与 revision，避免完整快照重复占据 localStorage。发送时固定数据副本；期间新编辑继续待同步。网络失败不显示成功。冲突采用已有 CAS RPC，保留另一端版本。旧草稿改名后可恢复归档，不再硬删除。
3. 回执必须有明确状态，检查项目、视频与节点身份。整体重编排不能覆盖已执行节点；DIFF 有版本校验，保护已完成和待审核节点并检查依赖环。
4. AI 回执、真实文件核验、质量检查、人工批准分别记录。人工锁记录明确为人工声明，不冒充程序扫描或旧版正式 Cloud Lock。
5. 交接包有 `projectId` / `videoId`，不自动传递真实素材或发布状态。固定与动态模式不会自动相互覆盖。发布单保留每条视频的文案、素材元信息和执行记录，切换后真实文件仍需本机确认。
6. 本轮仅新增独立发布草稿表及受限 RPC，不更改已有生产项目正文或 Lock；项目主表的旧状态机与动态快照是两个模型。Portal 已有联表 RPC 使用快照状态和生命周期展示动态项目，不把主表旧阶段当动态进度。新 RPC 的实际数据库事务测试覆盖首次保存、读取、版本冲突、双视频、身份校验与 owner RLS，并回滚全部测试草稿；主表访问权限保持原样。

## 验证

`npm test` 检查成熟 Prompt、回退、编码往返、依赖环与身份、兼容生产引擎、数据契约、本机助手与发布功能。现有固定 Studio / 兼容 Production 浏览器回归继续保留。

新 `test-gucc-premium-browser.cjs` 检查七个主要页面在 1600、1280、390px 下的真实 Chromium 渲染、溢出、分支、回执、回退、DIFF、独立视频发布单和空间不足。`test-gucc-cloud-browser.cjs` 使用隔离 API 验证保存竞态、断网提示、摘要基线、隐私字段与冲突备份。`test-gucc-publish-cloud-browser.cjs` 验证视频级 CAS、请求期间的新编辑、云端冲突恢复、两视频独立保存与旧发布接口隔离。手机默认一次编辑一个平台，可显式展开全部，隐藏表单仍参与预检。所有浏览器写测试仅作用于隔离数据，禁止生产 Auth signup。
