模型与规则

游戏资料、创作关注、游玩 T1/T2/T3、角色研究/养成、Creator 视频、语言轨、素材与发布复盘均已有独立的数据表；不要把这些状态混写。

  • 角色研究与养成：◯ / △ / ✕ / 対象外；喜好度存于 character_evaluations。
  • 游玩优先级在 game_play_policies；内容创作级别在 game_status。
  • Creator：project → video → deliverables；language tracks / visual master → variants → channels → publications。
  • 云端存元数据，真正大媒体仍在本地。历史备份表不得当作业务主表编辑。

点击下方表名展开字段。字段清单来自当日生产 Schema 只读查询；约束与迁移请以生产 catalog 和 supabase/migrations/ 为准。
