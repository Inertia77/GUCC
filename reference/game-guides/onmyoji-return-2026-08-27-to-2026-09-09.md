# 6. 日常：回坑后真正需要保留的固定循环

建议把日常压缩成 **10～25 分钟核心版**。

## S 级：每天必须看

### 1. 登录签到
无脑做。

### 2. 当前版本活动
凡是有每日门票 / 每日奖励的，优先处理。

### 3. 花合战
不用额外硬刷，围绕其他活动顺手完成。

### 4. 逢魔之时
价值仍然很高，包括逢魔御魂相关材料、逢魔之魂、黑蛋碎片等。能打就打；刚回坑不用追榜。

### 5. 阴阳寮基础操作

- 祈愿
- 寮任务
- 功勋 / 勋章
- 结界相关操作

### 6. 结界

- 收经验
- 收体力
- 寄养
- 处理结界卡

### 7. 胧车探索

开启条件包括：

- 单人 30 秒内通关「八岐大蛇·神罚」；
- **或累计签到满 365 天**；
- 且拥有任意 1 只契灵。

目前可用于御魂副本与觉醒副本。

核心用法：

> **把机械性御魂 / 觉醒刷取交给离线探索，而不是重新每天人工刷几百把。**

## A 级：有时间做

### 悬赏封印
高价值奖励优先：勾玉、体力、式神碎片及当前需要资源。

### 个人结界突破
有票就打，主要看勾玉 / 勋章收益，不需要因票满焦虑。

### 地域鬼王
每天打一份稳定奖励即可，不需要重新当环球鬼王公务员。

# 9. 现阶段 PVE 生产队

## 9.1 现在立刻可用：双天照短线

你已经有双天照，所以当前就能工作。

基础思路：

> **辅助 → 天照 1 → 天照 2 → 补刀 / 增伤**

用途：

- 探索
- 觉醒
- 活动小怪
- 部分御魂
- 普通短线 PVE
- 阴界清怪

目标是：

> **稳定自动 > 少两秒钟。**

## 9.2 获得神无月后：短线恢复队

推荐骨架：

> **神无月 + 天照 + 天照 + 供火/增伤 + 增伤**

根据 Box 替换：

- 因幡辉夜姬
- 不见岳
- 伊邪那美
- SP 缘结神
- 千姬
- 帝释天
- 追月神
- 辉夜姬
- 座敷童子

先有谁用谁。

## 9.3 雪御前：现代 PVE 主 C 储备

雪御前可承担：

- 御魂副本
- 活动爬塔
- 短线清场
- 长线 Boss
- 逢魔
- 麒麟
- 狭间等

### 重要

**现在不要直接“一键黑蛋 555”。**

先等：

1. 神无月拿到；
2. 十周年石长姬实装；
3. 周年免费抽结果；
4. 确认实际长期队伍；

再统一规划技能投入。

## 9.4 长线 Boss 逻辑

不要把所有输出都塞进去。

现代长线通常更接近：

> **1 个主 C + 4 个拐 / 功能辅助**

当前过渡：

> 神无月 + 天照 / 雪御前 + 增伤 + 供火 + 功能位

最终队伍根据具体逢魔 / 麒麟 / 活动 Boss 单独存预设。

- 招财
- 火灵

- 速度胚子
- 双速 / 高速
- 高爆伤
