## 统一事实等级

- 【官】官方/游戏内直接确认。
- 【证】多处已实装文本可稳定拼合。
- 【推】有充分依据但仍可能被后续推翻。
- 【未】明确抛出但尚未解释。
- 【可能未来】预知、演算或未来分支，具有信息价值但不能当成已发生历史。

## 统一时间原则

版本号不自动等于世界内年表。

至少需要区分：

```text
发布顺序
世界内真实顺序
角色当时认知顺序
后续重解释
```

典型案例：
- 《异环》1.2发生在1.3红字终局数周后；
- 翁法罗斯存在多轮演算/回归；
- 匹诺康尼存在梦境与被烧毁记忆；
- 二相乐园存在画中世界与因果回返。

## 高质量版本章标准

主要版本/篇章至少尽量覆盖：

```text
前情局势
→ 事件链
→ 人物动机
→ 谁在什么时候知道什么
→ 阵营/关系变化
→ 世界观新增
→ 伏笔回收与新增
→ 容易误读/禁止写死
→ 主题
→ 前后章连接
→ 来源锚点
```

## 当前维护系统

### 状态单一来源
`CURRENT_STATUS.json` 记录五款维护游戏的：
- 当前版本；
- 资料库版本；
- 当前文档；
- 最近核验日；
- 下次必须联网复核日。

### 在线目录
`FILE_MANIFEST.md` 是 Story Library LIVE 目录的Markdown路径事实源。

### 离线目录
`reference/story-library.html` 保留同步更新的fallback，manifest读取失败时也不能退回旧版目录。

### 自动检查
运行：

```bash
npm run check:story
```

会检查manifest、核心文件、当前版本状态、兼容页隐藏和来源区等。

### 维护顺序
根 `00-index.md` **最后更新**。它是验收结果，不是任务计划。
