## 阅读原则

### 1. 先分清“发布顺序”与“世界时间”

《异环》1.2 已经证明版本号不必等于世界内事件顺序；《崩铁》《鸣潮》等也存在梦境、模拟、记忆与历史层叠。时间线文件必须明确写出层级，不可机械按版本编号当年表。

### 2. 先写发生了什么，再写我们如何解释

统一事实等级：

- 【官】官方/游戏内直接确认。
- 【证】多处已实装文本可稳定拼合。
- 【推】有充分依据但仍可能被后续推翻。
- 【未】明确抛出但尚未解释。

### 3. 角色反转不修改旧事实

例如《异环》达芙蒂尔后来证实为卧底，不代表 1.1 的后果没发生；残虹最终反叛伊南娜，也不代表她在恒今时事件中没有作为红字执行者加害。

### 4. 高质量版本章标准

每个主要版本/篇章至少应覆盖：

```text
前情局势
→ 事件链
→ 人物动机
→ 信息揭露
→ 关系/阵营变化
→ 世界观新增
→ 伏笔回收与新增
→ 容易误读处
→ 主题
→ 前后章连接
→ 校对依据
```
