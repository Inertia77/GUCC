# Story Library｜来源与校对日志

> 最后更新：2026-08-25  
> 本文件记录“什么资料可以拿来写事实、什么只能拿来找线索”。具体章节仍应在文末保留自己的校对依据。

## 1. 来源优先级

### S 级：游戏内已实装内容

1. 主线 / 开拓任务 / 正篇
2. 角色任务 / 番外 / 伴星任务
3. 游戏内档案、索引、物品与异象说明
4. 已实装过场、环境文本、可交互文本

这是事实层最高优先级。若后续版本明确修正旧信息，以最新已实装文本为准并记录修正。

### A 级：官方公开资料

1. 版本更新公告
2. 官方网站世界观 / 角色资料
3. 官方 PV、前瞻直播、角色展示
4. 官方社媒补充设定
5. 官方制作组通讯

官方宣传语可以证明“官方如何定位内容”，但若宣传文案与游戏内最终实装细节冲突，剧情事件以实装为准。

### B 级：完整实机档案

- 无剪辑主线录像
- 完整番外录像
- 多语言文本录像

主要用于：检索章节顺序、回查对白、确认演出细节。关键结论尽量与游戏内/官方资料交叉核对。

### C 级：社区 wiki / 攻略 / 剧情复盘 / 讨论

用途：
- 找关键词和遗漏章节。
- 发现值得回查的细节。
- 对比不同解释。

不可单独用于：
- 写死角色亲属关系。
- 写死未说明的真实身份。
- 把测试服/内测旧文本当公测事实。
- 把社区俗称当官方术语。

## 2. 统一事实标签

- 【官】官方或游戏内直接确认。
- 【证】多个已实装证据可以稳定拼合。
- 【推】当前合理，但后续仍可能推翻。
- 【未】剧情明确留下但尚未解释。

## 3. 各游戏本轮主要校对方向

### 崩坏：星穹铁道

- 已实装主线 / 开拓续闻。
- 官方版本公告与角色资料。
- 重点校对：翁法罗斯、二相乐园、命途/身份/模拟与客观历史分层。

### 鸣潮

- 已实装潮汐任务、危行任务与版本公告。
- 重点校对：黑海岸、黎那汐塔、拉海洛、梦州/玄方；避免把梦境/演算当现实时间线。

### 绝区零

- 已实装主线 Season 1–3、代理人秘闻与版本公告。
- 重点校对：旧都灾变、Sacrifice、法厄同身世、卫非地、罗斯凯利法；旧的 `2.x` 压缩章已拆回版本粒度。

### 明日方舟：终末地

- 已实装“冷启动/复苏”、四号谷地、武陵 1.0–1.4。
- 官方更新公告、研发通讯。
- 《明日方舟》旧人物名在序章墓碑文本中属于实装硬证据；但“终末地与本篇到底是什么精确年代/世界关系”仍保持【未】，不得仅凭名字写死。

### 异环 / NTE

本轮主要使用：

1. **1.0 公测已实装正篇**：
   - 不虞亦先兆
   - 生意经与招财宝
   - 从捏造开始的恋爱大作战
   - 成交？成交！
   - 讨债人
   - 红字的研究
   - 未清算的债
2. **1.0 已实装番外**：
   - 月光当铺
   - 不言不知秋
   - 番茄酱暴走现场实录
   - 某传奇乐队（吗？）的第一页
3. **1.1 官方更新与已实装「游梦洄廊」**：向阳岛、异象福利院、娜娜莉失踪与旧梦停航。
4. **1.2 官方更新与已实装「勇者斗赤龙」**：九百九十九夜、沃伦大陆。官方明确其使用倒叙结构，发生在红字事件尘埃落定之后。
5. **1.3 官方更新与已实装「雾巢游戏」**：时间线重新接回 1.1 后，伊波恩 + E.T.D 六队突入红字基地，完成红字篇阶段性终局。
6. 官方角色资料用于核对残虹、真红、安魂曲、卡厄斯、娜娜莉、塔吉多等身份/能力。
7. 完整无剪辑录像用于核对具体任务顺序与演出。

#### 异环特别警告

- **1.2 版本号早于 1.3，但世界内时间晚于 1.3。**
- 第一枝展示的坏未来属于“可被改变的未来分支/预知”，不能当作已经发生的历史。
- 达芙蒂尔 1.3 被证实参与卧底计划，不反向取消 1.1 已发生的损失。
- 残虹最终反叛伊南娜，不等于她在 1.0 恒今时事件中的行为被洗掉；剧情后仍进入司法处理。
- 社区对残虹伪装名、部分角色亲属关系存在二手说法，未稳定核实的不进入事实层。

### 无限大 / ANANTA

本轮按用户要求**不维护**。原有预研资料保持原样，不新增来源、不把测试/宣传推测升级为正式剧情。

## 4. 版本资料的日期规则

所有“当前版本”“已实装”判断都应带校对日期。未来版本公开后：

1. 先确认是否真的上线。
2. 再把“已官宣未实装”移动到“已实装”。
3. 若正式版改动了前瞻文本，删除旧结论而不是强行兼容。

## 5. 社区内容的正确用法

一个安全流程：

```text
社区看到线索
→ 找到任务名/角色名/异象名
→ 回查完整实机或官方页
→ 分清事实与解释
→ 再写进资料库
```

不要反过来：

```text
看到一个高赞评论
→ 觉得很有道理
→ 直接写成“官方真相”
```
