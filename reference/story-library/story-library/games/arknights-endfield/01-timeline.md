# 明日方舟：终末地｜时间线 v3

> 校对日期：2026-08-25  
> 原则：**客观历史 / 管理员旧记忆 / 代理人重构 / 玩家当前版本**分层维护；无明确年份时不硬编。

## 0. 为什么《终末地》不能只做一条直线年表

至少存在四类“过去”：

1. **客观历史**：别人也能证实的事件，例如息壤突破、科考站事故；
2. **管理员旧记忆**：冷启动墓碑、远征、战场声音；
3. **代理人 / 画卷重构**：庄方宜1.2进入的记忆空间；
4. **玩家当前事件**：1.0–1.4实装主线。

这四类内容不能全部写成“某年某月真的以画面所示方式发生”。

# C. 武陵十年前：必须独立维护的一段历史

## C1. 息壤关键突破【官】

年轻庄方宜与科考站团队完成息壤关键研究。

研究者当时已经想象：

- 城市；
- 学校；
- 广场；
- 公共生活；
- 新学科；
- 后来的天师与研究者。

这是当前武陵很多基础设施的历史起点。

---

## C2. 北方重大裂隙 / 超域事故【证】

约十年前：

- 科考站遭遇重大灾难；
- 多位研究者牺牲；
- 北部地区长期封禁；
- 庄方宜幸存并留下；
- 后续应龙 / 防线 / 科研体系都被此事重塑。

【未】最初触发因素和完整责任链。

---

## C3. 庄方宜从年轻研究者变成地区承担者【证】

灾难后，她把悲伤转成工作：

- 继续息壤 / 地区技术；
- 逐步承担天师与管理责任；
- 让前辈想象中的城市真正出现。

这十年不是“她等主角回来”的空白，而是武陵实际成长的十年。

---

## C4. 应龙特勤队 / 陈千语 / 诀旧史【部分回收】

明确知道：

- 陈千语、诀与谈剑堂 / 旧师 / 应龙体系存在过去；
- 陈千语曾未能走上某条精锐道路；
- 1.4揭示其更容易优先救具体人命；
- 诀则更接近精锐使命逻辑。

【未】十年前应龙特勤队完整行动史仍不完整。

- 息壤突破；
- 前辈牺牲；
- 管理员收到成功汇报。

以下应作为“记忆对话”记录：

- 现在庄方宜对过去自己说话；
- 当前空间与过去设施混合。

不要写成真实时间旅行改史。

都没有在1.4被彻底封口。

# E. 官方章节顺序 ≠ 每个玩家实际游玩顺序

1.4加入“武陵主线先行解锁”。

完成第一章进程Ⅱ「修缮进展」后，即可较早接武陵。

所以不同玩家可能出现：

- 四号谷地后半尚未完成；
- 已经进入武陵前段

的体验差异。

资料库因此按**故事章节和版本实装顺序**维护，不用单一玩家流程倒推世界时间。

# F. 当前最重要的时间缺口

1. 序章旧史距当前到底多久？
2. 管理员跨星河远征与塔卫二定居 / 建设之间经历了什么？
3. 佩丽卡命名场景位于哪一阶段？
4. 四号谷地源石大树具体种植年代？
5. 十年前武陵事故与更大塔卫二超域变化是否有关？
6. 应龙特勤队十年前完整行动顺序？
7. 阿达希尔为何能声称多次见过管理员的绝望？

这些缺口以后应优先用新主线填，不用猜测年份补空白。
