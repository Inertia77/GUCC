> 校对日期：2026-08-25  
> 规则：谜团按“已基本回收 / 部分回收 / 高优先级未解 / 长期观察”分层；每条必须写出当前证据上限。

# A. 已基本回收的问题

## A1. 庄方宜为什么一直留在武陵？【已基本回收】

### 早期疑问

她为什么以极年轻天师身份长期承担武陵，且几乎把自己完全投入工作？

### 1.2证据

- 十年前加入科考站；
- 参与息壤突破；
- 同僚在裂隙事故中大量牺牲；
- 她把悲伤压成工作；
- 前辈想象的城市后来真的建成；
- 保存竹露十年；
- 最终对管理员说武陵已割舍不下。

### 当前结论

不是“她天生事业心超强”。

而是武陵同时是：

- 同僚未竟理想；
- 她幸存者身份的证明；
- 她亲手继续了十年的生活世界。

### 仍有余项

她未来是否真正学会不默认“我去”，仍待后续人物发展。

# B. 已部分回收，但仍有核心缺口

## B1. 武陵十年前发生了什么？【部分回收】

### 已知

- 息壤研究成功；
- 科考站存在；
- 发生重大裂隙 / 超域灾难；
- 多位研究者牺牲；
- 北部长期封禁；
- 庄方宜幸存；
- 应龙体系也被这段历史影响；
- 1.4当前人重新进入北部禁区。

### 仍未知

- 最初触发因素；
- 各组织当时完整决策链；
- 科考站与应龙行动精确先后；
- 是否存在尚未公开的责任人 / 外部干预。

### 当前结论

可以说“十年前灾难是武陵篇核心历史创伤”，不能说“事故原因已经彻底解释”。

---

## B2. 聂菲斯到底是什么状态？【部分回收】

### 已知

1.2经历重大Boss战。

1.4后续仍出现与聂菲斯 / 协议源石相关的信息。

### 资料规则

必须分开：

1. 战斗被击败；
2. 身体状态；
3. 官方是否明确死亡；
4. 是否通过其他机制继续存在。

当前不能用“打完Boss”替官方下死亡判决。

# C. 全作最高优先级未解

## C1. 管理员到底是谁？【未】

### 硬证据

- 序章“最终任务 / 追上往事”；
- 跨星河 / 跨死亡；
- 牺牲自我；
- 大量旧人物名；
- 四号谷地老员工认识TA；
- 源石大树；
- 十年前武陵科研团队向TA汇报；
- 阿达希尔声称多次见过TA过去的落寞。

### 不能越级

不能直接断言：

- 就是旧作某个具体角色；
- 同一肉身连续活了多少年；
- 复苏是克隆 / 转生 / AI / 休眠中的某一种。

### 当前真正问题

不是“管理员过去很厉害吗”，而是：

> **现在这个人格与过去那个承担者之间，连续性究竟由什么保证？**

## C2. 《明日方舟》旧人物名与塔卫二精确是什么关系？【未】

### 已知

游戏内主线墓碑直接出现：

凯尔希、特蕾西娅、特雷西斯、Scout、Ace、Outcast、Whitesmith、博卓卡斯替、叶莲娜、克丽斯腾·莱特、雷尔金等。

管理员有情绪反应。

### 已确认结论

两作存在强直接历史 / 记忆连续证据。

### 仍不能写

- 明确几百 / 几千年后；
- 所有人物墓碑属于同一现实地点；
- 某个旧作结局直接等同终末地历史起点。

这是目前最适合长期做“证据更新表”的谜团。

# D. 长期观察类

## D1. “征服者”是否就是序章称号回收？【推】

序章：

> 征服者，毙于征途。

1.2：聂菲斯“征服者”。

文本呼应非常强，但仍不足以证明序章唯一指向聂菲斯。

保留为高价值【推】，不要升级【官】。

---

## D2. 画卷 / 记忆空间能保存多少客观信息？【长期观察】

庄方宜1.2证明它有真实历史信息价值。

但当前空间会：

- 混合；
- 象征；
- 让现在人物与过去自我对话。

所以今后任何“记忆画面”都要分：

- 被多人 / 文件确认的事实；
- 角色主观记忆；
- 异常空间构造。

---

## D3. 蚀影保留多少“原本人”？【未】

1.4蚀影带有应龙等身份痕迹。

当前能确认它们与旧体系有连接，但不能凭敌人名直接断言每个个体是谁变的、保留多少人格。

# F. 研究纪律

后续任何新版本都执行：

1. 先记录新事实；
2. 再看它回收了哪条谜团；
3. 如果旧推论被推翻，直接降级 / 删除；
4. 不因为一个理论“很漂亮”就把【推】改成【官】。

《终末地》当前最大的魅力正是“证据已经很多，但最终解释还没有封死”。资料库要保住这个层次。
