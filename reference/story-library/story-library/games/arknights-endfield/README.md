## 这套资料库现在解决什么问题

上一版已经把版本顺序拆对，但仍偏向“这个版本发生了什么”。v3开始统一改成：

**发生了什么 → 为什么发生 → 谁为什么这么做 → 这个选择改变了谁 → 新增了什么世界观 → 哪些旧伏笔被重新解释 → 哪些仍不能写死。**

《终末地》尤其不能只做事件摘要，因为它的四条主线一直叠在一起：

1. 管理员失忆与旧史；
2. 塔卫二地区社会如何生存；
3. 超域 / 天使 / 源石等世界机制；
4. 集成工业如何把战斗胜利转化成真正可持续的生活。

所以本库把“剧情”“工业”“地区治理”“人物记忆”视作同一套因果系统。

## 七个总览入口分别干什么

### `00-overview.md`

回答“这游戏现在到底在讲什么”，重点不是名词表，而是把管理员、地区建设、超域危机和旧史连接起来。

### `01-timeline.md`

同时维护三类时间：

- 更早历史 / 管理员旧史；
- 武陵十年前；
- 玩家当前版本时间。

另外把代理人画卷等“记忆空间”单独标记，避免把记忆重构误当客观录像。

### `02-factions.md`

记录组织的：

- 公开目标；
- 实际资源；
- 内部矛盾；
- 与其他势力关系；
- 当前证据边界。

### `03-characters.md`

不是人物简介，而是人物弧线台账：起点、欲望、创伤、错误倾向、关键选择、关系变化、仍未解决的问题。

按：

- 已基本回收；
- 部分回收；
- 高优先级未解；
- 长期观察

分类，不把所有问号堆在同一层。

每个选题都提供：

- 核心问题；
- 可用证据链；
- 反方 / 易误读；
- 适合上屏的素材节点；
- 当前能下到什么结论。

## 证据规则

- **【官】**：游戏内已实装文本、官方更新、角色档案、研发通讯直接确认。
- **【证】**：多个已实装文本 / 完整流程可以稳定拼合，但不是一句官方原话。
- **【推】**：有充分依据，但仍存在其他解释。
- **【未】**：当前故事明确抛出，但尚未解释。

### 三条硬规则

1. **Boss被击败 ≠ 官方确认永久死亡。**
2. **记忆 / 画卷 / 代理人重构有情报价值 ≠ 客观录像。**
3. **《明日方舟》旧人物名出现在序章是硬事实，但精确年代 / 身份连续方式仍是【未】。**

## 当前最重要的阅读结论

截至1.4，《终末地》最核心的主题不是“人类征服荒野”。

更接近：

> **一个曾经不停牺牲自己的人重新醒来，发现文明没有因为TA的失忆而停止；现在TA要决定，继承过去是否意味着重复过去的死法。**

四号谷地的树、庄方宜的竹露、陈千语救人、诀坠落以及管理员伸手，都是这个问题的不同答案。
