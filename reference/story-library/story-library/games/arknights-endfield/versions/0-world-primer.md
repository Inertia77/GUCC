# 世界底座｜塔卫二、源石、超域、天使与终末地工业

> 游戏：明日方舟：终末地  
> 资料状态：截至 2026-08-25 / 当前主线实装至 1.4「向渊行」  
> 剧透等级：全剧透  
> 证据规则：【官】官方或游戏内直接确认｜【证】多段已实装文本可稳定拼合｜【推】有依据但仍可能被后续推翻｜【未】尚未解释

## 0. 为什么需要一篇“世界底座”

《终末地》最容易被误读成“在外星球建厂的明日方舟”。但实际主线从第一分钟就在同时处理四个层次：

1. **管理员是谁**：一个被全世界很多人认识、自己却记不起过去的人；
2. **塔卫二怎么活**：文明环带、地区聚落、源石工业、交通和本地治理共同维持生存；
3. **超域危机怎么改变社会**：侵蚀、天使、裂隙不是单纯怪物刷新器，而会逼迫整个地区改变生产、迁徙与政治关系；
4. **过去如何留在现在**：管理员失忆，但源石大树、息壤、武陵科考站、帝江号和他人记忆都保存着TA过去选择的结果。

因此本资料库把“工业系统”“地区剧情”“管理员记忆”“明日方舟旧名关联”放在同一套因果框架中记录。

## 1. 塔卫二：不是空白殖民地

【官】当前故事主要发生在塔卫二。这里已经拥有长期存在的人类社会、城市、科研体系、地方武装、贸易、教育、宗族/寨落结构和地区治理。

所谓“文明环带”的扩张，不是把无人荒地画进版图，而是把一块危险地区真正接入：

- 电力；
- 物流；
- 安全道路；
- 医疗；
- 生产；
- 防侵蚀设施；
- 信息和调度系统。

这也是为什么终末地工业每次“部署协议核心”都具有剧情意义。一个点被协议网络接入后，才有可能从“今天能打进去”变成“明天还能住人”。

### 四号谷地与武陵为什么必须分开理解

四号谷地是工业、矿业、研究设施和拓荒历史高度集中的地区；武陵则依水而生，天师体系、宏科院、息壤技术、寨落与武艺传统构成自己的地方文明。

两地都面对侵蚀，却发展出不同解决方案。这证明超域危机从来不是统一模板。

## 2. 源石：资源、生命与历史的共同介质

序章第一批对白就给出：**“源石是生命的支柱，联系着每一个人。”**

这句话决定了资料库不能把源石只记成生产配方里的矿物。

### 已确认的层面

- 【官】源石参与工业、武器、能源与大量技术体系；
- 【官】武陵息壤本身也是源石技术成果；
- 【官】协议源石在后续主线中具有远超普通工业原料的价值；
- 【官】四号谷地“晚安，大树”等剧情把源石与家园记忆直接绑定；
- 【证】管理员过去显然参与过多个源石相关重大工程/历史节点。

### 不能写死的层面

【未】塔卫二源石、泰拉源石以及更古老文明技术之间的完整历史关系仍没有被主线一次讲清。

所以正确结论不是“源石就是同一种东西，所以两作年代关系已经确定”，而是：**两作存在强硬的连续证据，但精确年代与迁移过程仍待官方回收。**

---

## 3. 超域与侵蚀：不是地图毒圈，而是改变社会结构的灾害

“超域”在剧情里会影响：

- 地形；
- 生物；
- 源石环境；
- 交通；
- 建筑；
- 人的生存；
- 天使活动；
- 息壤与其他地区技术的稳定性。

四号谷地的处理更接近“工业和地表节点逐步重启”；武陵则因为水系、潮汐和地下裂隙，使侵蚀呈现明显的水文特征。

### 武陵十年前灾难为什么重要

1.2庄方宜记忆确认：十年前科考站遭遇重大裂隙事故，多位科研人员牺牲；1.4玩家真正进入北部禁区，等于把原先只能通过回忆看到的灾难空间重新打开。

因此“十年前”是武陵篇的核心坐标：

**息壤突破 → 科考站事故 → 庄方宜幸存并留在武陵 → 北方长期封禁 → 现在重新进入禁区。**

---

## 4. 天使：人类已经对抗百余年的“遥远生命”

序章直接确认两件事：

- 天使被称作“遥远的生命”；
- 人类与它们的对抗已持续百余年。

后续主线还能看到：

- 锚点持续产生天使；
- 超域/裂隙附近天使密度上升；
- 武陵存在“破潮之像”等地区性高危天使；
- 1.4又出现保留应龙身份痕迹的蚀影体系。

### 不要把三个概念混成一个词

**天使 ≠ 侵蚀 ≠ 蚀影。**

它们之间存在关系，但表现层不同。

【未】天使、代理人、超域底层机制、源石以及更高层存在的完整关系仍没有完全公开。

## 5. 协议核心与集成工业：为什么建厂本身就是主线

佩丽卡明确把终末地工业的职责概括为文明环带的建设与复兴。

这意味着集成工业不是“玩家闲时小游戏”，而是组织能力的一部分：

1. 找到可控制地区；
2. 部署协议核心；
3. 恢复供能、物流、生产；
4. 本地化生产关键材料；
5. 修复据点与交通；
6. 让居民、守军和科研体系能继续运转。

### 武陵最典型的例子：天有洪炉

开服武陵篇里，终末地不是单纯送一批物资，而是与本地天师共同验证新的息壤生产方式。

“潮涌汹汹”对白明确展示：本地息壤储量告急，部分天师桩不得不停运，于是侵蚀和天使进入原本受保护区域。

因此管理员部署工业线解决的是一个真实因果链：

**息壤不足 → 防护设施被迫缩减 → 侵蚀扩大 → 城市安全进一步恶化。**

工业不是背景；它是阻止这条链继续恶化的方法。

## 6. 终末地工业：企业、远征组织还是准公共机构？

答案是：目前不能只用一个现代公司概念解释。

它同时拥有：

- O.M.V. 帝江号；
- 跨地区干员队伍；
- 安全、防卫、医疗、情报能力；
- 协议核心与集成工业技术；
- 与各地区政府/组织协商的政治接口；
- 管理员这一具有巨大历史影响力的核心人物。

在武陵，终末地不是来“接管城市”，而是以合作方身份进入庄方宜现有治理体系；在清波寨问题里，佩丽卡也反复强调需要更多帮手而不是制造更多敌人。

所以更准确的理解是：**终末地工业承担文明复兴型组织职能，商业只是其可能的一部分。**

## 7. 管理员：世界认识TA，TA却要重新认识世界

### 7.1 当前状态

管理员从“冷启动/复苏”重新进入现实，对大量过去存在明显记忆缺失。

但其他人并不把TA当新人：

- 四号谷地老员工知道管理员；
- 詹娜记得TA种下源石大树；
- 庄方宜十年前科考站成功后曾第一时间向TA汇报；
- 阿达希尔甚至声称见过管理员过去的落寞与绝望。

### 7.2 序章旧名是游戏内硬证据

墓碑互动明确出现：

凯尔希、特蕾西娅、特雷西斯、Scout、Ace、Outcast、Whitesmith、博卓卡斯替、叶莲娜、克丽斯腾·莱特、雷尔金等。

同时文本写管理员**“记不起这些名字，但悲伤令你胸口微痛”**。

这不是PV彩蛋，而是主线可交互文本。

### 7.3 但精确关系仍不能跳级

文本还说：**“这是无数的历史，也是同一段故事。”**

因此目前只能写：

- 【官】管理员与这些名字代表的旧史存在情感/记忆联系；
- 【官】管理员经历过跨星河的远征与某种死亡/牺牲；
- 【未】这是否对应同一肉身、同一意识连续体、重构人格、长期休眠还是其他机制；
- 【未】泰拉与塔卫二之间精确年代距离。

## 8. 佩丽卡：为什么序章最后一句名字如此重要

冷启动最后，在“唤醒生命”段落出现一句：**“名字……‘佩丽卡’，怎么样？”**

这句话位置极深：它发生在管理员追逐旧史、击败埃尔埃格尼斯、跨过死亡与记忆碎片之后。

所以佩丽卡和管理员的关系绝不只是“现在的副官”。

但目前仍要保留：

- 【未】说话者身份；
- 【未】是否真是佩丽卡第一次被命名；
- 【未】佩丽卡当前个体与那段旧史之间经历了什么。

## 9. 武陵的地方技术：息壤、天师桩、枢壤仪

### 息壤

1.2回忆确认，息壤是十年前科考站群体研究成果。研究者当时已经想象它未来可以支撑：

- 城市；
- 学校；
- 广场；
- 公共生活；
- 新学科和后继研究者。

庄方宜十年后面对这些回忆说“都有的……武陵现在什么都有的”，把科研成果和实际城市建立直接连起来。

### 天师桩

用于维持武陵地区防护/控制；息壤短缺时部分设施停运，侵蚀会进一步进入城市体系。

### 枢壤仪

后续用于对抗裂隙的重要设备。文档明确写过：使用者需要靠近裂隙，异常危险；庄方宜曾对人选请示只批两个字——“我去”。

这也是武陵线最重要的人物主题之一：技术可以改变灾难，但仍有人在替技术承担身体风险。

## 10. 清波寨、武陵城与“同一条江”

武陵不是单一城市共同体。

清波寨寨民拥有自己的生活方式、对外来者的戒心和与武陵城长期积累的旧怨。1.0汤汤已经说明寨民生活压力，1.1冲突进一步爆发。

官方把1.1最终任务命名为“共饮一江水”，正是对这种结构的回应：

**地方群体可以互相不信任，但他们仍共享水系、灾害和未来。**

终末地工业若只和武陵城合作、不处理清波寨的现实问题，就不可能真正稳定地区。

## 11. 应龙特勤队、诀与陈千语

开服阶段已经埋下：

- 陈千语深爱武陵；
- 她与汤汤有旧识；
- 她曾学习剑术，并对过去某次“失败”回避细谈；
- 应龙特勤队正关注北部禁区。

1.4才真正回收：她没有进入精锐道路的重要原因之一，是太容易把救具体的人放在任务逻辑之前。

诀则是另一面：她更接近“把自己当作使命之剑”，但在北部禁区面对旧师、蚀影和同伴时，也不得不承认自己会被私人情感改变。

两人共同回答一个问题：**专业是否意味着把人命从判断里剔除？**

## 12. 代理人、画卷与记忆：必须建立证据防火墙

庄方宜1.2进入的“十年前科考站”不是普通录像。

她自己明确说明：画卷是代理人能力保存的记忆痕迹；后段还会出现地下阵列息壤与旧科考站空间混合。

因此资料库采用三层记录：

1. **被角色确认的历史事实**：科考站存在、同僚牺牲、息壤研究成功；
2. **记忆空间里的情感对话**：现在庄方宜对过去自己说话，具有角色意义，但不等于真的改写十年前；
3. **代理人造成的空间混合/象征**：有情报价值，却不能自动当客观录像。

这和《绝区零》梦境资料采用同一原则。

1.0佩丽卡已经查不到阿达希尔可靠身份；1.2他则明确展示自己知道管理员远超常人的过去。

## 15. 当前世界观主轴

截至1.4，《终末地》最稳的世界观主轴不是“找幕后Boss”，而是：

> 一个失去过去的人，走进自己曾帮助建立的世界；每恢复一座基地、一条水路、一项技术，也就重新碰到一部分自己。

所以建设与记忆不是两条线。

**建设就是管理员过去留下的证据，记忆则决定现在的人要不要继续走同一条路。**
