# 世界底座｜塔卫二、管理员、源石、天使与文明环带

> 游戏：明日方舟：终末地  
> 状态：公测后持续校正  
> 资料校对日期：2026-08-25  
> 剧透等级：世界观剧透

## 1. 为什么不能只把终末地理解成“异星开荒”

玩家确实在塔卫二修路、供电、建产线，但公测序章从第一分钟就把故事指向更古老的历史：管理员追逐失落往事，源石被称为“生命的支柱”，与天使的战争被描述为已经持续百余年；墓碑上出现大量《明日方舟》熟悉名字。

因此塔卫二不是“从零开始的新世界”，而是一个**带着巨大历史遗产继续生存的世界**。

## 2. 塔卫二

【官】当前可探索主舞台。四号谷地与武陵显示不同地区拥有完全不同的生态、侵蚀形式、产业和治理方式。

- 四号谷地：工业基地、源石矿脉、旧大树与裂地者/天使威胁。
- 武陵：傍水文明、潮汐侵蚀、息壤科技、天师桩与地方寨民。
- 北部禁区：武陵十年前重大灾难留下的封禁区域，1.4重新进入主线。

## 3. 文明环带

佩丽卡在武陵开篇对陌生人介绍终末地工业时明确说，其目标是“文明环带的建设和复兴”。这意味着工业不是为了无限生产本身，而是为了让文明能够在危险区域连成带、维持人流与物流。

## 4. 源石

序章直接说“源石是生命的支柱，联系着每一个人”。这一句话说明源石在终末地依旧不是普通矿物。

目前能稳定确认的层面：
- 能源与工业资源；
- 与生命、历史和技术体系存在深层连接；
- 源石大树等特殊形态能承载地区记忆与希望。

仍不能确认的层面：塔卫二源石与旧作源石在所有物理/生物学机制上是否完全一致。

## 5. 天使

【官】序章称“这些遥远的生命永远不知疲倦”，并说对抗已持续百余年。天使会由锚点持续制造，也常出现在超域/裂隙高危地区。

资料库需要避免一个常见错误：**“天使”是游戏内正式敌对类别，不等于宗教意义的天使。**

## 6. 超域与侵蚀

武陵剧情明确指出侵蚀存在地区差异。水系地区会随潮汐变化，北方裂隙则能制造更极端超域现象。

玩法中的净水、抽取污染液、息壤设备、侵蚀核心等都与剧情世界规则相连，因此“地区工业”同时也是抗灾技术。

## 7. 协议核心与建设

投放协议核心是管理员重新控制/建设地区的重要行为。围绕核心建立电力、物流、生产、防卫与据点供应后，终末地工业才能真正改变区域状态。

这也是游戏叙事最独特的一点：很多RPG让NPC在过场里说“城市重建了”，终末地要求玩家亲手把基础设施搭出来。

## 8. 管理员的历史层

序章“冷启动”有几组不能忽略的一手证据：

1. 管理员在类似过去/记忆的场景中推进一场远征。
2. 有声音称管理员“跨过星河，跨过和寰宇深处一样冰冷的死亡”。
3. 有人说管理员“为了我们，为了明天，你牺牲了自我”。
4. 墓碑出现凯尔希、特蕾西娅、特雷西斯、Scout、Ace、Outcast、Whitesmith、博卓卡斯替、叶莲娜、克丽斯腾·莱特、雷尔金等名字。
5. 管理员不记得名字，却感到悲伤。
6. 最后出现“名字……‘佩丽卡’，怎么样？”这一片段。

这些是【官】；但“所以管理员就是X”“所以时间一定是Y年后”不是【官】。

## 9. 息壤：武陵文明的第二条资源线

庄方宜1.2记忆说明，十年前科考站把息壤从研究设想推进到关键成功。团队讨论的不是武器，而是学校、城市、广场、食物和新学科。

因此息壤在叙事中代表一种很明确的东西：**技术突破只有变成人可以生活的环境，才算完成。**
