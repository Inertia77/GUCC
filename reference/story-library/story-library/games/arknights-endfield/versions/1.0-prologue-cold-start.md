# 1.0 序章｜冷启动与复苏：追上往事，重新成为管理员

> 游戏：明日方舟：终末地  
> 版本：1.0 公测  
> 实装状态：已实装  
> 实装日期：2026-01-22  
> 资料校对日期：2026-08-25  
> 剧透等级：全剧透

## 0. 一页看懂

- **表层事件**：管理员在一段高度象征化、疑似记忆/意识空间的远征中前进，击败埃尔埃格尼斯，随后“复苏”进入现在。
- **真正重要**：这不是普通教程。它一次放出源石、天使百年战争、管理员牺牲、跨星河、旧人名、死亡、新生、佩丽卡命名等总主线关键词。
- **最稳妥结论**：管理员拥有比当前塔卫二行动更久远的过去，但现在无法完整访问这些记忆。

## 1. 开端：最终任务开始

任务说明直接写“最终任务开始。管理员来到地面，见到了在那里等待自己的‘她’。”

这句话非常反常：玩家第一次开始游戏，却被称为“最终任务”。说明序章不是时间线起点，而是从某个旧终点切入。

## 2. 源石与天使：世界冲突先于个人记忆

前进时未知声音连续给出：
- 源石是生命支柱；
- 必须阻止污染；
- 远征不能失败；
- 天使是遥远生命，对抗已持续百余年。

这里的顺序很重要：管理员还没想起“自己是谁”，世界已经有一套延续很久的战争。

## 3. “追上往事”

任务目标就叫“追上往事”。沿途花、墓碑、伤员、阵线都像被压缩成记忆标本。

未知声音说“一份遗产，一座墓碑。一个孤独的灵魂不该背负如此重任。而你最终……没有选择放下。”

这为管理员定下第一层人格：过去的TA不是旁观者，而是一个持续承担的人。

## 4. 墓碑：最硬的旧作关联证据

互动文本直接列出：

- 凯尔希、特蕾西娅、特雷西斯；
- Scout、Ace、Outcast、Whitesmith；
- 博卓卡斯替、叶莲娜；
- 克丽斯腾·莱特、雷尔金等。

文本同时强调：管理员**记不起名字，但悲伤令胸口微痛**。

这比PV彩蛋强得多，因为它是可交互主线文本。

### 但不能因此直接下结论

墓碑还说“这是无数的历史，也是同一段故事”，语言故意保留多义性。精确时间线仍是谜。

## 5. 巨塔与“跨过星河”

未知声音描述管理员：

- 跨过星河；
- 跨过冰冷死亡；
- 仍然对生命抱有希望；
- 为“我们”和“明天”牺牲自我。

这让“管理员为什么现在需要复苏”与过去牺牲发生可能关联，但现阶段不能擅自补全过程。

## 6. 埃尔埃格尼斯

深邃呢喃以非常抽象的方式描述文明/角色循环：

“兴起 → 登峰 → 陨落 → 新生 → 沉寂”。

另有：
- “吾曾见，统御者，遗忘自我。”
- “吾曾见，征服者，毙于征途。”
- “吾曾见，拒亡者，一无所有。”

这些称号是否对应具体人物、文明阶段还是更大法则，目前应标【未】。

## 7. 最后的“佩丽卡”

击败埃尔埃格尼斯后出现“唤醒生命”，并听到：“名字……‘佩丽卡’，怎么样？”

这一幕至少证明“佩丽卡”这个名字进入了管理员非常深层的旧记忆。

不能确定：
- 说话者是谁；
- 这是佩丽卡诞生/命名现场还是别的记忆；
- 佩丽卡与管理员跨越了多久。

## 8. 复苏后的叙事意义

真正的玩家主线不是“第一次成为管理员”，而是**重新成为管理员**。世界里有很多人知道TA，TA却要通过别人、遗迹、自己留下的设施重新认识自己。

## 9. 主题

序章的主题不是失忆，而是“责任能否在记忆消失后继续成立”。

如果一个人不记得自己曾做出的承诺，但世界仍由那些承诺塑造，他是否还要负责？整部游戏从这里开始。
