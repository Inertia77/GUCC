# 崩坏：星穹铁道｜世界观与主线总览

> 校对日期：2026-08-24  
> 用途：在读任何版本章之前，先解决“这个世界怎么运转、主角为什么卷进来、故事到底在追什么”。

## 1. 一句话主轴

失去过去的星核载体加入星穹列车，以“开拓”身份穿越一个个被星核、星神命途与文明自身矛盾撕裂的世界；局部主线不断回到同一个问题：**被命运、命途或剧本塑造的人，能否仍然作出属于自己的选择？**

## 2. 世界运行规则

### 星神与命途
星神不是传统意义上全知全能的“人格神”，而是把某种概念贯彻到宇宙尺度的存在。命途既是宇宙力量路径，也是价值与行为结构；个人可以行走某命途而不必政治上效忠对应星神。

### 星核
星核被称为“万界之癌”，可在不同世界诱发完全不同灾难。开拓者体内就有星核，因此既是解决星核的人，也是长期谜团本身。

### 文明不是命途的简单附属
贝洛伯格追随存护却会形成僵化封锁；家族追随同谐也会出现秩序极权；仙舟追随巡猎又必须不断处理曾追求丰饶的历史。故事常用这种错位说明：价值口号不自动保证制度正确。

## 3. 主角 / 玩家身份

开拓者的过去被人为切断。卡芙卡与银狼按艾利欧剧本把星核植入其体内并留在空间站，让列车组发现。此后主角一方面接受“无名客”新身份，另一方面持续被星核猎手提醒：旅途可能早已出现在某个预见中。

因此最稳妥的写法不是“开拓者是自由的”或“开拓者完全被操纵”，而是：**故事不断把有限选项摆在面前，再看主角如何在有限中创造主体性。**

## 4. 主线阶段

1. **空间站**：诞生 / 被发现 / 选择登车。
2. **雅利洛-VI**：第一次独立解决文明级星核灾难，获得存护注视。
3. **仙舟罗浮**：与仙舟结盟，丹恒前世、丰饶与毁灭令使线展开。
4. **匹诺康尼**：自由与秩序、梦境与现实、无名客历史集中爆发。
5. **翁法罗斯**：轮回、记忆、模拟世界、智识权杖与毁灭实验。
6. **二相乐园 / Planarcadia**：欢愉、注意力政治、丰饶遗产、IPC与姬子故乡线。

## 5. 当前剧情位置

截至2026-08-24，当前已实装版本为4.4。4.5在2026-08-26更新，因此任何4.5剧情均属于未来，不应回填为“已发生”。4.x官方定位为横跨一整年的欢愉故事，且舞台后续不只限于二相乐园。

## 6. 长期主题

- 命运与自由：艾利欧剧本、终末预见、占卜与循环都不断缩小选择空间。
- 记忆与人格：三月七、丹恒/丹枫、翁法罗斯、忘归人都在问“记忆改变后还是不是同一个人”。
- 制度与价值：每个世界都展示“好价值如何被制度化成坏结果”。
- 旅行伦理：列车不是殖民者，不负责替每个世界永久治理；它更多是在关键断点帮助当地人重新获得选择。

## 7. 阅读时最容易踩的坑

- 不要把角色所属命途=角色政治立场。
- 不要把“星神注视”写成正式入教。
- 丹恒不是“丹枫完整复活”。
- 翁法罗斯是模拟/数据结构，不等于“里面的人都是假的”。
- 当前4.x仍在进行中，未来版本标题或测试信息不能反向污染已实装史料。
