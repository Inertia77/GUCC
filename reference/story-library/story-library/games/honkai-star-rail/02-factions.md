# 崩坏：星穹铁道｜阵营与组织 v3.1

> 校对：2026-08-26 / 当前版本4.5。  
> 目的：不列百科名单，只记录**组织想解决什么、拥有什么资源、让谁承担代价、最危险的盲点是什么**。

## 1. 星穹列车 / 无名客

### 核心目标
探索、理解、连接被危机切断的世界，并让旅程继续。

### 优势
- 没有固定殖民/治理项目；
- 能和不同文明建立长期关系；
- 成员拥有跨命途经验。

### 风险
危机中的“外来英雄”很容易获得过大话语权。

4.5新增的重要变化是：列车不再总是“别人来找我们帮忙”，而是因为贪饕危机主动进入千星城寻求援助。这证明开拓不是独立主义：**需要别人不等于把主体性一起交出去。**

## 2. 星核猎手

已知成员包括艾利欧、卡芙卡、银狼、刃、流萤等。

核心特征是按艾利欧剧本行动。其最大长期问题仍是：
> 如果未来高度可预测，剧本与自由如何共存？

资料库不提前写死艾利欧能力必然来自终末。

## 3. 星际和平公司 IPC

IPC不是统一人格，而是横跨金融、物流、建设、资产、军事与存护信仰的大型制度。

### 已实装主线案例

**1.4贝洛伯格**：旧债、托帕、行星治理方案。  
问题：成功率更高是否意味着有权接管？

**2.x匹诺康尼**：产权、基石、石心十人与治理谈判。  
问题：公司如何把“资产权利”与当地政治未来连接？

**4.x二相乐园**：真珠同时涉及治理、公司利益与幻月谒者身份。  
问题：管理者和参赛者身份冲突。

**4.5千星城**：列车主动赴IPC重镇寻求关键援助。  
问题首次变成：当你真的需要IPC资源时，怎样谈条件而不把未来所有权一起抵押？

### IPC真正值得持续追踪的四个指标
1. 它提供什么真实能力；
2. 它要求什么对价；
3. 谁拥有谈判权；
4. 合作结束后，当地还能否改变路线。

## 4. 千星城 / Astropolis

4.5把IPC问题从“公司派代表来边缘世界”转成“列车主动进入公司主场”。

官方当前确认千星城拥有新的中心城区、指针塔/空声院等区域，并承载4.5主线与续闻。

当前可以写：
- 【官】这里是4.5关键舞台，与IPC/存护体系高度相关；
- 【官】列车为了二相乐园贪饕危机赴此求援；
- 【未】主线完整交易条件、公司内部不同角色最终立场，等待上线日完整流程复核。

## 5. 仙舟联盟

从追求长生到承受丰饶代价，再形成巡猎丰饶孽物的文明体系。

内部包括六舰、云骑、十王司、持明、狐人等不同制度，不应写成一个无差异“仙舟意志”。

主问题：
- 长生与魔阴；
- 持明轮回与身份；
- 丰饶战争；
- 年轻人是否必须继续继承旧战争。

## 6. 丰饶相关势力 / 现象

药王秘传、步离人、倏忽相关力量不能合成同一个组织。

共同问题是：
> 当“活下去、延长、增殖”本身成为绝对价值，个人选择是否会被生命逻辑吞掉？

4.1–4.3又把丰饶从仙舟历史带进二相乐园的身体改造与刃线。

## 7. 匹诺康尼「家族」

家族把危险忆域工程化为大型共享梦境社会。

优点是真实创造安全与繁荣；问题是信息不透明和强制幸福风险。

星期日把父爱式治理推到极端，但不能代表家族所有成员。

## 8. 流光忆庭 / 记忆相关组织

拥有记忆读取、保存、进入和重构能力。

随着3.x证明记忆能锚定人格乃至文明，其政治重要性显著上升。

风险：保存记忆的人也拥有巨大的筛选、解释与隐私接近权。

## 9. 焚化工 / 大丽花相关线

3.8证明“删除/焚化记忆”同样能够真实改变历史认知。

恢复被烧毁的记忆不是普通回忆，而会触及终末与因果问题。当前仍不能把大丽花的全部目标提前写成可靠盟友逻辑。

## 10. 天才俱乐部

黑塔、阮·梅、螺丝咕姆等拥有极高研究尺度，但伦理与人格差异巨大。

1.6阮·梅尤其证明：
> “我算得比你准”不能替代知情同意。

所以资料库避免使用“天才俱乐部认为……”来概括个体立场。

## 11. 反物质军团 / 毁灭

毁灭不是只会正面爆破：
- 幻胧利用停云身份与丰饶建木；
- 铁墓利用演算/生命数据；
- 归寂利用父亲身份、画作、幻月规则和公众愿力。

一个稳定规律是：**毁灭越危险时，越会先借用目标文明自己的矛盾。**

## 12. 假面愚者 / 欢愉相关群体

花火等角色通过角色扮演、游戏、谎言与观看反应制造欢愉。

但4.x明确证明：
> 欢愉 ≠ 自由。

快乐可以被计分、商业化、强制，甚至成为封印和政治资源。

## 13. 二相乐园 / 幻月体系

### 表层
八名谒者通过愿力争夺接近阿哈权柄的资格。

### 后见
4.2以后确认幻月游戏与贪饕遗蜕封印有关。

### 当前状态
4.4归寂计划被击败，但封印没有恢复；4.5贪饕危机已经正式爆发。

最大制度错误是：很多参与者只把它当竞赛规则，却不断修改一套同时承担宇宙级基础设施功能的系统。

## 14. 翁法罗斯黄金裔 / 泰坦结构

3.0早期把世界未来集中在少数黄金裔与英雄身上；3.7最终将整个文明变成变量。

这是从“英雄替公共承担”向“全民成为历史主体”的制度变化。

## 15. 阵营判断四问

以后任何新组织都先问：

1. 它想解决什么真实问题？
2. 它允许谁参与决定？
3. 它把代价放在谁身上？
4. 当事实不符合目标时，它愿不愿意修改自己？

因此不会得到“IPC=好/坏”“仙舟=好/坏”这种失去研究价值的答案。
