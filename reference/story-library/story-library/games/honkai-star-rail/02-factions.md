# 崩坏：星穹铁道｜阵营与权力关系

> 校对日期：2026-08-24

## 星穹列车 / 无名客

- **公开目标**：沿开拓星轨旅行、连接世界、处理阻断道路的危机。
- **实际关切 / 隐藏议程**：没有统一征服目标；成员各自带着过去，列车更像共同体而非军队。
- **主要资源**：星穹列车、跨星际通行经验、各世界建立的人情与盟约。
- **关键人物**：姬子、瓦尔特、丹恒、三月七、开拓者等。
- **关系**：与仙舟、贝洛伯格等保持友好；与星核猎手既对立又被迫合作。
- **剧情变化**：从空间站临时救援小队逐步变成多个宇宙势力承认的关键变量。

## 星核猎手

- **公开目标**：执行艾利欧剧本，导向其预见的未来。
- **实际关切 / 隐藏议程**：具体终极目标与“最优未来”的代价仍未完全公开。
- **主要资源**：预见剧本、卡芙卡操控、银狼现实编辑、刃不死体、流萤萨姆等。
- **关键人物**：艾利欧、卡芙卡、银狼、刃、流萤。
- **关系**：被多国通缉；却多次主动让列车进入关键世界。
- **剧情变化**：从序章幕后操作者变成越来越明确的“危险合作方”。

## 星际和平公司 IPC

- **公开目标**：以存护名义组织宇宙商业、信用与基础设施。
- **实际关切 / 隐藏议程**：不同部门和石心之间利益并不一致；“投资/拯救”常伴随资产控制。
- **主要资源**：跨星际资本、舰队、合同、技术与信息网络。
- **关键人物**：钻石、砂金、托帕、翡翠、Pearl等。
- **关系**：既与列车合作也争夺世界资产；在匹诺康尼、二相乐园尤其关键。
- **剧情变化**：从背景巨企逐步成为直接塑造世界政治的常驻势力。

## 仙舟联盟

- **公开目标**：追随巡猎、清剿丰饶孽物，维护长生种社会。
- **实际关切 / 隐藏议程**：内部仍要处理长生制度、持明权力、将军问责等矛盾。
- **主要资源**：六大仙舟、云骑军、十王司、太卜司等。
- **关键人物**：景元、飞霄、怀炎、符玄等。
- **关系**：与列车正式建立友好盟约；与丰饶民长期战争。
- **剧情变化**：罗浮危机后从被救援方变成未来宇宙大战的潜在盟友。

## 家族

- **公开目标**：以同谐组织匹诺康尼梦境社会。
- **实际关切 / 隐藏议程**：内部家系对秩序、商业与梦境治理并非一致；星期日路线曾试图以秩序重写同谐。
- **主要资源**：忆质梦境、家系网络、谐乐大典。
- **关键人物**：星期日、知更鸟及各家系代表。
- **关系**：与IPC长期存在产权 / 政治博弈。
- **剧情变化**：匹诺康尼事件后权力结构重新洗牌。

## 天才俱乐部 / 模拟宇宙合作组

- **公开目标**：探索宇宙规律、星神与极端科学问题。
- **实际关切 / 隐藏议程**：天才之间没有统一伦理；研究目标可能比普通文明安全更重要。
- **主要资源**：黑塔空间站、模拟宇宙、天才个人技术。
- **关键人物**：黑塔、螺丝咕姆、阮·梅等。
- **关系**：与列车长期合作，也会把开拓者当实验变量。
- **剧情变化**：翁法罗斯进一步证明其研究直接影响现实世界存亡。

## 反物质军团 / 毁灭势力

- **公开目标**：践行毁灭。
- **实际关切 / 隐藏议程**：不同绝灭大君拥有不同“毁灭美学”，不只是统一军队。
- **主要资源**：军团、令使级力量、文明内部代理人。
- **关键人物**：纳努克、幻胧、铁墓、阿萨特·普拉玛德等。
- **关系**：列车长期核心敌对。
- **剧情变化**：从空间站直接入侵，发展到利用文明制度、模拟世界与古老遗产的复杂毁灭。

## 欢愉阵营 / 假面愚者等

- **公开目标**：践行欢愉；不以稳定政治纲领为必要条件。
- **实际关切 / 隐藏议程**：帮助与破坏可能同时发生，动机常是“这是否有趣”。
- **主要资源**：模因、身份伪装、阿哈相关权能。
- **关键人物**：桑博、花火等，以及二相乐园多方欢愉角色。
- **关系**：可能帮助列车，也可能主动制造不可控局面。
- **剧情变化**：4.x从边缘搅局者跃升为整个世界制度的中心。
