# 崩坏：星穹铁道｜核心人物与人物弧线

这不是角色名册；只收录对主线因果、阵营变化或长期谜团有实质影响的人物。

## 开拓者

- **身份 / 位置**：星核载体、星穹列车无名客。
- **核心欲望**：寻找自身来历，同时保护旅途中建立的关系。
- **核心恐惧 / 矛盾**：被剧本、星核或外部身份定义成工具。
- **关键选择**：每个世界都在“被安排的抵达”中主动选择介入方式。
- **重要关系**：列车组是当前核心家庭；与卡芙卡/星核猎手有复杂前史。
- **当前状态**：4.4二相乐园线中。
- **仍未解释**：星核植入前完整经历、与艾利欧计划的最终位置。

- **仍未解释**：冰封前身份与记忆来源。
