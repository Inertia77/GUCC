## 资料可信度

一手资料优先使用游戏内开拓任务与HoYoLAB官方更新；Fandom等用于任务顺序、历史条目与查漏，理论部分必须另标【推】。

任何“角色自己说的话”都不自动等于客观事实；任何“预告里出现的画面”也不自动等于已经发生的剧情。资料库优先保留不确定性。
