## v3.1这次解决什么

v3已经把2.x、3.x按版本拆开，并深写到4.4；全库审计后仍有四个问题：

1. 1.x还存在 `1.0–1.3`、`1.4–1.6` 两个大合集，没有真正执行“一个正式叙事阶段一份档案”；
2. 4.0–4.3相对原作信息密度仍偏浓缩；
3. 4.5已于2026-08-26正式上线，旧文仍残留“4.5未实装”；
4. Story Library全库需要更严格的时效、来源与自动检查机制。

v3.1因此采用：

> **正文先完成 → 状态/来源/manifest/前端/自动检查通过 → 根索引最后宣告完成。**

## 事实标签

- 【官】游戏内/官方直接确认。
- 【证】多个已实装一手信息可以稳定拼合。
- 【推】当前最合理，但仍可能被后续推翻。
- 【未】作品明确留下、当前没有完整答案。
- 【可能未来】预知/演算分支等尚未发生历史。

角色说出口的话 ≠ 客观事实。  
梦、记忆、画中世界 ≠ 自动等于历史录像。  
后续反转 ≠ 旧版角色当时“其实早知道”。

## 当前长期主线如何递进

**1.x：身份与同意。**  
开拓者被安排起点；丹恒继承丹枫因果；停云身份被盗用；托帕/岁阳/阮·梅分别测试制度、情绪和知识对主体的侵入。

**2.x：自由。**  
匹诺康尼把“为了你好”推成强制幸福；仙舟演武把继承、血统和战争变成身体命题。

**3.x：如果世界本身被设计，自由还有没有意义。**  
翁法罗斯用数千万回归回答：不靠更强救世主，而让整个文明成为变量。

**3.8–4.4：过去也不稳定。**  
记忆可恢复、因果可有限改动、姬子童年被归寂侵入；最终仍以“选择出发”保存主体性。

**4.5：自主并不等于永远不求助。**  
贪饕危机迫使列车进入IPC主场千星城。问题从“拒绝别人替我决定”变成“我真正需要你的资源时，怎样合作而不把未来所有权一起交出去”。
