## 这次 v3 为什么要重做

旧版最大问题不是“有错”，而是**版本颗粒度太粗**：

- 匹诺康尼 2.0–2.3 被压在一篇；
- 仙舟演武 2.4–2.7 被压在一篇；
- 翁法罗斯 3.0–3.7 被压在一篇；
- 3.8「记忆是梦的开场白」甚至没有进入版本档案；
- 4.x虽然已有单版本文件，但很多仍停在梗概层。

v3改成：

> **一个正式主线版本 = 一份可独立查阅的剧情档案。**

每篇尽量回答：
1. 具体发生了什么；
2. 为什么发生；
3. 每个关键人物掌握什么信息；
4. 角色为什么作出这个选择；
5. 后续反转后，旧场景应该怎样重读；
6. 哪些结论已确认，哪些只是推论；
7. 这一章在整部星铁里承担什么主题功能。

## 证据标记

- 【官】游戏内文本、官方公告、官方剧情回顾直接确认。
- 【证】多个已实装文本能够稳定拼合出的结论。
- 【推】有充分依据，但仍可能被后续反转。
- 【未】作品明确抛出、目前还没有完整答案。

**角色说出口的话 ≠ 自动等于客观事实。**  
**梦、记忆、演算、画中世界呈现的画面 ≠ 自动等于历史录像。**  
**后续发生反转 ≠ 旧版人物当时“其实早就知道”。**

## 现在这套库的主线阅读逻辑

星铁表面每年换一个世界，底层其实一直在推进同一组问题：

**1.x：别人给你的身份，你要不要接受？**  
开拓者/星核、丹恒/丹枫、停云/幻胧。

**2.x：如果有人能给你一个更安全幸福的世界，他有权替你决定吗？**  
星期日、家族、IPC、丰饶战争、模因控制。

**3.x：如果世界本身就是被设计和重复的，自由还有意义吗？**  
翁法罗斯三千多万次回归、Lygus、铁墓、记忆与全民变量。

**3.8–4.x：如果过去甚至可以被恢复、改写、画成另一个版本，一个人如何证明自己仍是自己人生的作者？**  
流萤、终末、大丽花、姬子、归寂、画中世界。

这条线比“每个星球独立讲一个故事”更适合长期维护。
