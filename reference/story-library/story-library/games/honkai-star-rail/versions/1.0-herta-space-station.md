## 0. 一页看懂

- **一句话**：星核猎手借反物质军团袭击空间站制造混乱，把一枚「星核」植入失忆的开拓者体内；开拓者由此登上星穹列车，故事真正启动。
- **主冲突**：军团入侵只是表层危机，真正决定长线剧情的是“谁制造/准备了开拓者、为什么让星核进入其身体、艾利欧的剧本究竟要把开拓者送到哪里”。
- **本章最重要的变化**：开拓者从“被留下的容器”变成主动选择同行的无名客。

## 1. 剧情发生前的局势

【官】黑塔空间站由天才俱乐部#83黑塔建立，收藏大量奇物并进行前沿研究。星核被严密封存。
【官】卡芙卡、银狼入侵时以军团袭击作掩护；开拓者在没有正常人生记忆的状态下醒来。
这一章不是单纯的新手村：它同时把反物质军团、星核猎手、天才俱乐部、星穹列车四条宇宙级势力线第一次接在同一事件上。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 卡芙卡与银狼把“人”留在空间站

银狼绕过安保、卡芙卡取得星核并将其植入开拓者。她们没有带走开拓者，而是按艾利欧的剧本把人留在即将被列车组发现的位置。这说明“被列车收留”本身就是计划的一环，而非偶然救援。
### 2. 丹恒与三月七发现开拓者

两名无名客在撤离与救援途中遇见开拓者。开拓者几乎没有可依赖的身份信息，只能一边应付军团、一边根据现场人物的反应确认世界。叙事用这种失忆视角让玩家与主角同步学习宇宙规则。
### 3. 救援阿兰并进入主控舱段

开拓者很快卷入空间站防卫。艾丝妲承担组织撤离和维持站务的责任；阿兰作为防卫科负责人在受伤后仍坚持职责。空间站在黑塔本人并不常驻的情况下，依靠一套研究者与管理者体系运转。
### 4. 末日兽袭击与星核反应

末日兽的攻击逼出开拓者体内的星核力量。危急中，开拓者感受到毁灭星神纳努克的注视，第一次证明其身体并非普通“容器”。随后瓦尔特压制/封锁星核失控，使危机暂时稳定。
### 5. 黑塔把开拓者当成研究对象，也承认其价值

黑塔对星核载体表现出典型的研究兴趣，并让开拓者接触模拟宇宙。此后开拓者不仅是列车成员，也成为天才们观察星神、命途与宇宙现象的重要变量。
### 6. 开拓者选择登上星穹列车

在留在空间站与随列车旅行之间，叙事最终把主角推向“主动选择开拓”。这一选择把被设计的出生与之后自己作出的选择区分开：来历可能属于剧本，但旅途开始由本人承担。

## 3. 主要人物弧线

### 开拓者

从“没有过去、身体里有星核”的被动对象开始；关键选择是接受列车组、加入无名客。以后每个世界都在反复追问：如果起点是别人写好的，人还能不能写出自己的答案？
### 卡芙卡

对开拓者明显知道得远比她当场说明的多；她既执行艾利欧剧本，也保留一种近似引导者/监护者的关系。
### 三月七

以热情与好奇把开拓者拉入日常，是“失忆者遇见另一个失忆者”的镜像；她自己的过去后来成为长线核心。
### 丹恒

最初谨慎而克制，承担可靠同伴位置；其被仙舟放逐的过去尚未在此章展开。

## 4. 本章新增 / 修正的世界观

- **星核**：能引发灾难、扭曲世界并与命途力量产生复杂关系；开拓者能将星核留在体内而不立即毁灭，是长期异常。
- **星神注视**：极端意志与行为可触及命途并得到星神注视；开拓者在末日兽危机中第一次与“毁灭”发生直接感应。
- **模拟宇宙**：黑塔等天才用于模拟星神与宇宙规律的实验系统，后来持续扩展为理解星神历史的重要窗口。

## 5. 伏笔、回收与仍未解释的问题

- **开拓者的制造与过去**：已确认星核猎手知道其身份与用途，但“成为星核载体前的完整经历”仍未公开。
- **艾利欧剧本**：卡芙卡与银狼严格按预见推进事件；剧本能看到什么、能否改变、为何需要开拓者，仍是总主线。
- **纳努克为何注视开拓者**：可以确认发生过注视，但不能据此直接断言开拓者与毁灭阵营存在从属关系。

## 6. 主题与叙事作用

空间站篇把“被安排的人生”和“自己选择出发”放在同一章里。它的叙事价值不在最终打赢末日兽，而在开拓者第一次决定：即便不知道过去，也可以先成为一个正在前往未来的人。
