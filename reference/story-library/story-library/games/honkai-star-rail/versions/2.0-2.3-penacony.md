# 2.0–2.3｜匹诺康尼总览 v3

> 本文件保留为兼容总览。详细剧情请进入2.0、2.1、2.2、2.3四份独立档案。

## 一句话

匹诺康尼的完整结构不是“梦境里出了杀人案”，而是：

> **一个把“绝对安全幸福”作为政治合法性的社会，被多个外部阵营逼着承认：真正的自由包括醒来的权利。**

## 四个版本各自负责什么

### 2.0｜先让安全神话破裂
流萤、知更鸟梦中“死亡”，证明家族宣传不完整。
流萤的普通生活愿望让“梦”先具有真实价值，避免故事变成简单“现实一定比梦高贵”。

→ `2.0-if-one-dreams-at-midnight.md`

### 2.1｜让阴谋公开化
砂金把自己、基石和黄泉力量都押进计划，逼家族无法继续封闭信息。
流萤=萨姆揭露。

→ `2.1-cat-among-pigeons.md`

### 2.2｜把问题从案件升级成制度
流梦礁、米沙/米哈伊尔、钟表匠历史回收。
星期日用秩序构造强制幸福。
黑天鹅通过“米沙不该出现在现实”识破假胜利。

→ `2.2-then-wake-to-weep.md`

### 2.3｜回答“打完Boss之后怎么办”
IPC债权、家族治理、梦境未来继续谈判。
自由不是推翻星期日后自动完成的状态。

→ `2.3-farewell-penacony.md`

## 核心人物对照

### 流萤
自由 = 能拥有不被兵器身份/熵失症定义的普通时间。

### 星期日
自由的反面不是痛苦，而是“有人替你永久决定什么对你最好”。

### 知更鸟
帮助弱者与尊重主体必须同时成立。

### 砂金
自由被资本化：他最擅长利用规则，却也最习惯把自己当筹码。

### 黑天鹅
谁保存记忆，谁就拥有极强信息权力。

## 3.8为什么必须反过来更新匹诺康尼

3.8确认：
- 有关键记忆被烧毁；
- 流萤过去与AR-214有更多现实锚点；
- 知更鸟在2.0曾主动调查；
- “第三次死亡”并未被2.3烟火完全解释；
- 终末力量可以造成有限过去改变。

所以本总览以3.8后见知识维护，但独立2.x档案会明确区分“当时角色知道什么”。

## 最终主题

**好的梦不是问题，不能醒才是。**
