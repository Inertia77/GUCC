# 3.x｜翁法罗斯总览 v3

> 历史兼容文件名保留 `3.0-3.7-amphoreus.md`，但本总览已经纳入3.8在翁法罗斯终局之后对“记忆/终末”的直接延伸。  
> 逐版本细节请阅读3.0–3.8独立档案。

## 一句话

翁法罗斯篇用三千多万次世界回归把“命运是否能改变”推到最极端：

> **如果系统已经见过几乎所有英雄选择，真正的新变量还能从哪里来？**

最终答案不是“出现一个系统没算到的超级英雄”，而是：
**整个文明都成为行动者。**

## 第一阶段｜3.0–3.3：先认真相信神话

### 3.0
黄金裔、十二泰坦、火种、逐火、再创世。
三月七失联，开拓者获得记忆力量。

### 3.1
万敌结束旧王朝并继承纷争；那刻夏用理性拆解神话。
逐火9/12。

### 3.2
那刻夏完成证明并走向终点。
遐蝶成为死亡半神。
只剩天空/负世。

### 3.3
逐火11/12。
城市更接近毁灭，英雄连续坠落。

这一阶段必须保留居民视角：
他们不是“NPC不知道自己在模拟里”，而是在当时可知世界里做真实选择。

## 第二阶段｜3.4：撕开系统

确认：
- 翁法罗斯与权杖δ-me13演算/实验有关；
- 永恒回归达到三千多万次规模；
- 黑潮/毁灭/铁墓有系统层解释；
- “照预言集齐火种”本身可能就是被建模过的路线。

真正目标从完成任务表，变成制造旧循环没有的变量。

## 第三阶段｜3.5：回到英雄未死之前

开拓者回到更早逐火时代。
海瑟音、刻律德菈等从碑文变成活人。
Lygus的优势不是只会打，而是拥有大量循环历史去预测“英雄通常怎么选”。

## 第四阶段｜3.6：列车三人重新成为完整小队

三月七：
原来最先进入翁法罗斯，以记忆保护同伴。

丹恒：
返回世界，面对丹枫/高云五骁/战争混合记忆，成为大地半神腾荒。

开拓者：
进入大墓，看见三千万昔涟与Demiurge结构。

三人共同拒绝“只保留成功记忆”的永夜方案。
Era Nova完成。

## 第五阶段｜3.7：取消“救世主制度”

再创世后一千年，文明已经能自己发展。
卡斯兰娜不再独自当铁墓棺椁。
整个翁法罗斯人口响应开拓预言，成为实验从未拥有的大变量。

开拓者真正进入记忆命途，保护宇宙生命记忆。
铁墓被锚定击败，实验终止。

## 3.8为什么仍然属于3.x的思想尾声

地点回到匹诺康尼，但规则来自翁法罗斯之后的新认知：
- 记忆可以被烧毁和恢复；
- 过去有现实锚点；
- 终末能有限改动过去；
- “旧版本”不能因为结果改变就被当成没发生。

3.8是把翁法罗斯学到的宇宙规则重新应用于旧伤。

## 翁法罗斯最重要的反误读

### 错：原来全是模拟，所以牺牲没意义
对：演算承载不取消主体经验和外部因果。

### 错：三千万次都一样
对：差异和记忆累积恰恰是最终破局条件。

### 错：白厄/卡斯兰娜就是唯一救世主
对：终局专门把“一个人承担世界”改成“全体文明成为变量”。

### 错：再创世成功=3.6已经大结局
对：100%只是满足实验条件，铁墓才是真正外层危机。

## 最终主题

**自由不是没有因果，而是因果知道你之后，仍然有人做出新的关系与新的选择。**
