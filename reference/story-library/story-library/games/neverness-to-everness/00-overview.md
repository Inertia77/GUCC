# 异环 / Neverness to Everness｜世界观与主线总览

> 校对日期：2026-08-25  
> 剧透：截至 1.3「雾中朔望星回」全剧透

## 1. 一句话主轴

《异环》的主线不是“现代都市里随机打怪”，而是**一群处理超自然异常的人，如何在一座已经把异常日常化、产业化、制度化的城市里，面对那些会利用规则、记忆、时间与欲望反过来利用人的异象**。

玩家作为首位“无证上岗”的异象猎人进入海特洛，加入经营拮据却专接民间异象委托的「伊波恩」古董店。早期看似是照相馆、恋爱、拍卖会、讨债等都市单元剧，实际上从 1.0 后半开始，这些事件逐步被串到「红字」组织、时间类异象以及伊波恩店主浔的过去与能力上；1.1 将冲突推进到向阳岛与游梦洄廊，1.3 则在「雾巢游戏」中完成红字篇第一阶段终局。

## 2. 世界怎么运转

### 海特洛

【官】故事从海特洛市启篇。这里不是“异常突然降临的末日都市”，而是一个已经形成异常管理、民间委托、异象商品、异能者就业、交通与娱乐产业的超自然城市。

因此理解《异环》的关键不是问“为什么大家见到怪事不惊讶”，而是：**异常本身已经成为社会结构的一部分。**

### 异象

异象可以表现为物件、空间、规则、现象、生命体，甚至把人的执念、记忆与欲望固化为可重复运行的“世界”。

1.0 的「第一枝」「恒今时」、1.1 的「游梦洄廊」、1.2 的「九百九十九夜」、1.3 的「雾巢」说明异象并不只是怪物；真正危险之处常在于它们拥有自己的规则，而人会主动利用这些规则。

### 异象猎人 / E.T.D

【官】玩家以异象猎人身份行动；E.T.D 各队代表官方高危涉异处理能力。1.1 起，安魂曲、卡厄斯等人物让“民间伊波恩”与“官方处置体系”的差异更清晰；1.3 两边真正形成联合行动。

### 伊波恩古董店

表面是古董店，实际是玩家最重要的家庭与委托中枢。

- **浔**：店主，平时不靠谱，涉及红字与时间类异象时却掌握远超常人的情报与能力。
- **娜娜莉**：自封“柯林斯家族一代目”的伊波恩台柱；1.1 是红字计划的直接受害者之一。
- **早雾**：伊波恩核心成员，鬼郎丸的持有者。
- **塔吉多**：歧骸与“最佳修理师”，承担大量伊波恩日常喜剧。
- **鉴定师**：从外来者逐渐变成伊波恩真正的行动核心。

## 3. 第一条长线：红字

### 红字不是一次性反派组织

1.0 拍卖会事件已经出现红字式布局：伊波恩被引入局，时间/预知相关异象「第一枝」遭夺取；随后「讨债人 / 红字的研究」中，残虹伪装身份靠近「恒今时」持有者蕾妮，再次围绕时间类异象行动。

1.1 中，红字继续通过达芙蒂尔、向阳岛与游梦洄廊，把伊波恩最在乎的人直接拉入局中。到 1.3 才揭示更完整逻辑：前三次事件并不是彼此独立的坏事，而是在持续逼迫浔离开安全位置、亲自进入可夺取能力的「雾巢」。

### T 女士 / 伊南娜

【证】1.3 将 T 女士的核心目标明确为延续生命、获得更接近“不老不死”的能力；浔的时间类异能正是她长期瞄准的目标。雾巢的胜者可以从失败者那里夺走包括异能在内的“东西”，此前取得的时间类异象由此成为最终布局的一部分。

### 残虹

【官】残虹是伊南娜的养女与侍卫，是红字最危险的执行者之一，持有「惑乱之眼」，能够嗅探情绪、引发幻觉、制造令人沉溺的幻境。

她不是“1.3 突然洗白”。1.0 她参与恒今时事件；1.3 她对伊南娜出手，也仍需为自己的行为承担法律后果。终局应理解为**她第一次真正决定自己的刀砍向谁**，而不是一句话抹掉过去。

## 4. 发布顺序不等于世界内顺序

这是目前最容易读错的地方。

发布顺序：

```text
1.0 → 1.1「游梦洄廊」→ 1.2「勇者斗赤龙」→ 1.3「雾巢游戏」
```

但官方在 1.2 更新公告中明确说明：**1.2 采用倒叙结构，发生在“红字事件”尘埃落定、众人重返平静生活之后。**

因此更合理的世界内时间线是：

```text
1.0 红字初现
→ 1.1 游梦洄廊 / 娜娜莉受创
→ 1.3 雾巢游戏 / 红字终局
→ 若干周后
→ 1.2 勇者斗赤龙 / 九百九十九夜
```

## 5. 当前已实装主线阶段

### 1.0：从都市日常到红字现身

- 「不虞亦先兆」：鉴定师进入海特洛并踏上异象猎人道路。
- 「生意经与招财宝」：正式进入伊波恩生活与民间异象委托。
- 「从捏造开始的恋爱大作战」：以塔吉多恋爱事件展示异象商品如何渗入普通生活。
- 「成交？成交！」：拍卖会、预知异象「第一枝」、时间停止与红字布局第一次升级。
- 「讨债人 / 红字的研究」：蕾妮、恒今时、残虹登场，红字从幕后线索变成明确敌对势力。

### 1.1：游梦洄廊

娜娜莉因师父达芙蒂尔重新站到红字一侧而低落；伊波恩前往向阳岛散心，却被红字利用为进入游梦洄廊的引路人。娜娜莉被异象卷走，鉴定师在洄廊中看到她获得粉色老虎异能并加入伊波恩的过去。最终虽然将她带回现实，却只保住不完整的意识/灵魂，娜娜莉陷入昏睡。

这不是单纯“救人失败”，而是红字第一次真正破坏伊波恩的家庭结构。

### 1.3：雾巢游戏——红字篇终局

时间线接回 1.1 后。浔与艾尔菲德揭开反击方案，达芙蒂尔的“背叛”被重新解释为高风险卧底；伊波恩与 E.T.D 六队进入红字基地与雾巢。

雾巢是规则型大逃杀异象空间。红字想利用其规则夺取浔的能力。T 女士/伊南娜进入最终战后，零号异象的介入打破原本极端不利的局面，残虹最终反叛伊南娜。事件后红字核心遭清算，残虹被捕服刑，娜娜莉苏醒。

### 1.2：勇者斗赤龙——红字终局后的恢复期

红字事件结束数周后，薄荷搬入新居并邀请伙伴聚会；娜娜莉刚恢复仍被限制外出，真红因此加入鉴定师与薄荷的聚会。众人启动异象制品桌游「九百九十九夜」，直接被拉入沃伦大陆。

桌游按角色内在自我认知分配职业；真红被赋予“普通人”，反而直接触及她长期想摆脱自身异能、做普通人的愿望。奇幻冒险最终把她的“独行”从性格标签转化成自我认同问题。

## 6. 当前最重要的主题

### 正常与异常

“一切正常，就是异常”不是只用于宣传。故事不断追问：当异常已经变成城市基础设施、商品和职业时，所谓“普通人”到底是什么？

### 时间与无法回头

第一枝、恒今时、游梦洄廊、浔的能力与雾巢都围绕“能不能让过去停止/重来”。1.1 的主题“时间应当向前流动，而非束缚于过往”正是红字篇的核心反面：红字不断把时间当资源、能力和交易对象。

### 家庭不等于血缘

伊波恩的吸引力来自一种很传统的同住、同吃、一起收拾烂摊子的家庭结构。1.1 的痛苦之所以有效，就是因为红字不是只制造城市危机，而是直接打进这个家庭。

### 欲望会成为规则漏洞

拍卖会对第一枝的贪欲、蕾妮对恒今时的依赖、游梦洄廊对过去的执念、伊南娜对永生的追求，都说明异象常常抓住人已经存在的欲望并把它规则化。
