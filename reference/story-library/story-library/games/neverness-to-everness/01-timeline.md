# B. 1.0：伊波恩家庭与红字长线同时建立

这是红字篇的情感前置：**必须先证明伊波恩是“家”，后续对娜娜莉的攻击才不是普通任务失败。**

# C. 1.1：游梦洄廊

## C1. 达芙蒂尔旧身份击中娜娜莉
娜娜莉失去的不是普通队友信任，而是：**师父似乎主动重新回到会伤害大家的一边。** 这直接导致伊波恩决定带她去向阳岛散心。

## C2. 向阳岛
【官】1.1把向阳岛与“异象福利院”历史连接。当前消费化景区之下埋着异常儿童 / 异能者的照护与管理史。

## C3. 娜娜莉失踪
- 娜娜莉被诱离现实队伍。
- 线索指向「游梦洄廊」。
- 鉴定师进入规则空间追寻她。

## C4. 过去成为牢笼
洄廊将记忆、愿望与执念构造成可停留的空间。被困者真正面对的不是“这是真是假”，而是：**为什么我必须离开一个比现实更愿意接纳我的地方？**

## C5. 达芙蒂尔切割权能

### 1.1当时视角
她的行为几乎进一步坐实“再次投敌”。

### 客观后果
娜娜莉虽然被带回现实，却未完整恢复，并陷入昏睡。

### 1.3后视角
达芙蒂尔属于卧底行动。**动机被重解释；后果没有消失。**

# D. 1.3：雾巢游戏

## D1. 时间线回到1.1之后
1.3不是接在1.2“桌游聚会”后面，而是回到游梦洄廊脱险后的危机状态。

## D2. 反击计划公开
- 浔与艾尔菲德早已准备反击红字。
- 达芙蒂尔的回归属于卧底。
- 伊波恩与E.T.D六队共同进入行动。

## D3. 雾巢规则
【证】雾巢是大型规则型异象游戏空间。
- 参与者受规则约束；
- 胜者可从失败者处取得“东西”；
- “东西”可以指向异能；
- 红字试图利用规则让浔失去原本优势。

## D4. 伊南娜真正目标
【证】T女士 / 伊南娜追求延续生命 / 更接近永生的状态。浔的时间 / 不老相关能力是其长期目标。

```text
第一枝
+ 恒今时
+ 对伊波恩持续施压
+ 雾巢规则
=
逼浔进入能力可被夺取的结算环境
```

## D5. 第一枝坏未来
第一枝显示极端失败路线：
- 多数参与者可能死亡；
- 即使浔之后继续行动，也未必能挽回；
- 鉴定师在极长时间尺度上的状态异常。

必须标记：**【可能未来】而非已发生历史。**

## D6. 零号异象介入
主角方的布局让他们到达终局，但规则优势仍偏向伊南娜。真正打破“几乎按她设计好的结算”的变量是零号异象。

## D7. 残虹反叛
残虹对伊南娜出手，意义是摆脱控制、获得主体性、不再只作为组织武器行动。但1.0加害行为仍成立。

## D8. 司法与恢复
- 残虹被捕并服刑。
- 涉案人员按责任进入抓捕 / 矫正等处理。
- 娜娜莉苏醒。
- 伊波恩从“持续被夺走”进入恢复。

# E. 1.2：勇者斗赤龙（世界内在1.3之后）

## E1. 数周恢复期
红字事件结束后，薄荷搬家并邀请朋友。“去朋友新家玩”在经历1.1–1.3以后本身就是剧情结果。

## E2. 九百九十九夜
DSD异象制品把参与者送入沃伦大陆。这里显示异象商品化已经发展到：**企业可以把完整规则世界包装成消费娱乐。**

## E3. 真红的“普通人”职业
职业分配映射参与者自我定义。真红获得“普通人”，触及她最深的愿望之一：如果没有异能，自己是否能过真正普通的生活？

## E4. 从独行到允许别人参与
冒险不断制造必须依赖队伍的情境。真红真正接受的不是“我其实很正常”，而是：**即使特殊，也仍然可以拥有普通关系。**
