# 1. 伊波恩古董店

## 定位
【官】接取民间异象委托维持周转的古董店。

## 核心资源
- 对普通居民生活非常贴近；
- 能快速接触“小到官方未必优先处理、但对当事人极其严重”的异常；
- 浔拥有特殊情报与时间相关能力；
- 鉴定师能异常深入规则型异象；
- 团队成员之间形成极强非血缘家庭关系。

## 核心限制
- 不是官方机构；
- 没有完整司法权限；
- 情报与正规武装能力有限；
- 面对红字级组织时单独行动成本极高。

## 核心成员
浔、鉴定师、娜娜莉、早雾、塔吉多，以及长期围绕伊波恩生活的伙伴。

## 组织弧线
```text
民间小店
→ 能解决都市异象委托
→ 被红字纳入长期博弈
→ 家庭成员直接成为攻击目标
→ 与E.T.D联合反攻
→ 红字终局后恢复日常
```

# 2. E.T.D / 官方异象管理体系

## 定位
负责更高危、制度化的涉异处置。

## 与伊波恩不是上下级关系

| 伊波恩擅长 | E.T.D擅长 |
|---|---|
| 民间委托 | 高危事件 |
| 灵活调查 | 正规调查 |
| 特殊个人关系 | 组织级情报 |
| 快速进入日常现场 | 武力与协同 |
| 规则异象特殊变量 | 司法收尾 |

1.3证明：红字这种规模的威胁需要两套体系共同工作。

## 重要人物

### 艾尔菲德
E.T.D高层 / 局长级核心，与浔共同掌握红字长期情报并参与反击布局。

### 安魂曲
E.T.D四队王牌，1.1版本重点人物之一。

### 卡厄斯
E.T.D六队核心执行者。1.3联合突入和后续抓捕使其“使命必达”的官方执行身份真正进入主线核心。

### 达芙蒂尔
不能简单归成“E.T.D角色”或“红字角色”。其旧身份、伊波恩关系与卧底任务横跨多个体系。

# 3. 红字

## 当前定位
1.0–1.3最重要的持续性敌对组织。

## 已证明能力
- 高价值异象情报；
- 拍卖 / 灰色交易渗透；
- 长期伪装；
- 情绪 / 记忆 / 幻觉操纵；
- 规则型异象利用；
- 绑架与直接施压；
- 能力夺取布局。

## 行动链

### 第一枝
目标：未来 / 时间类高价值异象。

### 恒今时
继续围绕停滞、永恒与时间能力。

### 游梦洄廊
从“拿东西”升级成“伤害浔周围的人”。

### 雾巢
把真正目标浔本人拖进能力可被夺取的规则空间。

## 核心人物

### 伊南娜 / T女士
红字核心首脑。【证】追求延续生命 / 更接近永生的能力。

### 残虹
伊南娜养女与侍卫；真实参与过加害行为。1.3反叛伊南娜之后仍进入司法处理。

### 达芙蒂尔
具有红字过去，但1.3证实其再度进入红字属于反击计划中的卧底行动。

## 红字是否彻底消失
【未】。“核心计划失败”不等于所有成员、资产、情报网络与受益人同时消失。

# 4. DSD 与异象商业体系

## 已知现象
- 随心泥可以作为消费玩具；
- 九百九十九夜可以作为桌游产品；
- 产品可承载真实异象规则。

## 重要含义
海特洛已进入“怎样规模化、商品化、娱乐化异象”的阶段。

## 长期问题
- 谁负责安全评级？
- 谁承担事故责任？
- 商品说明能否完整描述异象规则？
- 企业掌握规则到什么程度？
- 消费者是否真正理解风险？

# 5. 高端异象拍卖 / 收藏市场

拍卖会证明：
- 异象具有价格；
- 高危能力可以进入私人收藏逻辑；
- 有钱并不意味着理解规则；
- 安保本身也依赖异象，因此可被更懂规则的人反向利用。

第一枝事件显示：**当异常被当作资产，市场会把“想拥有它的人”与“真正懂它的人”同时吸引到一个地方。**

# 6. 向阳岛与异象福利院

【官/证】1.1把向阳岛与“异象福利院”历史连接。它提示海特洛存在长期的异常儿童 / 异能者照护体系。

但“福利”与“管理”边界仍未完整公开：
- 是照护？
- 是收容？
- 是训练？
- 是否存在强制性？
- 哪些角色曾与这一体系发生关系？

目前不能把所有问题提前写成阴谋论。

# 7. 沃伦大陆 / 九百九十九夜

不是现实政治组织，但属于必须单列的“规则系统”。

## 规则意义
- 参与者进入完整异象世界；
- 职业分配映射自我认知；
- 世界任务会迫使参与者以新角色理解自己。

## 商业意义
随心泥只证明“异象能做玩具”；九百九十九夜进一步证明“复杂规则世界也能被包装成消费产品”。

# 8. 雾巢 / 雾柩

## 雾巢
大型规则游戏空间。

## 雾柩
处于普通参与者之上的高位力量层。

## 红字与它们的关系
红字至少足够熟悉规则，可以把雾巢设计成对浔极其不利的能力夺取场。

但仍不能写死：
- 雾巢由红字创造；
- 雾柩属于红字；
- 伊南娜完全控制雾柩。

# 9. 零号异象

必须单独列出，因为其1.3介入直接改变终局。

当前只可确认：
- 力量层级足以影响雾巢终局；
- 不属于伊波恩 / E.T.D可常规调度资源；
- 介入打破了伊南娜原本极有利的规则结算。

不能写死：
- 它“站在主角阵营”；
- 它“专门保护鉴定师”；
- 它与雾柩天然敌对。

# 10. 阵营研究禁区

1. 不要把角色所在组织等同角色全部动机。
2. 不要把一次合作等同长期同盟。
3. 不要把高位异象强行塞进人类阵营表。
