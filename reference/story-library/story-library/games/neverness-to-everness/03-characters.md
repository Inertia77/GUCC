# 1. 鉴定师

## 当前身份
【官】首位“无证上岗”的异象猎人，加入伊波恩。

## 1.0
最重要的变化不是获得战力，而是获得社会位置：
```text
外来者
→ 有住处
→ 有手机
→ 有同伴
→ 有第一份委托
→ 能站进伊波恩全家福
```

## 规则异象中的异常性
【证】鉴定师在多个规则空间中具有极强介入能力，尤其游梦洄廊与雾巢相关事件。

这不能直接推出“鉴定师比所有人战力更高”，只能说明其与异象规则的关系本身具有特殊性。

## 第一枝可能未来
【可能未来】1.3相关未来信息暗示，即使经过极长时间，鉴定师仍可能保持异常持续存在。

不能写成：
- 已确认永生；
- 已确认不是人类；
- 已确认零号异象化身。

## 人物主题
鉴定师一直在做的事是：**进入别人已经被规则困住的地方，并帮助对方重新获得选择。**

# 2. 浔

## 表层
爱喝酒、爱占便宜、经常表现得不靠谱。

## 真正位置
从第一枝开始逐步证明：
- 她掌握的信息远超普通店主；
- 对时间异常有特殊应对；
- 与艾尔菲德共同掌握红字长期威胁；
- 1.3成为伊南娜真正能力夺取目标。

## 为什么不“早点解决红字”
错误问题是“既然浔这么强，为什么不直接把红字秒了？”

更合理的读法：
- 能力有规则边界；
- 预见不等于能随意改写；
- 对方不断借异象规则限制她；
- 直接行动可能触发更坏未来；
- 身边的人会成为代价。

## 人物核心
```text
继续留在规则之外
→ 身边的人持续被攻击

亲自入局
→ 自己的能力可能被夺取
```

# 3. 娜娜莉·柯林斯

## 1.0：家庭气氛制造者
她让伊波恩拥有夸张、吵闹、孩子气但稳定的生活感。

## 1.1：为什么达芙蒂尔的“背叛”会击穿她
达芙蒂尔不仅是认识的人，而是：
- 师父；
- 成长支点；
- “强大意味着什么”的重要定义者。

因此她失去的是一种对世界的基础信任。

## 游梦洄廊
鉴定师通过记忆层重新理解：
- 她并非一直是今天的“家族一代目”；
- 粉色老虎相关异能 / 伙伴是成长节点；
- 达芙蒂尔师徒关系深刻影响其人格；
- 加入伊波恩后，她才获得稳定的家庭共同体。

## 1.3
娜娜莉苏醒。这不是“自动痊愈”，而是红字篇终于从失去转入恢复。

## 尚未解决
【未】她与达芙蒂尔的关系怎样真正修复，仍不能用一句“误会解除”概括。

# 4. 达芙蒂尔

## 1.1当时
一切证据都在让她看起来再次站回红字：
- 旧身份已经暴露；
- 她离开伊波恩一侧；
- 她在洄廊终局切割权能；
- 娜娜莉未完整恢复。

角色不信任她完全合理。

## 1.3反转
【证】其再次进入红字属于浔 / 艾尔菲德反击计划中的卧底。

## v3必须避免的误读
错误：
> “所以1.1她其实什么都没做错。”

正确：
> **动机被重解释，不等于行动效果被删除。**

她的人物弧线不是“清白证明”，而是用极高风险、接受被最亲近的人误解的方式偿还旧组织关系留下的债。

# 5. 伊南娜 / T女士

## 身份
红字核心首脑，残虹养母。

## 欲望
【证】追求延续生命 / 更接近永生。

## 她真正擅长的不是正面战斗
```text
找到目标欲望 / 弱点
→ 找到对应异象规则
→ 把目标放进自己有利的规则
→ 让“夺取”变成结算结果
```

## 与四个核心异象的关系
- 第一枝：未来 / 时间
- 恒今时：停滞 / 永恒
- 游梦洄廊：过去 / 执念
- 雾巢：胜者夺取败者之物 / 异能

## 主题位置
她代表：**把时间私有化。**

# 6. 残虹

## 1.0
必须保留事实：
- 她真实参与红字行动；
- 操纵目标；
- 协助争夺恒今时。

## 为什么她会一直服从伊南娜
目前可理解为长期养育、控制、组织身份与情感结构共同结果，但不能把所有具体心理细节写死。

## 1.3
她最终对伊南娜出手，意义是第一次真正决定自己的行动方向。

## 司法结果
她被捕并服刑。这是角色弧线非常重要的一部分：
```text
成为自己
≠
过去无罪
```

# 7. 真红

## 官方定位
【官】任务中极其可靠，习惯单独进入高危区域，人际交往相对笨拙。

## 1.2：普通人职业
九百九十九夜的职业分配直接触及她的深层愿望：如果没有异能，自己是否就能成为普通人？

## “独行”的双重含义
- 保护别人；
- 避免别人真正接近自己。

## 角色成长
不是突然变成外向角色，而是接受：**特殊并不剥夺自己拥有普通关系的资格。**

## 仍未解
【未】“另一个自己”的本体性质。

# 8. 蕾妮

恒今时事件核心人物。

她的重要性在于证明：异象危险不一定来自外部强迫，人也可能因为不愿放弃某种状态而主动依赖规则。因此她与恒今时构成红字时间主题中最“人”的一层。

# 9. 薄荷

## 序章
把鉴定师从官方空间带入伊波恩与城市生活。

## 1.2
搬新家、邀请朋友，触发九百九十九夜。

她的叙事作用非常稳定：**让主线人物重新回到普通生活。**

# 10. 伊洛伊

- 1.1承担向阳岛引导；
- 1.2进入沃伦大陆队伍。

她把现实度假区和奇幻规则世界两种叙事空间连接起来。

# 11. 安魂曲

【官】E.T.D四队王牌。

v3重点不是补“战力介绍”，而是理解其制度位置：
- 专业官方涉异力量；
- 与伊波恩民间模式形成对照；
- 即使足够专业，也不意味着能免疫异常对情绪与舆论的影响。

# 12. 卡厄斯

E.T.D六队核心执行者。

1.3使其定位从角色背景变成真正剧情职责：官方体系负责的不只是打赢终局，也包括抓捕、押送和让“危机结束”真正进入法律结果。

# 13. 艾尔菲德

E.T.D高层 / 局长级核心。

与浔共同布局说明：
- 红字威胁早已超过普通委托；
- 反击并非1.3临时起意；
- 达芙蒂尔卧底需要组织级保护与情报条件。

【未】她与浔更早的合作历史仍值得追踪。

# 14. 伊波恩其他家庭成员

## 早雾
承担稳定日常与战斗成员位置。价值在于让伊波恩不是“只有主线焦点角色才存在”的队伍。

## 塔吉多
歧骸、修理师、恋爱大作战主角。他证明“异常居民”在海特洛拥有真正生活欲望，不只是世界观展示物。

# 15. 角色考据规则

1. 反转只重解释动机，不删除行为。
2. 幻觉 / 梦境中的角色表现，不自动当成客观现实性格证据。
3. 角色资料里的宣传语气与主线行动要分开。
4. “被控制”与“没有责任”不是同义词。
5. 人物成长优先看选择变化，不只看是否换阵营。
