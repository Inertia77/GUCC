# 1. 鉴定师到底是什么人？

## 已知
- 【官】首位“无证上岗”的异象猎人。
- 【证】加入伊波恩后，能深入多个规则异象并改变结果。
- 【可能未来】第一枝相关坏未来中，其长期存在状态异常。

## 未知
- 是否真正长生。
- 是否存在过去身份缺失。
- 是否与零号异象存在因果关系。
- 为什么高位异象会允许 / 关注其介入。

## 禁止写死
- “鉴定师已经确认永生。”
- “鉴定师就是零号异象。”
- “鉴定师是某种确定种族。”

# 2. 浔的时间 / 不老能力

## 已知
- 第一枝拍卖会时间异常中表现特殊。
- 红字持续收集时间相关异象。
- 1.3伊南娜最终目标指向其时间 / 不老能力。
- 第一枝未来证明其选择与未来分支存在高强度关联。

## 未知
- 是预见、暂停、回溯、寿命延长，还是复合机制。
- 能否改变已经发生的事实。
- “不老”与“时间控制”是否同源。
- 能力来源。

## 最重要限制
**能看见风险 ≠ 能零成本重写风险。** 否则1.1–1.3所有选择都会失去意义。

# 3. 第一枝到底看到什么？

1.3已经证明一个关键点：第一枝展示的极端坏结局并非不可改变。

目前最稳妥模型：
```text
当前条件
→ 高可信度未来分支
→ 外部变量 / 新选择可改变结果
```

而不是：
```text
必然宿命录像
```

任何“第一枝已经证明某角色未来一定如何”的说法都应降级。

# 4. 零号异象为什么介入雾巢？

## 已知
- 介入改变终局。
- 力量层级足以影响雾柩相关局面。
- 不属于伊波恩 / E.T.D正常计划资源。

## 可能解释
- 保护鉴定师；
- 反对雾柩；
- 反对伊南娜；
- 维护某种更高规则；
- 完全出于自身目的。

全部只能标【推】。

## 禁止写死
“零号异象是主角阵营守护神。”

# 5. 雾柩与雾巢的起源

## 已知
- 雾巢有强制规则。
- 胜负可与“夺取东西 / 异能”关联。
- 伊南娜非常熟悉并能利用这些规则。
- 雾柩层级远高于普通参与者。

## 未知
- 天然形成还是人工改造。
- 红字参与到什么程度。
- 是否有历届游戏。
- 伊南娜是否曾在旧轮次中经历类似结算。
- 与零号异象是否属于同类体系。

# 6. 红字是否真的结束？

## 已回收
- 伊南娜核心目标。
- 时间类异象收集逻辑。
- 达芙蒂尔卧底。
- 1.3核心计划失败。

## 未知
- 剩余成员。
- 资金与资产。
- 情报网络。
- 外部合作对象。
- 旧实验 / 研究是否还有遗留。

因此后续出现“红字相关”不应立刻写成“组织复活”。

# 7. 达芙蒂尔1.1到底救下了多少人？

1.3已经解决“她为什么回红字”，但没有完全解决“1.1那个技术决策具体救下多少、损失多少、还有没有别的选择”。

需要继续追踪：
- 被困者最终结果；
- 娜娜莉为何只能不完整返回；
- 当时红字监视 / 规则限制；
- 她是否有其他可行方案。

这是“反转不删除后果”的典型案例。

# 8. 真红的“另一个自己”

## 已知
- 1.2将真红异能与自我认同冲突推到核心。
- “普通人”职业直接映照其深层愿望。
- “另一个自己”与这套冲突高度相关。

## 未知
它究竟是：
- 异能人格化；
- 心理投影；
- 独立异象意识；
- 共生体；
- 规则世界根据真红认知临时构造的存在。

当前不能越级结论。

# 9. DSD为什么能把异象做成消费品？

随心泥与九百九十九夜证明：
- 商品化存在；
- 复杂规则也能产品化；
- 普通消费者能接触。

真正未解的是制度：
- 安全评级；
- 责任归属；
- 事故赔偿；
- 产品回收；
- 规则更新；
- 企业内部研究能力。

- 普通规则异象；
- 雾巢级大型规则空间；

- 谁能对谁产生效果；
- 是否存在制度化编号 / 分类。
