## 0. v3 解决什么问题

《异环》最容易写错的不是“谁打赢了谁”，而是三类信息被混在一起：

1. **发布顺序**：玩家什么时候看到某段剧情。
2. **世界内顺序**：角色真正按什么先后经历这些事件。
3. **信息揭露顺序**：后续反转怎样改变我们对旧事件的理解。

v3 因此按以下结构维护：

```text
事件事实
→ 当时角色知道什么
→ 当时为什么会作出那个判断
→ 后续版本揭露了什么
→ 哪些旧行为被重新解释
→ 哪些后果仍然不能被“反转”抹掉
```

最典型的是达芙蒂尔：1.1 当时看起来像再次投向红字；1.3 证实其行为属于反击计划中的高风险卧底；但这只改变“动机解释”，不会让娜娜莉在游梦洄廊中受到的伤害自动消失。

## 8. 事实等级

- **【官】**：官方公告、官网角色资料、游戏内明确文本。
- **【证】**：多个已实装文本 / 完整流程可稳定拼合。
- **【推】**：有足够依据，但后续仍可能推翻。
- **【未】**：剧情明确抛出、目前尚未解释。
- **【可能未来】**：预知、梦境、分支结果；不能直接写成已发生历史。

## 9. v3 维护原则

1. 版本号不等于世界内时间。
2. 后续反转改变解释，不删除旧行为与后果。
3. 预知、梦境、幻觉、异象重构内容必须和客观历史分层。
4. 记录具体行为、动机与责任，不用“洗白 / 黑化”替代分析。
5. 社区资料可用于查漏，关键结论必须回查实装剧情或官方资料。
6. 新版本优先同步 `01-timeline.md`、`03-characters.md`、`04-mysteries.md`。
