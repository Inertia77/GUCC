1. 先读 `00-overview.md`，理解海特洛、伊波恩、红字与非线性时间线。

3. 按 `versions/` 阅读每个具体章节。
4. 最后用 `04-mysteries.md` 区分哪些谜团已经回收、哪些还不能写死。

## 当前最值得长期追踪的线索

- 鉴定师的真实身份与异常寿命暗示。

- DSD 等组织如何把异象合法/商业化为消费品。
- 向阳岛异象福利院的旧历史。

## 事实标记

- 【官】：官方公告、官网角色资料、游戏内明确文本。
- 【证】：多个已实装流程可以稳定拼合。
- 【推】：有证据支持，但仍可能被后续推翻。
- 【未】：剧情已经抛出、目前尚未解释。

## 维护规则

1. 新版本先确认实际发生时间，不机械按版本号排世界时间线。
2. 角色台词、异象制造的未来/梦境，不自动视为客观历史。
3. 角色后来反转立场，不反向删除其早期真实行为。
4. 社区复盘可以用于查漏，但关键结论至少回查实装剧情或官方资料。
5. 若未来官方改写/补充旧章，优先修正文档而不是保住旧考据结论。
