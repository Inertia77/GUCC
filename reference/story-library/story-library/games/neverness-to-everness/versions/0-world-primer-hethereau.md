# 异环｜海特洛世界观入门 v3

> 校对日期：2026-08-26  
> 用途：第一次进入剧情库时先读。  
> 核心问题：**为什么海特洛可以“正常地发生不正常的事”？**

## 0. 一句话理解海特洛

海特洛不是异常刚刚降临的末日都市，而是一座已经学会：**管理异常、雇佣异常者、买卖异象、消费异象、娱乐化异象，并继续正常上班生活的城市。**

因此本作的世界观问题不是“人类如何第一次面对超自然”，而是：**当超自然已经被社会吸收，人类会怎样高估自己对规则的控制能力？**

## 1. 城市生活没有因为异常停止

【官】故事从海特洛启篇；鉴定师作为“无证上岗”的异象猎人加入伊波恩。

居民依然会：
- 上班；
- 开店；
- 租房 / 买房；
- 开车 / 坐电车；
- 逛商场；
- 看演出；
- 上网；
- 玩桌游；
- 谈恋爱；
- 追星；
- 买异象商品。

同时：
- 电话亭可能把人吐出来；
- 照相馆可能把人锁进照片空间；
- 玩具可能失控；
- 拍卖会会交易高危预知异象；
- 桌游可以把玩家直接拖入规则世界。

这就是“一切正常，就是异常”的社会层含义。

## 2. 异象至少有四种表现层

### 2.1 物件型
第一枝、恒今时、随心泥、九百九十九夜。

### 2.2 空间 / 规则型
菲林轨迹、月光当铺、游梦洄廊、雾巢、沃伦大陆。

关键：进入这种异象后，真正敌人常常不是怪物，而是**规则本身**。

### 2.3 生物 / 人格型
部分异象具有明确意志、情绪或关系。

### 2.4 人类 / 异能 / 异象边界模糊
娜娜莉、真红、残虹、浔等证明异常能力可以成为人格、职业、社会身份、创伤，以及被别人觊觎的资源。

## 3. 异象猎人不是“怪物猎人”

标准涉异处理更接近：
```text
接委托
→ 找触发条件
→ 确认规则
→ 判断谁被影响
→ 进入规则空间
→ 解除 / 稳定 / 泯除 / 收容
→ 处理现实后果
```

如果不理解规则，单纯战斗甚至可能扩大风险。

## 4. 伊波恩为何存在

城市存在大量“对当事人非常严重，但还没有严重到必须立刻出动官方高危单位”的案件。

伊波恩正好处于：
```text
普通生活
↕
民间异常委托
↕
官方高危涉异体系
```

这个中间层。

## 5. E.T.D为何仍然必要

民间灵活不等于制度可以消失。

当事件涉及：
- 大规模犯罪；
- 高位异象；
- 组织渗透；
- 抓捕；
- 司法处置；

就需要E.T.D。

1.3的伊波恩 + E.T.D联合行动说明：两者是能力互补，不是简单“官方强 / 民间弱”。

## 6. 异象已经进入市场

### 拍卖
第一枝进入高端拍卖。

### 玩具
随心泥。

### 桌游
九百九十九夜。

### 愿望交易
月光当铺。

这意味着异象已经具有资产、商品、娱乐、合同等社会属性。

## 7. 商品化最危险的误解

消费者很容易把：
```text
有品牌
+ 有售价
+ 有用途
=
一定可控
```

但异象真正遵循的是自身规则。商品化只能证明人类学会利用规则，不证明规则已经变成普通物理产品。

## 8. 异象最常抓住人的欲望

- 第一枝：想知道未来。
- 恒今时：想让某种状态永远不变。
- 月光当铺：想获得现实中得不到的东西。
- 游梦洄廊：想留在过去。
- 雾巢：想夺取别人拥有的能力。
- 九百九十九夜：把“我想成为怎样的人”直接翻译成职业。

所以调查异象时，必须同时调查：**谁为什么愿意接受它的规则。**

## 9. 异常者也有普通生活

塔吉多想谈恋爱；真红想当普通人；娜娜莉想建立“家族”；伊波恩想维持店铺周转。

本作最重要的世界观温度来自：异常身份不会自动取消一个人的普通生活需求。

## 10. 向阳岛与异常者照护制度

1.1把当前度假区与旧“异象福利院”历史连接。

这证明城市很早就存在某种照护、收容、管理、教育异常儿童 / 异能者的制度。具体边界仍【未】。

## 11. 网络与舆论也是异常世界的一部分

1.0番外证明直播、网络舆论、短视频式传播、群体误解可以与异象事件叠加。异常进入现代网络社会后，反而可能被信息传播二次放大。

## 12. 当前世界观最重要的未知

- 异象完整分类体系；
- 高位异象层级；
- 零号异象性质；
- 异象商品审批 / 监管；
- 异常者福利制度历史；
- 鉴定师与规则异象特殊关系；
- 浔时间能力来源。

## 13. 阅读主线前记住四句话

1. **异象不等于怪物。**
2. **规则通常比战斗更重要。**
3. **异常已经是社会的一部分。**
4. **能利用规则，不等于真正控制规则。**
