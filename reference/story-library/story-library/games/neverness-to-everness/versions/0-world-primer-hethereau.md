# 异环｜海特洛世界观入门

> 校对日期：2026-08-25  
> 用途：先读本页，再进入 1.0–1.3 剧情。这里只解释“这个城市为什么能正常地发生不正常的事”。

## 1. 海特洛不是末日城

海特洛最大的世界观特点是：**异常没有摧毁现代都市生活，而是被现代都市生活吸收了。**

居民照常：
- 上班与经商；
- 买房、开车、坐电车；
- 逛商场、玩街机、看 live；
- 使用网络和短视频；
- 买带有异象能力的商品。

与此同时，电话亭可以把人吐出来，照相馆会把顾客关进照片空间，异象玩具可能失控，高危异象还能进入拍卖会。

所以“正常”与“异常”不是两张地图，而是同一座城市的两层规则。

## 2. 异象是什么

截至 1.3，异象至少可以表现为以下几类：

### 物件型

例如第一枝、恒今时、随心泥、九百九十九夜等。外观看起来可以像收藏品、玩具或桌游，但内部规则可能远超普通物理对象。

### 空间 / 规则型

例如菲林轨迹照相馆中的摄影框空间、月光当铺、游梦洄廊、雾巢、沃伦大陆。

这种异象最危险之处通常不是敌人攻击力，而是**“你已经进入了它的规则，而规则并不关心你是否理解。”**

### 生物 / 人格型

部分异象具有明确意志、情绪与关系，例如月光当铺相关的蒲公英/墨菲克斯。它们不能一律理解为没有思想的怪物。

### 与人的异能纠缠

异能者、歧骸等超自然居民进一步模糊“人”和“异象”的边界。娜娜莉、真红、残虹、浔等人都说明：异常能力可以成为人格、职业和社会身份的一部分。

## 3. 异象猎人

鉴定师以“无证上岗”的异象猎人身份开始活动。

异象猎人的工作不是单纯讨伐：

1. 接受委托。
2. 调查异常来源。
3. 确认规则和触发条件。
4. 保护当事人/普通市民。
5. 必要时进入异象空间。
6. 泯除、收容、解除或重新稳定异象。

很多案件如果不先理解规则，直接战斗反而可能让结果更糟。

## 4. 伊波恩为什么重要

伊波恩是民间古董店，也是民间异象委托入口。

它在世界结构中的价值是连接三层：

```text
普通市民的麻烦
↕
民间异象猎人 / 伊波恩
↕
官方 E.T.D 与更高危涉异体系
```

许多普通人遇到的异常没有严重到立刻让官方高危部队介入，但又绝非普通警察或售后服务能解决。伊波恩正好活在这个缝隙里。

## 5. E.T.D 与官方体系

E.T.D 各队处理更高危的涉异犯罪与异常事件。

1.1–1.3 证明，当敌人达到红字级别时，民间伊波恩与官方体系需要合作：伊波恩掌握特殊人物和民间现场优势，E.T.D 提供正规情报、武力、调查和司法收尾。

## 6. 异象已经进入商业社会

这是海特洛最值得长期跟踪的设定之一。

### 拍卖与收藏

第一枝这种高价值异象会进入高端拍卖会，意味着异象已成为稀缺资产与投资对象。

### 消费品

DSD 的随心泥、九百九十九夜证明部分异象被做成了娱乐商品。

### 愿望与契约

月光当铺则把“愿望实现”做成一种极端合同交易：得到能力或成功，同时支付感官、未来生活等代价。

因此异象管理的真正难题不只是“封不封得住”，还包括：**谁能合法拥有、谁能出售、消费者是否真正理解风险、企业对规则掌握到什么程度。**

## 7. 异象与人的欲望

1.0–1.3 反复证明，异象最常利用的不是肉体弱点，而是人已有的愿望：

- 想知道未来 → 第一枝。
- 想让某种关系/状态永恒 → 恒今时。
- 想实现现实中得不到的愿望 → 月光当铺。
- 想回到过去 → 游梦洄廊。
- 想拥有永生 → 伊南娜利用雾巢。
- 想成为普通人 → 九百九十九夜把真红内心愿望变成职业。

因此研究异象时，必须同时研究“谁在使用它、为什么愿意进入它的规则”。

## 8. 海特洛社会的几个重要层面

### 街区与普通生活

桥间地、半角街等区域承担伊波恩日常与城市生活。

### 高端资本与灰色交易

惠比寿拍卖会等场景显示富人和收藏市场也深度参与异象流通。

### 异常者照护

向阳岛围绕异象福利院开发，说明城市长期存在对异常儿童/异能者的照护、收容或管理制度。

### 网络社会

安魂曲番外证明网络舆论可以与异象危机互相放大；现代传播本身也是城市异常的一部分。

### 文化娱乐

哈尼娅乐队、月亮狗之夜等说明城市并非只有危机。音乐、演出和青年文化是真实生活，而不是主线间隙的装饰。

## 9. 当前最大的世界观谜团

- 鉴定师为何对规则异象具有特殊介入能力？
- 零号异象是什么层级的存在？
- 浔时间/不老能力从何而来？
- E.T.D 与民间异象猎人完整制度关系如何？
- 异象商品化的审批/监管体系究竟有多成熟？
- 雾柩、雾巢等高位规则异象的来源是什么？

## 10. 阅读主线时记住三句话

1. **异象不等于怪物。**
2. **规则往往比战斗更重要。**
3. **海特洛真正特别的地方，是人已经学会和异常一起过日子。**
