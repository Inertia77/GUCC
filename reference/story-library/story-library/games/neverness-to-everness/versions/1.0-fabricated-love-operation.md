# 异环 1.0｜从捏造开始的恋爱大作战

> 校对日期：2026-08-25  
> 本章定位：伊波恩日常喜剧 + “异象商品进入普通消费生活”的世界观展示。

## 1. 事件起点：塔吉多要约会

塔吉多向伊波恩众人求助，希望和塔可小姐来一场真正意义上的约会。于是原本负责处理异常事件的一群人，开始一本正经地替一只歧骸筹备恋爱作战。

这章之所以值得单独留档，是因为它把《异环》的核心气质写得很清楚：**怪异不一定意味着恐怖，它也可以成为普通人生活的一部分。**

## 2. 外形改造：先给老大整一套西装

第一阶段是让塔吉多看起来“像个靠谱的约会对象”。鉴定师陪它前往服装店，处理尺寸、试衣等一连串问题。

塔吉多穿西装本身是笑点，但也说明海特洛的“异常居民”并不完全活在隔离区：它们会购物、约会、进商场，也会被尺寸和回头率困扰。

## 3. 礼物计划

众人继续帮塔吉多准备礼物：

- 红玫瑰。
- 糖果等普通约会物品。
- DSD 出品的异象玩具「随心泥」。

随心泥是本章最重要的世界观物件。它已经被包装成潮玩产品，拥有明确的消费场景和使用说明——这意味着“异象制品产业”已经成熟到普通市民可以把它买回家当玩具。

## 4. 约会路线

塔吉多与塔可小姐开始约会，鉴定师和伊波恩众人在幕后提供支援。

路线包含电玩城、白鹦鹉街、湛望角等日常都市空间；期间还穿插娜娜莉等人为了制造“英雄救美/老大威风”效果安排的表演。

这整段没有宏大世界危机，却把伊波恩每个人的性格写得非常直观：大家嘴上吐槽，实际上全员认真帮塔吉多完成愿望。

## 5. 随心泥失控

真正的异象冲突出现在告白/表演阶段。

本来被当作道具使用的随心泥突然失控，鉴定师等人不得不从恋爱军师切回异象猎人模式，处理由商品化异象引发的现场混乱。

### 这一段真正说明什么

问题不只是“塔吉多倒霉”。

它揭示了海特洛社会一个长期隐患：

> 当异象被包装成商品后，消费者很容易把“可控”误解成“普通”。但规则异象的危险从来没有因为价格标签和包装盒就消失。

这条世界观后来在 1.2「九百九十九夜」被放大：桌游产品甚至能直接把参与者拖入完整异象世界。

## 6. 结局

事故被处理后，众人还要承担清理现场等后果。塔吉多的约会并没有按计划变成完美浪漫故事，但它和塔可之间的关系也不是简单“失败清零”。

伊波恩众人则再次证明：他们处理异常的方式，经常是先把事情搞得更大，再一起把残局收回来。

## 7. 人物作用

### 塔吉多

从纯粹的搞笑维修角色变成有私房钱、恋爱愿望、自尊与社交焦虑的生活角色。

### 伊波恩众人

这一章继续给“家庭感”加砖：没有任何人必须帮塔吉多约会，但所有人都参与了。

### 鉴定师

逐渐习惯伊波恩的逻辑：异象猎人的工作边界并不只在战斗现场，很多委托与生活本身就是混在一起的。

## 8. 与后续连接

- **随心泥 → 九百九十九夜**：共同展示 DSD 异象商品化体系。
- **恋爱日常 → 红字主线**：1.0 故意先给足轻松生活，后半再逐步转向拍卖会和讨债人，让红字威胁显得更具侵入性。
- **塔吉多日常 → 伊波恩家庭**：让后续伊波恩成员受伤时，玩家更容易把损失理解为家庭危机。

## 9. 校对依据

公测完整任务流程可核到：准备西装 → 购买玫瑰/随心泥 → 电玩城 → 白鹦鹉街 → 湛望角 → 告白表演 → 随心泥失控 → 清理现场。
