## 4. 玩家在1.0结束时知道什么

### 已知
- 红字是组织，不是单一犯人。
- 残虹是重要执行者。
- 第一枝、恒今时都与时间主题高度相关。
- 浔对时间异常具有特殊性。

## 5. 1.3后回看1.0

1.3让1.0中的两条线真正合并：

### 情感线
伊波恩已经成为浔 / 鉴定师不能当作可牺牲资源的家。

### 战略线
红字已经开始收集、试探与时间能力有关的异象和人物。

因此1.1娜娜莉事件不是突然升级，而是：红字发现“只拿异象”不足以逼浔入局后，开始攻击她真正不能放弃的东西。
