# 异环 1.0｜序章：不虞亦先兆 → 生意经与招财宝

> 校对日期：2026-08-25  
> 本文解决：鉴定师怎样进入海特洛、怎样加入伊波恩、为什么这家店会成为后续主线的“家”。

## 1. 起点：从官方体系出来，去往伊波恩

鉴定师以异常但尚未完全被制度化定义的身份进入海特洛。早期剧情很快把玩家从官方异象管理体系送到民间：薄荷负责带路，目的地是桥间地的「伊波恩古董店」。

这一步很重要，因为《异环》没有让玩家长期待在官方机构，而是让主角进入一个经济拮据、成员古怪、但真正和城市普通人生活贴得很近的民间据点。

## 2. 桥间地：城市第一印象

从异象管理局离开后，薄荷带鉴定师穿过铁路、半角街等区域，并介绍维特海默塔等海特洛地标。

玩家在这里第一次感受到《异环》的城市逻辑：电车、商店、街区、广告都正常运作，但异常现象随时可能插进日常——例如电话亭会把人“吐”出来，这种事情并没有直接让整个街区进入末日状态。

## 3. 抵达伊波恩：第一印象绝对不正常

鉴定师到达伊波恩后，先接触到店门口的铃状异象。进入店内后，所谓“好客屋”的特性又把塔吉多变成夸张的巨人状态并触发战斗。

这里用喜剧快速建立三件事：

1. 伊波恩不是纯粹售卖古董的正常商店。
2. 店里的人自己也经常被异象规则折腾。
3. 大家处理异常的第一反应不是惊慌，而是“先把问题解决，再收拾烂摊子”。

这套反应模式之后几乎贯穿所有伊波恩剧情。

## 4. 宿舍：外来者开始变成“自己人”

阿德勒与塔吉多已经替鉴定师准备住处。鉴定师获得手机、认识娜娜莉、早雾、埃德嘉等成员，并被自然地纳入伊波恩生活。

这一段看似只是游戏功能解锁，但从剧情角度非常关键：**主角与伊波恩不是签一份正式劳动合同才形成关系，而是在被给一张床、一部手机、有人招呼吃住之后慢慢变成一家人。**

## 5. 第一单生意：照相馆「菲林轨迹」

鉴定师刚住下不久，伊波恩便接到照相馆委托。店里几乎“全体出动”，一个很现实的动力是：除了报酬，还能顺便蹭一张新的全家福。

### 调查流程

- 伊波恩众人进入照相馆调查多层影棚。
- 摄影框会把人捕捉进诡异的异象空间。
- 鉴定师多次进入、脱出这些定格式空间，逐渐掌握规则。
- 线索最终指向地下室与陈旧胶片。
- 核心异常「MANISH」被确认并泯除。

这次委托用一个非常“都市怪谈”的结构教玩家理解本作异象：**危险不是一定来自长着角的怪物，也可能来自一个看似普通行业中失控的规则。**

## 6. 全家福：为什么这个结尾值得记

委托完成后，伊波恩获得报酬，众人也完成了那张“顺便蹭来的”全家福。

这张照片的叙事价值远高于一个笑点：刚来到海特洛的鉴定师，在一章之内已经从陌生人变成了可以站在伊波恩合照里的人。

后面 1.1 红字真正打击伊波恩时，玩家之所以会觉得那不是“NPC 受伤”，就是因为 1.0 花了大量日常时间让这种家庭关系先成立。

## 7. 本章人物关系变化

### 鉴定师 → 伊波恩

从“被引荐来的特殊新人”变成可以一起出委托、一起住、一起拍全家福的正式成员。

### 薄荷 → 鉴定师

承担城市向导角色。她把鉴定师从官方空间带进民间生活，也因此成为后续能自然串联伊波恩、朋友聚会与 1.2 九百九十九夜的角色。

### 娜娜莉 / 早雾 / 塔吉多 / 阿德勒等

不是一次性做完人物介绍，而是通过宿舍、委托、互相吐槽把“家庭功能”逐渐固定下来。

## 8. 世界观新增

- 海特洛已经把异象当成常态社会问题处理。
- 民间存在真正以处理异象委托维生的组织。
- 异象可以附着于空间、物件与行业场景。
- 泯除不是唯一叙事方式；理解规则、调查来源同样重要。
- 伊波恩是民间异象网络与城市普通生活之间的重要接口。

## 9. 与后续章节连接

本章并未直接进入红字，但建立了红字篇最需要的两个前提：

1. 鉴定师为什么会持续参与海特洛异象事件。
2. 伊波恩为什么值得被红字拿来威胁浔。

没有这一章的日常，后面的阴谋只会是“打反派”；有了这一章，它才会变成“有人在动我的家”。

## 10. 校对依据

- 官方游戏定位：鉴定师作为无证异象猎人加入接取民间委托的伊波恩。
- 公测正篇完整流程：不虞亦先兆、生意经与招财宝。
- 任务文本：桥间地、好客屋、巨人塔吉多、宿舍、菲林轨迹、MANISH、全家福。
