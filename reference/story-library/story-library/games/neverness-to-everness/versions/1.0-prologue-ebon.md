# 异环 1.0｜序章：不虞亦先兆 → 生意经与招财宝 v3

> 校对日期：2026-08-26  
> 本章作用：解释鉴定师怎样从“海特洛外来者”变成“伊波恩全家福里的人”。  
> 事实等级：【官】官方/游戏内直接确认｜【证】实装流程稳定拼合｜【推】解释层｜【未】尚未解释

## 0. 一页看懂

```text
进入海特洛
→ 离开纯官方空间
→ 薄荷带往桥间地
→ 伊波恩
→ 好客屋 / 巨人塔吉多
→ 获得宿舍与手机
→ 第一份正式委托：菲林轨迹
→ MANISH
→ 完成全家福
```

这一章真正建立的不是“新手教学”，而是：**鉴定师第一次拥有一个会等自己回家、会一起接单、会一起拍照的社会单位。**

## 1. 从官方体系走向民间

【官】鉴定师以“无证上岗”的异象猎人身份进入海特洛。

剧情很快把主角从纯粹官方管理场景送向民间伊波恩，这是关键叙事选择：
- 如果长期待在官方机构，玩家会把异常理解为任务；
- 进入伊波恩后，异常会直接与房租、吃住、生意和朋友混在一起。

## 2. 桥间地：海特洛的第一课

薄荷承担城市向导。

玩家在铁路、街区、地标与普通商铺之间移动，同时发现异常现象并不会让整座城市停止运行。

这告诉玩家：海特洛不是“异常爆发后进入紧急状态”，而是“异常本来就是日常的一部分”。

## 3. 伊波恩第一次见面为什么一定要荒唐

进入店铺后：
- 铃状异象；
- 好客屋；
- 塔吉多巨大化；
- 现场混乱。

这套喜剧定义伊波恩的处理逻辑：

```text
异常发生
→ 先解决
→ 互相吐槽
→ 收拾烂摊子
→ 继续过日子
```

后面再大的危机，伊波恩都没有完全失去这种生活底色。

## 4. 宿舍与手机：真正的“入职仪式”

阿德勒、塔吉多等人为鉴定师准备住处。

主角获得：
- 个人空间；
- 城市通讯工具；
- 稳定同住关系；
- 会主动找自己的伙伴。

这比“签合同”更重要。伊波恩通过**生活安排**而不是机构手续把鉴定师变成成员。

## 5. 第一单生意：菲林轨迹

伊波恩接到照相馆委托。

### 调查层
- 多层影棚；
- 摄影框；
- 异常空间；
- 地下室；
- 陈旧胶片；
- 核心异常MANISH。

### 世界观层
它第一次明确证明：异象危险可以藏在非常普通的行业规则里。

照相本来是“留下现实”的行为；异常照相馆却把人反过来固定进影像 / 规则空间。

## 6. 鉴定师为什么重要

本章没有一次性解释鉴定师身份，但已经留下长期特征：其对规则异象的进入、理解与解除能力非常突出。

这以后会在游梦洄廊、雾巢等大型规则空间中进一步放大。目前只能记录“特殊”，不能提前写成具体种族 / 身份。

## 7. 全家福：1.0最重要的情感证据之一

完成委托后，伊波恩获得全家福。

这张照片证明：

```text
刚进城的陌生人
→
已经被允许站在家庭记忆里
```

1.1红字打击娜娜莉以后，这张全家福会产生后见意义：对方伤害的不是一个任务NPC，而是照片里的人。

## 8. 人物关系

### 鉴定师 ↔ 薄荷
薄荷是城市入口，也是“正常社交生活”入口。

### 鉴定师 ↔ 伊波恩
从任务合作升级成共居关系。

### 娜娜莉 / 早雾 / 塔吉多
不是一次性角色介绍，而是通过日常功能逐渐构成家庭角色。

## 9. 当章新增世界观

- 异象已经被城市常态化管理；
- 民间存在异象猎人 / 委托体系；
- 规则异象可附着普通商业场所；
- 理解规则往往比单纯战斗重要；
- 民间组织是官方体系的重要补充。

## 10. 与红字篇的关系

本章没有红字核心冲突，却建立红字篇必需前提：

### 前提一
鉴定师为什么会不断参与后续案件。

### 前提二
为什么攻击伊波恩成员能逼浔改变策略。

没有日常，就没有真正的威胁。

## 11. 详细流程补记：为什么这些“新手步骤”都值得留档

### 11.1 从官方区域离开后，城市先于主线登场

薄荷带鉴定师进入桥间地一带时，铁路、半角街、维特海默塔等城市元素先被建立。这里的作用不是让玩家背地图名，而是让后续所有异象都发生在一个“本来有人上班、逛街、坐车”的现实城市里。

电话亭把人吐出来之类的异常不会自动触发全城封锁，也说明居民与管理体系早已形成对低烈度异常的日常适应。

### 11.2 伊波恩的“欢迎”不是一句台词

鉴定师抵达伊波恩后，先被店门口与屋内的异象规则折腾；“好客屋”把塔吉多变成巨人，众人必须先处理眼前混乱。

这种开场实际上定义了伊波恩成员的默契：他们不会因为家里出现异象就把彼此当成危险源隔离，而是默认“先救人、先处理，再骂两句”。

### 11.3 宿舍、手机与日常联系人

随后获得宿舍和通讯工具，看似属于系统功能解锁，却把鉴定师从临时访客变成有固定住址、有联系人、有地方回去的人。娜娜莉、早雾、塔吉多、阿德勒等人的介绍也是通过这种生活场景完成，而不是一次性站成一排报履历。

### 11.4 「菲林轨迹」的调查不是只打一只怪

照相馆委托的推进至少包含：
1. 进入多层影棚调查异常；
2. 理解摄影框如何把人卷入定格式空间；
3. 反复从“现实场景”与“照片规则”之间寻找出路；
4. 继续追到地下室、陈旧胶片等源头线索；
5. 最终确认核心异常 MANISH 并完成泯除。

这套流程是本作第一次完整示范“异象猎人”的工作不是看到怪就打，而是**先判断规则如何运作，再决定怎样让规则停止伤人**。

### 11.5 全家福为什么是后续剧情的情感基准

委托完成后大家真正拍下全家福。这个结果会成为1.1的隐性参照：红字后来伤害娜娜莉时，被打碎的是一套已经通过“住在一起—一起接单—一起拍照”成立的家庭关系，而不是刚认识几小时的队友关系。

## 12. 容易误读

### “序章只是功能教学”
不对。宿舍、手机、全家福都是角色关系证据。

### “伊波恩只是任务公会”
不对。它首先是生活共同体，其次才是委托中枢。
