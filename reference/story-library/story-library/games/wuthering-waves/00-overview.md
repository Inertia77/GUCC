# 鸣潮｜世界观与主线总览

> 校对日期：2026-08-24  
> 用途：在读任何版本章之前，先解决“这个世界怎么运转、主角为什么卷进来、故事到底在追什么”。

## 1. 一句话主轴

一个失去记忆却被世界不断“认出来”的漂泊者，在悲鸣后的频率文明中旅行；每到一地既处理当地灾害，也从旧识、系统和历史遗留中拼回过去。

## 2. 世界运行规则

- **悲鸣（Lament）**：改变索拉里斯-3的世界级灾变总称，不应粗暴理解为一次单一爆炸；其余波以多种频率异常持续塑造生态和文明。
- **频率是底层语言**：共鸣者、声骸、残象、无音区等都与频率结构有关。游戏里的“声音/共振”不是纯美术主题，而是世界运行规则。
- **残象（Tacet Discord）**：灾后异常生命/频率实体的重要类别；不同地区会形成不同生态与高阶威胁。
- **声骸（Echo）**：残象频率可被捕获/利用，战斗系统因此与世界观直接相连。
- **岁主 / 鸣式 / 高阶存在**：不同地区的高阶存在拥有长时间尺度与文明影响力，但称号、宗教叙述和实际机制必须分开。
- **异常空间**：黑海岸计算域、心之集域、拉海洛虚质空间等证明频率可作用于记忆、梦境、空间乃至局部时间。

## 3. 主角 / 玩家身份

漂泊者是失忆主角，但不是“没有历史的人”。今州岁主角、黑海岸、拉海洛学院等都保留其旧日痕迹。资料库把两种身份并行记录：
1. **过去的漂泊者**：曾参与不同文明关键项目、与高阶存在有旧关系。
2. **现在的漂泊者**：在不知道全部过去的前提下，以当前选择重新建立关系。
不能因为旧身份越来越强，就把所有当前关系解释成“别人天生服从救世主”。

## 4. 主线阶段

1.x 今州与黑海岸：建立频率世界、今州关系和漂泊者旧史。

2.x 黎那汐塔：展示另一种把声骸、艺术、信仰与城市制度结合的灾后文明，并完成长篇政治/信仰危机。

3.0–3.4 拉海洛：极地地下学术都市、虚质、Exostrider、Roya与漂泊者更私人化的旧日人生。

3.5起 第四章梦州/玄方：机关文明、两百年前旧战、秧秧等旧伙伴重新回到核心；3.6以清宵和机关失灵继续推进。

## 5. 当前剧情位置

截至2026-08-24，当前实装版本为3.6。第四章第三幕《烟云幽远心剑鸣》与幕间《幽客销残声》已开放；下一阶段危机性质尚未官方完整说明。

## 6. 长期主题

- **身份与选择**：过去能解释你从哪里来，但不能自动替现在决定怎么活。
- **文明如何适应灾害**：今州军政、黑海岸计算、黎那汐塔声骸城市化、拉海洛学院、梦州机关体系都是不同答案。
- **技术与牺牲伦理**：泰缇斯、Exostrider、机关体系不断追问“更大共同体的安全”能否无限压过个体。
- **记忆可靠性**：失忆、梦境、记录、时间异常让“谁记得什么”本身成为证据问题。

## 7. 阅读时最容易踩的坑

- 不要把“角色很喜欢/信任漂泊者”直接写成“过去一定是恋人/主仆”，除非任务明确。
- 不要把梦境/模拟重现当作现实历史逐帧录像。
- 不要把岁主、鸣式、守护神等不同文化称谓机械换算成同一“战力等级”。
- 新版本社区对幕后身份的推理更新很快；未有实装文本时保留【推/未】。
