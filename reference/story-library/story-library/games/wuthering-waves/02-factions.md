# 鸣潮｜阵营与权力关系

> 校对日期：2026-08-24

## 今州 / 瑝珑地方体系

- **公开目标**：保护边境城市、维持居民生活并应对残象潮。
- **实际关切 / 隐藏议程**：地方治理还必须平衡岁主传统、军政需求与普通人的生活。
- **主要资源**：夜归军、今令尹制度、研究与城防、岁主协作。
- **关键人物**：今汐、忌炎、散华、秧秧等。
- **关系**：与漂泊者长期盟友；与残星会敌对。
- **剧情变化**：1.x从审查漂泊者到把其视为可信盟友。

## 黑海岸

- **公开目标**：观测悲鸣、预测文明灾难、寻找降低全球风险的方法。
- **实际关切 / 隐藏议程**：“系统最优”可能与个体生命价值冲突。
- **主要资源**：泰缇斯系统、全球情报与计算设施。
- **关键人物**：守岸人及黑海岸成员，漂泊者旧日亦与组织深度相关。
- **关系**：与漂泊者是旧关系+当前盟友。
- **剧情变化**：1.3后拒绝把守岸人永久工具化，系统伦理需要重构。

## 残星会

- **公开目标**：以自身理念理解/利用悲鸣与进化，主动制造或利用社会裂缝。
- **实际关切 / 隐藏议程**：不同成员动机与组织高层目标不能完全等同。
- **主要资源**：异常技术、渗透、残象/频率利用。
- **关键人物**：疤痕等。
- **关系**：主线长期敌对，但其信息有时会暴露官方叙事盲区。
- **剧情变化**：从今州直接诱导漂泊者，扩展到拉海洛等地区行动。

## 黎那汐塔城市/家族网络

- **公开目标**：维持城市贸易、家族利益与地方秩序。
- **实际关切 / 隐藏议程**：不同家族对危机和改革答案不一。
- **主要资源**：财富、城市基础设施、声骸产业与社会关系。
- **关键人物**：珂莱塔等。
- **关系**：与修会既合作又存在解释权/利益张力。
- **剧情变化**：2.x危机后权力与信任关系重组。

## 隐海修会等黎那汐塔信仰体系

- **公开目标**：维持信仰、仪式与对高阶存在的社会解释。
- **实际关切 / 隐藏议程**：制度自保、传统真实性和居民安全有时冲突。
- **主要资源**：宗教合法性、组织网络、仪式知识。
- **关键人物**：菲比等。
- **关系**：与城市权力互相依赖。
- **剧情变化**：2.x经历历史真相和危机后，不再能维持开幕时的单一权威。

## 启明学院 / 拉海洛研究体系

- **公开目标**：研究虚质、极地灾害、Exostrider与文明生存方案。
- **实际关切 / 隐藏议程**：科研风险由谁承担、历史如何被保存是核心伦理问题。
- **主要资源**：科研人员、学院都市、工程设施。
- **关键人物**：琳奈、莫宁、Lucilla等。
- **关系**：与Roya既合作又背负历史结构性矛盾。
- **剧情变化**：3.0–3.3从学院中心视角逐步纳入Roya与旧史。

## Roya族群

- **公开目标**：保存自身生活、历史与对极地土地的主体性。
- **实际关切 / 隐藏议程**：并非单一政治实体，不应只作为学院世界观背景。
- **主要资源**：地方知识、社群网络与雪原生存经验。
- **关键人物**：Sigrika等。
- **关系**：与拉海洛学院存在合作与历史张力。
- **剧情变化**：3.2后从背景设定进入主线主体。

## 梦州 / 玄方地方体系

- **公开目标**：维持机关文明、镇守异常与地方秩序。
- **实际关切 / 隐藏议程**：两百年前旧战、高阶存在约束和机关系统根因仍有空白。
- **主要资源**：镇玄司、机关/傀儡系统、地方修行体系。
- **关键人物**：清宵、景燃、穗穗等。
- **关系**：当前与漂泊者合作处理3.5–3.6危机。
- **剧情变化**：3.6后仍在危机余波与新风波之间。
