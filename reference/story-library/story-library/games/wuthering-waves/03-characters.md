# 鸣潮｜核心人物与人物弧线

> 校对日期：2026-08-24

这不是角色名册；只收录对主线因果、阵营变化或长期谜团有实质影响的人物。

## 漂泊者

- **身份 / 位置**：失忆的高适配共鸣者 / 世界级旧史参与者。
- **核心欲望**：找回过去，同时保护旅途中形成的新关系。
- **核心恐惧 / 矛盾**：过去身份替现在的人生作主；自己再次把重要的人变成“系统部件”。
- **关键选择**：多次在旧制度给出的最优解之外选择保留个体选择权。
- **重要关系**：秧秧、今汐、守岸人、各地区旧识与现识。
- **当前状态**：3.6梦州玄方线。
- **仍未解释**：失忆根因、完整旧职责、与各高阶存在关系的统一解释。

## 秧秧

- **身份 / 位置**：最早陪伴漂泊者的共鸣者，长期伙伴。
- **核心欲望**：帮助他人并理解自身能力/责任。
- **核心恐惧 / 矛盾**：无法保护重要之人或被自己的敏感共鸣拖累。
- **关键选择**：从今州开局到3.5第四章仍持续主动参与。
- **重要关系**：漂泊者、炽霞、今州伙伴。
- **当前状态**：第四章重新成为核心伙伴。
- **仍未解释**：其能力与更大频率现象是否还有后续深化。
