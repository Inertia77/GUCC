## 资料可信度

一手优先：游戏内潮汐任务、库洛官方版本说明；版本/任务Wiki用于确认任务顺序和英文名。当前3.6刚实装，社区理论只可用于提出问题，不直接作为结论。

任何“角色自己说的话”都不自动等于客观事实；任何“预告里出现的画面”也不自动等于已经发生的剧情。资料库优先保留不确定性。
