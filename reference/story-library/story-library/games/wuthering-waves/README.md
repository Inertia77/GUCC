## 这套资料库和 v2 最大区别

v2已经覆盖到3.6，但存在两个明显问题：

1. **2.1–2.3、2.4–2.6被三个版本压成一个文件**，导致Interlude、正式Act、周年角色线、Septimont高潮的性质被混在一起。
2. 很多单版本文件只有“局势→几句概括→主题”，适合复习，不足以做人物动机、伏笔和视频考据。

v3改成：

- 2.1～2.6全部逐版本单列；
- 旧合集保留为兼容导航；
- 1.0～3.6全部按“事件因果—人物选择—世界规则—关系变化—事实边界”重写；
- 当前3.6严格区分已实装事实与社区理论。

## 事实等级

- **【官】**：官方公告、游戏内主线、系统文本直接确认。
- **【证】**：多个已实装文本可稳定拼合，结论高度可靠。
- **【推】**：解释力较强，但后续版本仍可能推翻。
- **【未】**：官方明确留下问题，或目前证据不足。

### 特别提醒

《鸣潮》的叙事大量使用：
- 梦境；
- 声弦/频率记录；
- 回忆；
- 局部时间异常；
- 被删除的集体记忆；
- Voidspace非线性时空；
- 角色传说与宗教叙事。

所以“画面出现过”不代表“客观世界一定这样发生过”。任何高质量考据都必须先问：**这段信息由谁观察、通过什么媒介留下、处于哪个时间层。**

## v3核心阅读主轴

如果只记一条线：

> **世界不断告诉失忆的漂泊者“你以前是谁”；而漂泊者不断用当下选择回答“过去不能替现在做决定”。**

今汐、守岸人、椿、Cartethyia、Lupa、Phrolova、Iuno、Aemeath、清宵等人物其实都在回答同一组问题：

- 被使命定义之后还能不能重新选择？
- 被社会忘记之后是否还存在？
- 被神话成英雄之后还是不是具体的人？
- 被系统判断“牺牲最优”时，个人价值还能否成立？
