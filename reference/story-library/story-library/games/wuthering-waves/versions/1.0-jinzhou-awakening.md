## 0. 一页看懂

- **一句话**：漂泊者在索拉里斯-3失忆苏醒，被秧秧、炽霞与白芷带入今州；表面目标是确认身份并处理鸣式危机，深层则不断出现“这个世界认识漂泊者，而漂泊者不认识这个世界”的反常证据。
- **主冲突**：今州要抵御无冠者、残象潮与残星会操纵；漂泊者同时要判断今州、黑海岸、残星会等各方对自己过去的说法。
- **关键结果**：漂泊者与今州建立信任，今汐/忌炎等认可其战力与身份特殊性；其与岁主、鸣式、无音区乃至文明旧史的联系成为长期主线。

## 1. 剧情发生前的局势

【官】索拉里斯-3经历“悲鸣”后，物质、信息与生命会以频率异常形式受灾害影响，残象（Tacet Discords）是最直观结果。
漂泊者醒来几乎没有过去记忆，却能异常稳定地吸收声骸、处理高强度频率污染。今州既需要这份力量，也必须确认这个突然出现的人是否是风险。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 无冠者让“普通失忆者”假设立即失效

漂泊者刚苏醒不久便遭遇无冠者。战斗后对异常频率与声骸的处理能力远超普通共鸣者，说明其身体与频率结构本身就是谜团。
### 2. 进入今州并接受身份调查

秧秧等把漂泊者带往今州。白芷、散华、今汐等从不同角度观察其频率和行为；“欢迎”与“审查”同时存在，体现边境城市在灾害压力下的现实谨慎。
### 3. 线索把漂泊者引向过去而非单纯任务目标

各种信物、隐喻与角色态度表明，漂泊者过去曾经深刻影响索拉里斯。玩家却只能通过他人的记忆拼图重构自我，形成全篇最重要的信息不对称。
### 4. 残星会把灾害当成进化与秩序工具

疤痕等人不是普通强盗，而是用自己的世界观解释悲鸣与残象，试图诱导漂泊者怀疑今州秩序。其叙事策略是“你忘了，所以任何历史都可能是别人替你写的”。
### 5. 忌炎与今州防线迎来鸣式级危机

战事把个人身份谜团与今州存亡合并。漂泊者与忌炎、今州军民共同抵抗大规模残象潮，证明自己至少在当下选择站在保护平民的一侧。
### 6. 危机后没有得到身世答案

1.0结束只确认漂泊者并非第一次与世界发生关系。故事有意不一次性交代过去，而是把“过去的我是谁”拆成后续地区与人物各自掌握的局部真相。

## 3. 主要人物弧线

### 漂泊者

起点是几乎没有社会身份的失忆者；通过一次次当下选择建立新身份。其核心矛盾不是“失忆多久能恢复”，而是恢复前是否必须服从别人对旧我的定义。
### 秧秧

最早给予稳定信任与生活性关怀的人，使漂泊者不是只以武器/救世主身份被世界接纳。
### 今汐

作为今州权力核心，需要在城市安全与对漂泊者的信任之间平衡；她与岁主角、乘霄山线为1.1铺垫。
### 忌炎

承担前线守城与战争伦理，和漂泊者形成“当下行动比未知过去更重要”的战友关系。
### 疤痕

通过残星会视角挑战官方叙事，作用不是给正确答案，而是让玩家意识到所有阵营都在争夺漂泊者对自我的解释权。

## 4. 本章新增 / 修正的世界观

- **频率世界观**：生命、物质、信息都能以频率被观测/干涉；共鸣能力、声骸、残象与悲鸣因此属于同一底层语言。
- **岁主与鸣式**：不是简单Boss等级标签，而是与区域生态、文明历史及悲鸣机制深度绑定的高阶存在。
- **漂泊者的声骸吸收**：其处理高阶残象频率的方式在世界内并不普通，是长期身份证据。

## 5. 伏笔、回收与仍未解释的问题

- **漂泊者过去**：世界各处存在旧关系，但不同角色只掌握切片；任何“某一章揭露=完整真相”的说法都应谨慎。
- **残星会真正目标**：其成员话术与实际行动并不总一致；需要区分理念宣传、组织战略和个体执念。
- **悲鸣源头**：1.0只让玩家理解灾后世界，不足以确认悲鸣最终成因。

## 6. 主题与叙事作用

今州篇把“记忆决定我是谁”改写成“选择也能决定我是谁”。它看似是传统失忆主角开局，却从第一章就让多个组织竞争性地解释主角过去，为后续每个地区的“旧识重逢”结构奠定基础。
