## 0. 一页看懂

- **一句话**：漂泊者抵达黎那汐塔，进入一个把声骸、艺术、信仰与城市政治深度结合的地区；看似华丽的狂欢背后，秩序由教会、家族、城市传统与危险的异常共同维持。
- **人物入口**：珂莱塔、洛可可、菲比、布兰特、赞妮等从不同社会阶层带玩家认识城市。
- **主线方向**：寻找与哀声鸷/岁主、隐海修会和黎那汐塔旧史相关的真相，而不是只完成观光。

## 1. 剧情发生前的局势

黑海岸线后，漂泊者继续依据过去线索旅行。黎那汐塔与瑝珑不同：这里把声骸嵌入交通、艺术、仪式和日常经济，居民对异常力量的态度更接近“文明基础设施”而非纯灾害。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 漂泊者进入拉古那并认识当地权力网络

初到异乡的主角不是自动拥有政治权限，而要通过家族、修会、骑士团等中介理解规则。
### 2. 狂欢节把城市最美的一面与最危险的一面叠在一起

节庆、艺术、信仰让城市充满生命力，同时也为身份伪装、组织活动和异常事件提供掩护。
### 3. 蒙泰利家族与珂莱塔线揭示贵族/家族秩序

珂莱塔既是个人角色，也是玩家理解家族利益、礼仪和地下风险的窗口。
### 4. 隐海修会与菲比线展示信仰体系

修会不是简单宗教背景，它参与城市治理、对异常的解释和对岁主/神圣秩序的理解。
### 5. 声骸社会化成为黎那汐塔最大世界观差异

声骸可以进入交通、服务、娱乐与文化表达，说明灾后文明并非只能与残象对抗，也能重新驯化部分频率现象。
### 6. 开幕章把真正危机推到幕后

2.0主要建立舞台与关系网，深层敌人与岁主异常并未一次性解决，为2.x连续长篇留出空间。

## 3. 主要人物弧线

### 漂泊者

从在今州有高信誉的英雄重新变成异乡人，必须学习另一种文明如何解释同一套频率世界。
### 珂莱塔

家族身份与个人行动之间持续拉扯，是理解黎那汐塔“华丽外观下有现实利益”的入口。
### 菲比

信仰并非天真，她体现普通人如何通过制度与仪式面对超自然世界。
### 布兰特

以更自由、表演性的方式连接城市与漂泊者，使“舞台/角色扮演”成为本地区重要隐喻。

## 4. 本章新增 / 修正的世界观

- **声骸城市化**：黎那汐塔证明Echo并非只用于战斗；文明可把频率实体纳入生活设施与文化。
- **修会与岁主信仰**：地区宗教制度与实际高阶存在之间关系复杂，不能把“信仰描述”直接当客观宇宙学。

## 5. 伏笔、回收与仍未解释的问题

- **哀声鸷与地区灾害关系**：开幕阶段只揭一部分，需要2.x后续回收。
- **漂泊者旧史为何延伸到黎那汐塔**：再次出现“世界记得漂泊者”的模式，但每个地区的旧身份细节不同。

## 6. 主题与叙事作用

黎那汐塔篇把鸣潮从“灾后边境生存”拓展成“灾后文明可以长成怎样不同的社会”。它最有价值的不是地图更繁华，而是展示同一个悲鸣世界里，制度、艺术与信仰如何形成另一套适应机制。
