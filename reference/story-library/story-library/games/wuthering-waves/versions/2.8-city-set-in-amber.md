# 2.8｜琥珀之城：Honami City、时间循环、Sumika的记忆与被抹去的都市

## 0. 一页看懂

- **一句话**：Act XII《Stagnant Dawn on Wastelands》把漂泊者带入一座早已从正常历史中消失、坐标持续漂移的Honami City；时间可在有限范围前后流动，越接近Neon Tower越异常，Sumika的琥珀能力与Chisa等人的生存经验共同维持“这座城曾经存在”的证据。
- **意义**：2.8不是Rinascita尾声彩蛋，而是把Lament从社会灾害重新推回“可以切割空间、循环时间、删除城市历史”的宇宙级规则问题。

## 1. 剧情发生前的局势

2.7后黑海岸扩充频率数据库并分析Leviathan essence，从中捕捉到不断移动的空间坐标。该信号指向一座早已消失的城市。漂泊者进入不是为了旅游，而是验证一个悖论：**如果世界的正常记录里没有它，为什么系统还能收到它的频率？**

## 2. 事件链：按“为什么下一件事会发生”来记

### 1. 黑海岸从Leviathan残余中找到漂移坐标

这一步把2.7终局残留直接转成2.8入口。高阶灾害的“尸体/余波”仍携带信息，黑海岸的价值在于能从异常数据中发现正常地图已经遗失的地点。

### 2. 进入Honami City后，空间与时间都失去常规稳定性

城市并非单纯废墟。空间像被切片，时间在固定范围内可前后流动，不同位置流速不同；靠近Neon Tower时异常进一步加剧。

这意味着玩家必须把“看到的人/建筑处于哪一时刻”纳入调查，而不能按普通线性地图理解。

### 3. Chisa等幸存/残留人物提供互相不完整的现实锚点

城市中的人仍有日常、恐惧和目标，但他们对时间状态的理解并不一致。漂泊者要通过多人的经验、物件和环境变化拼出局势。

角色证词在这里尤其需要标时间层级，否则很容易把不同循环中的说法当矛盾。

### 4. Sumika的Forte把记忆以“琥珀”形式保存

Sumika能够把记忆/时刻保存为琥珀式载体，使它们在城市时间混乱中仍可成为证据。这个能力的意义不只是剧情道具：它让“记忆能否对抗被世界抹除”变成可操作机制。

### 5. 研究记录与Neon Tower逐步解释灾害结构

玩家收集实验/城市记录，发现Honami并非普通遭遇一场爆炸后被遗忘。时间、空间、Lament和高阶异常共同制造了封闭/循环状态。

越接近核心，越难用外部世界的线性因果理解内部经历。

### 6. 面对Chronorift级威胁，目标是让城市重新拥有出口

战斗只是破局手段。真正目标是打断把城市锁在固定灾难时刻的结构，让人和信息重新能够向未来流动。

这与2.7“黎明”形成对照：Rinascita能向前，是因为人接受历史；Honami连“向前”这件事本身都被物理规则剥夺。

### 7. 《Flowing Starlight in the Iris》把余波带向下一章

Segue处理离开时仍残留的人物与频率问题，并为3.0 Lahai-Roi/太空与Voidmatter研究建立概念桥梁：悲鸣研究已经从地区历史走向时空、外空间与信息保存。

## 3. 人物动机与弧线

### Sumika
她的能力让“记忆”从叙事主题变成救援工具。保存不是为了把人冻结在过去，而是为了让未来仍有证据承认过去发生过。

### Chisa
代表在异常城市中仍努力维持日常判断的人。她的价值不是掌握全真相，而是给漂泊者一个内部时间视角。

### 漂泊者
自身失忆再次与城市失忆形成镜像：被世界记录系统遗忘，并不等于不存在。

## 4. 本章新增 / 修正的世界观

- **局部时间前后流动/流速差异【官】**。
- **空间坐标持续漂移【官】**。
- **Forte/频率载体能保存记忆与时刻【官/证】**。
- **Lament可以造成城市尺度的历史脱落【证】**。

## 5. 阵营与关系变化

黑海岸再次作为全球异常观测中心发挥作用；2.x地区社会冲突结束后，漂泊者与黑海岸合作模式转向更大的Lament机制研究。

## 6. 伏笔、回收与仍未解释的问题

- Honami从外界历史中被抹除的精确机制【未】。
- Chronorift与后续Voidspace/Stridergate是否属于同一底层机制【推，不能写死】。
- Sumika保存记忆的上限与真实性边界【未】。

## 7. 容易误读的地方 / 事实边界

- 时间循环中的重复事件 ≠ 每次都发生在同一因果层。
- 保存记忆 ≠ 记忆绝对客观；仍需与环境/多源证据核对。
- Honami被抹除 ≠ 从未存在。

## 8. 主题与叙事作用

2.8把“记忆政治”升级为“记忆物理学”：此前是组织决定谁被记住，现在连世界规则都可能让城市从历史中脱落。反抗遗忘因此成为真正的生存行为。
