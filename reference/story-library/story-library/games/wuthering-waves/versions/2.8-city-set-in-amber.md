## 0. 一页看懂

- **一句话**：2.8承担第二章尾声与第三章入口，把漂泊者从黎那汐塔完成度很高的地区故事送向拉海洛；“时间/保存/被封在某种状态中的城市”意象为3.x的学院、虚质与旧日漂泊者线预热。
- **结构作用**：它不是可随便跳过的番外，而是叙事换大陆时的接口。

## 1. 剧情发生前的局势

黎那汐塔主冲突已收束，但旅行需要一个合理的地理与线索转接。2.8通过新城市/异常和最终Segue，把下一目的地拉海洛与漂泊者过去连接起来。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 漂泊者进入“琥珀之都”相关事件

新地点以保存、凝固、历史残留等意象重新讨论灾后文明如何与过去共处。
### 2. 地区小型危机提供第二章余韵

不再启动一整套新政治史诗，而是集中处理少数人物与空间异常，让玩家消化黎那汐塔终章。
### 3. Flowing Starlight in the Iris等过渡内容出现

主线明确把下一阶段目标指向拉海洛/拉海洛地下结构及新的旧识。
### 4. 第三章入口被打开

空间通道、黑海岸联系与未知频率共同把漂泊者推向新的学院文明。

## 3. 主要人物弧线

### 漂泊者

再次面对“下一地也有人认识过去的我”的预兆，旅途从地区救世转回身份追索。

## 4. 本章新增 / 修正的世界观

- **章节间空间通道**：黑海岸等跨区域技术/异常成为移动到拉海洛的条件，世界各地区开始更明确互联。

## 5. 伏笔、回收与仍未解释的问题

- **拉海洛为何与漂泊者旧史相连**：2.8给方向，3.0才正式进入。

## 6. 主题与叙事作用

2.8最重要的功能是“换挡”：让第二章不是戛然而止，也让第三章不是凭空开新地图。一个好的过渡章应当同时完成告别和预告。
