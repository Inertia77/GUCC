## 0. 一页看懂

- **一句话**：漂泊者穿过通道抵达拉海洛，进入启明学院（Startorch Academy）与地下极地文明；学院并非陌生地——线索显示漂泊者过去曾在这里以学生/相关身份生活。
- **主冲突**：虚质风暴、虚噬体与岁主/鸣式级存在Aleph-1威胁地区；与此同时，学院对灾害、探索和“外骨骼/巨型机体”计划的研究隐藏着旧事故。
- **关键角色**：琳奈、莫宁、埃梅斯（Aemeath）等让主角从不同角度面对“我曾经属于这里吗”。

## 1. 剧情发生前的局势

【官】第三章《To the Stars Yet to Shine》以拉海洛为主舞台。拉海洛位于Roya Frostlands之下，极地地表在悲鸣与行星变化后形成雪原；第二次悲鸣又带来巨大机体Exostrider与Aleph-1。
3.0包含序章《When the Unknown Thrums》、第一幕《What Burns Beneath Frostlands》与第二幕《Ode to the Second Sunrise》。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 通过黑海岸/宏观通道前往拉海洛

漂泊者在通道中遭遇异常维度与虚质干扰，抵达过程本身就说明这里的灾害规则与此前地区不同。
### 2. 琳奈把漂泊者带入启明学院

学院是学术都市、训练机构与灾害研究中心。漂泊者在办理入学/接触课程时不断发现对环境的熟悉感，过去身份线被生活化而非只用史诗回忆表现。
### 3. 虚噬体夺走/干扰漂泊者部分频率

异常生物携带与更高阶灾害相关气息，直接作用于漂泊者自身频率，使本章危机从“帮助当地”变成“主角能力/身份也被卷入”。
### 4. 学院研究与旧日事件逐渐浮出

外骨骼/Exostrider、虚质、Roya历史等不是纯科研背景；它们与第二次日出、学院过去的生存选择相连。
### 5. 第二次日出意象连接过去与未来

剧情把“文明为什么在极地继续仰望星空”与角色个人选择结合：即使世界曾经坠落，仍有人用科研、学习和冒险争取下一次日出。

## 3. 主要人物弧线

### 琳奈

她是玩家认识学院日常、学生压力和虚噬体风险的第一窗口。她不是单纯导游，其个人选择把学院制度与真实危险连接。
### 莫宁

学院/科研线的重要参与者，使“如何理解漂泊者频率与地区异常”有技术视角。
### 漂泊者

旧日身份从“远古领袖”转为更私人、更可触摸的“曾在这里生活/学习过”，让失忆的重量更具体。

## 4. 本章新增 / 修正的世界观

- **拉海洛**：索拉里斯极地地区，主要文明在地下发展；与地表Roya Frostlands、Solvein Heartwood、Voidmatter高度相关。
- **Voidmatter / 虚质**：3.x核心异常媒介之一，对空间、生物与频率产生强干涉。
- **Exostrider与Aleph-1**：第二次悲鸣后地区历史的关键存在，学院研究计划与其紧密相连。

## 5. 伏笔、回收与仍未解释的问题

- **漂泊者在学院的旧身份**：大量熟悉感与证据存在，但需逐版本确认其时间、关系和职责。
- **Aemeath为何重复出现/记忆错位**：3.0只铺垫，3.1成为核心。
- **Aleph-1真实目标与性质**：不能仅凭“Threnodian”标签把全部动机写死。

## 6. 主题与叙事作用

3.0把鸣潮的失忆主线从“别人告诉你你曾是伟人”推进到更尖锐的问题：如果你真的曾经在这里上课、交朋友、失败过，那么失去的不是一个称号，而是一段人生。
