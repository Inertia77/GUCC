## 0. 一页看懂

- **一句话**：第三章第五幕《Starlights from Yesterdays》把拉海洛长期积累的旧史、星海/远航计划与人物记忆推向阶段性高潮；多个Segue则把危机后的愿望、告别和梦州方向连接起来。
- **结构**：这是拉海洛篇的主要收束版本，不应只记成“周年剧情”。

## 1. 剧情发生前的局势

3.2结束暗面事件后，残星会更大计划仍悬而未决；埃梅斯、Exostrider、Roya与学院各自掌握的历史也需要在同一因果链上对齐。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. The Flaming Red from Tomorrow确认后续威胁

Lucilla与Hiyuki的对话直接表明，暗面事件不是终点，残星会还在筹备更危险行动。
### 2. Wishes in the Bell让愿望/记忆进入舞台化空间

Hiyuki等通过一连串“记录/演出/回看”接触Grand Architect留下的信息，过去被转译成可观看、可穿行的结构。
### 3. Starlights from Yesterdays回收拉海洛核心旧史

学院、星海、远航和过去人物关系被重新拼合。标题强调“昨日的星光”仍能照到现在，和本章记忆主题一致。
### 4. 主要危机得到阶段性解决

玩家不是把所有异常机制一劳永逸消除，而是让拉海洛获得继续研究与生活的空间。
### 5. Beneath a Melting Night Sky转向Denia等人的恢复

雪开始“融化”的意象把宏大危机落回人的康复、相处和未来计划。

## 3. 主要人物弧线

### Hiyuki

从情报/过渡角色变成承接历史记录与新地区方向的重要桥梁。
### Denia

后日谈通过身体/梦境恢复展示危机真正结束的标准：不仅Boss停止行动，受影响的人也要重新生活。
### 漂泊者

对旧日学院关系获得更多确认，但同时准备离开，重复“知道更多过去以后仍继续向前”的结构。

## 4. 本章新增 / 修正的世界观

- **记录型空间/回声**：过去可以通过频率、影像、梦境被重新访问，但“重现”不应自动等于完全客观历史。
- **拉海洛阶段性结局**：第三章到此完成主体收束，为梦州第四章切换做准备。

## 5. 伏笔、回收与仍未解释的问题

- **残星会更高层目标**：地区行动被挫败不等于组织终局。
- **Hiyuki与梦州/后续角色联系**：在过渡中逐渐明确，3.5正式进入第四章。

## 6. 主题与叙事作用

3.3处理的是“告别一个研究过过去的地方”。拉海洛教会漂泊者：历史不是为了把人困回旧身份，而是让现在的人知道哪些失败不必再重复。
