# 绝区零｜世界观与主线总览

> 校对日期：2026-08-25  
> 用途：在读任何版本章之前，先解决“这个世界怎么运转、主角为什么卷进来、故事到底在追什么”。

## 1. 一句话主轴

灾后都市新艾利都把“空洞”从末日异常驯化成日常基础设施、产业与职业体系；法厄同兄妹一边以传奇绳匠身份处理街区委托，一边追查旧都陷落、自己的过去、异常力量以及被城市制度掩盖/保存的历史。

## 2. 世界运行规则

- **空洞**：吞噬并重构现实空间的异常区域，伴随以太环境与空间路径变化。
- **以太侵蚀 / 以骸**：长期或高强度暴露可造成身体与认知异化；侵蚀不是单纯“感染值”，还会被人为利用。
- **绳匠与代理人**：绳匠提供路径和情报，代理人负责现场行动；法厄同通过伊埃斯/HDD形成特殊远程介入方式。
- **邦布**：城市人工智能/自动化体系的重要载体，不只是陪伴物。
- **虚狩**：新艾利都历史中的顶级空洞行动者与公共英雄符号，既有战力意义，也有政治/社会记忆意义。
- **牲鬼 / 人为高阶侵蚀**：第一季后半证明人类势力能主动推动危险异化。
- **梦 / 数据 / 记忆**：第二季从昔丘梦境推进到第三季罗塞塔数据，逐渐成为比“谁打赢”更重要的身份问题。

## 3. 主角 / 玩家身份

哲与铃共享传奇绳匠「法厄同」身份，以Random Play录像店掩护地下工作。第一季末，两人出现超出传统绳匠定义的异常能力；第二季前往卫非地拜仪玄为师并研究自身力量；第三季抵达罗斯凯利法，开始面对“主角自身也可能是旧技术/旧历史产物”的更深问题。

资料库不把主角代理人战斗形态、绳匠身份、个人本体简单合并为一个未经解释的设定，必须按版本分别记录。

## 4. 主线阶段

- **第一季 1.0–1.4**：六分街→狡兔屋→白祇→维多利亚→外环→对空六课，多阵营建立，最终合流到布林格/牲鬼与旧都阴谋。
- **第一季尾音 1.5–1.7**：舞台/反舌鸟/称颂会，薇薇安、雨果、莱卡恩旧账与主角异常能力显现。
- **第二季 2.0–2.8**：卫非地、辉瓷产业、梦与昔丘、叶瞬光虚狩之路、新·艾利都日落时；主题从“力量来源”扩展到“过去是否支配现在”。
- **第三季 3.0起**：罗斯凯利法/天之算枢、罗塞塔数据、人格与记忆技术、初代虚狩蕾米埃尔。

## 5. 当前剧情位置

截至2026-08-25，当前实装3.1「漫长的告别」，版本持续至2026-09-09 06:00。3.2尚未实装，任何未来剧情只能列为观察项。

## 6. 长期主题

- **身份与表演**：绳匠、卧底、管家、明星、怪盗、英雄、数据人格都在问“社会给的角色是不是你”。
- **城市如何消费灾难**：空洞既是危险也是经济来源，辉瓷、工程、武器、娱乐和英雄神话都可能建立在灾难上。
- **代价伦理**：庞培、薇薇安、叶瞬光等线持续反对把具体人默认写进“大局需要”的成本项。
- **记忆与主体性**：第二季梦境、第三季数据让“记得一个人”与“那个人仍存在”逐渐分离。

## 7. 阅读时最容易踩的坑

- 不要把所有以骸化都写成同一种原因；自然侵蚀、药物/技术推动、仪式等需要区分。
- 不要把虚狩只做战力榜；它还是公共历史身份。
- 梦、录像、罗塞塔数据都可能保存信息，但不能未经文本证明就当完整客观历史。
- 官方前瞻节目包装常明确说明与原作无关，必须排除出剧情证据。
