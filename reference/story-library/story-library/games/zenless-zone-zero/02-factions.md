# 绝区零｜阵营与权力关系

> 校对日期：2026-08-25

## 法厄同 / Random Play

- **公开目标**：维持正常生活、接委托、帮助合作伙伴并追查兄妹过去。
- **实际关切 / 隐藏议程**：法厄同身份必须隐藏；Fairy、HDD与主角异常力量都可能引来更高层关注。
- **主要资源**：绳网声望、伊埃斯/HDD、Fairy、跨阵营关系网。
- **关键人物**：哲、铃、Fairy。
- **关系**：与狡兔屋、白祇、六课、云岿山等长期合作。
- **剧情变化**：从幕后导航者逐渐成为第三季直接卷入身份/数据问题的主体。

## 狡兔屋

- **公开目标**：接委托赚钱并让团队活下去。
- **实际关切 / 隐藏议程**：看似逐利，实际有稳定道德底线。
- **主要资源**：街头情报、代理人战力、人脉。
- **关键人物**：妮可、安比、比利、猫又。
- **关系**：法厄同最早且最稳定的朋友团队。
- **剧情变化**：从第一章雇主/客户关系转为城市危机中的老朋友网络。

## 白祇重工

- **公开目标**：工程建设与企业生存。
- **实际关切 / 隐藏议程**：霍尔斯旧事故和企业声誉长期影响决策。
- **主要资源**：工程机械、工业技术、施工团队。
- **关键人物**：珂蕾妲、格莉丝、安东、本。
- **关系**：与法厄同合作；与企业竞争/旧事故线相关。
- **剧情变化**：第一季完成家族与企业责任的重新评价。

## 维多利亚家政

- **公开目标**：为雇主提供高规格服务及异常处理。
- **实际关切 / 隐藏议程**：成员和雇主网络都比“家政公司”表面复杂。
- **主要资源**：高水平代理人、情报、礼仪身份掩护。
- **关键人物**：莱卡恩、丽娜、艾莲、可琳。
- **关系**：与法厄同友好；莱卡恩与反舌鸟旧关系复杂。
- **剧情变化**：1.6–1.7被迫正面面对莱卡恩过去。

## 新艾利都治安局 / 刑侦特勤组

- **公开目标**：维持治安、打击空洞相关犯罪。
- **实际关切 / 隐藏议程**：会采用卧底等高风险非常规手段，内部信息并非完全共享。
- **主要资源**：执法权、调查系统、专业人员。
- **关键人物**：朱鸢、青衣、简等。
- **关系**：与法厄同既合作又处于合法性灰区。
- **剧情变化**：从普通治安伙伴逐步介入牲鬼和城市级阴谋。

## 对空六课

- **公开目标**：处理高危空洞与异常事件。
- **实际关切 / 隐藏议程**：成员的家族、身体、过去与虚狩体系带来额外压力。
- **主要资源**：顶级战力、官方情报、专业调查。
- **关键人物**：星见雅、月城柳、浅羽悠真、苍角。
- **关系**：法厄同重要官方盟友。
- **剧情变化**：1.4后成为城市级异常应对核心之一。

## 卡吕冬之子 / 外环势力

- **公开目标**：运输、生存、维护外环共同体。
- **实际关切 / 隐藏议程**：霸主头衔既是荣誉也是资源与政治责任。
- **主要资源**：车队、外环路线、人脉。
- **关键人物**：凯撒、露西、柏妮思、派派、莱特。
- **关系**：与法厄同盟友。
- **剧情变化**：1.2完成新霸主秩序。

## 云岿山 / 随便观

- **公开目标**：修行、守护卫非地并处理空洞异常。
- **实际关切 / 隐藏议程**：仪玄等人掌握部分旧都/主角能力线索。
- **主要资源**：修行体系、虚狩级战力、本地社会网络。
- **关键人物**：仪玄、橘福福、潘引壶等。
- **关系**：第二季主角师门/长期盟友。
- **剧情变化**：2.0起成为法厄同理解自身力量的关键组织。

## TOPS / 辉瓷产业与企业网络

- **公开目标**：控制生产、技术、商业利益。
- **实际关切 / 隐藏议程**：不同企业与部门立场不同，不能整体反派化。
- **主要资源**：资本、辉瓷技术、供应链。
- **关键人物**：以各版本企业代表为准。
- **关系**：与防卫军、本地居民、云岿山存在利益交叉。
- **剧情变化**：2.1后产业政治成为主线背景。

## 称颂会及相关残余

- **公开目标**：以仪式/信念方式推动其异常目标。
- **实际关切 / 隐藏议程**：组织层级、牲鬼技术来源与更高层联系未完全公开。
- **主要资源**：信徒、仪式、异常药物/技术线索。
- **关键人物**：卡米尔、蒂娜及其他成员。
- **关系**：与主角及多方敌对。
- **剧情变化**：1.6–2.x持续留下残余影响。

## 罗斯凯利法 / 天之算枢

- **公开目标**：维持罗塞塔数据长期稳定产出并运行空域机密特区。
- **实际关切 / 隐藏议程**：数据目的如何影响居民身份、历史保存和伦理仍在第三季展开。
- **主要资源**：高度数据化基础设施、研究/医疗系统、机密权限。
- **关键人物**：维琳娜、诺姆、当地管理与研究者。
- **关系**：法厄同当前调查舞台。
- **剧情变化**：3.0起从目的地变成整个第三季核心制度。
