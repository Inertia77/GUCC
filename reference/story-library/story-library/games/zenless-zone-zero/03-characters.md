# 绝区零｜核心人物与人物弧线

> 校对日期：2026-08-25

这不是角色名册；只收录对主线因果、阵营变化或长期谜团有实质影响的人物。

## 哲 / 铃

- **身份 / 位置**：录像店经营者、传奇绳匠法厄同的共同主体。
- **核心欲望**：保护彼此与朋友，并查清旧都/自身过去。
- **核心恐惧 / 矛盾**：身份暴露、对方被卷入不可逆风险、自己成为旧计划的工具。
- **关键选择**：从接单求生逐步选择主动离开新艾利都追查真相。
- **重要关系**：彼此是最核心关系；狡兔屋、云岿山等构成长程盟友。
- **当前状态**：3.1罗斯凯利法。
- **仍未解释**：异常力量、过去身份、Helios关联、为何被Fairy选中。
