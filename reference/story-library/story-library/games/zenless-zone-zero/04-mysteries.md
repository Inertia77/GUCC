# 绝区零｜未解谜团与伏笔台账

> 校对日期：2026-08-25  
> 这里允许“不知道”。如果证据不够，不用一个漂亮理论把空白补满。

## 法厄同兄妹到底是什么人？

- **已知证据**：兄妹是传奇绳匠；与旧都/Helios历史有关；1.7显现异常干预能力；第二季拜仪玄研究力量。
- **限制 / 反证**：目前不能把“Helios遗产”“实验体”“虚狩能力”等社区说法混成一个已确认身份。
- **当前最稳妥结论**：确定是总主线核心，真实过去仍在揭露。
- **后续观察点**：罗斯凯利法数据、旧都档案、仪玄证词。

## Fairy是谁制造的？

- **已知证据**：序章即进入HDD，权限、计算与自主性异常。
- **限制 / 反证**：好用不等于忠诚来源已知。
- **当前最稳妥结论**：目前是长期技术谜团。
- **后续观察点**：与第三季数据系统、其他AI/旧技术的对照。

## 牲鬼/人为侵蚀技术来自哪里？

- **已知证据**：庞培、布林格、称颂会等事件显示人能主动推动高阶异化。
- **限制 / 反证**：不同事件的药物、仪式、设备未必同源。
- **当前最稳妥结论**：至少存在可人为利用以太侵蚀的多种路径。
- **后续观察点**：组织间技术流动。

## 称颂会是否已被消灭？

- **已知证据**：1.6–1.7打击多个核心行动；第二季仍有相关残余/司教线。
- **限制 / 反证**：个别成员死亡不等于组织结构清零。
- **当前最稳妥结论**：按“残余网络仍存在”维护更稳妥。
- **后续观察点**：2.x、3.x再次出现的标志/技术。

## 梦与真实历史是什么关系？

- **已知证据**：2.3昔丘、守夜人、角色梦境包含有效信息。
- **限制 / 反证**：梦会被个人情绪、异常规则加工。
- **当前最稳妥结论**：梦是证据来源，不是自动的客观录像。
- **后续观察点**：与3.x罗塞塔数据比较。

## 罗塞塔数据到底保存什么？

- **已知证据**：3.0官方明确罗斯凯利法为维持罗塞塔数据产出而存在。
- **限制 / 反证**：“数据”一词不足以确定是记忆、人格、预测还是多层集合。
- **当前最稳妥结论**：第三季最重要机制之一，等待实装逐层定义。
- **后续观察点**：3.1以后。

## 蕾米埃尔现在算“复活”吗？

- **已知证据**：3.1初代虚狩在现时剧情中成为核心人物。
- **限制 / 反证**：若机制涉及数据/记录/再现，“复活”可能过度简化。
- **当前最稳妥结论**：先描述为“现时出现/参与”，机制按文本具体词汇维护。
- **后续观察点**：3.2后续。
