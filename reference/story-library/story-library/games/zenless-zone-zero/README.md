# 《绝区零》Story Library｜v3 深档案

> 当前校准：2026-08-25  
> 当前已实装主线：3.1「漫长的告别」  
> 维护目标：不是做剧情标题索引，而是把每章写成可以直接用于复盘、人物研究、世界观考据和视频选题的长期档案。

## 阅读入口

建议按需求进入：

- 想快速建立全局：`00-overview.md`
- 想按世界/版本顺序重温：`01-timeline.md`
- 想查组织：`02-factions.md`
- 想查人物动机和关系：`03-characters.md`
- 想知道还有什么没解释：`04-mysteries.md`
- 想从剧情做内容：`05-video-hooks.md`
- 想完整复盘某章：进入 `versions/` 对应正式版本章

## v3相较上一版改了什么

上一版已经解决“缺版本文件”的问题，但很多章仍只有3–4KB，更接近高质量提纲。v3把 **1.0序章至3.1共22个正式剧情章**全部重写，统一要求：

```text
一句话结论
→ 剧情前置局势
→ 具体事件链
→ 角色为什么这么做
→ 阵营/关系如何改变
→ 新增世界观
→ 哪些伏笔被回收
→ 哪些仍不能写死
→ 容易误读的地方
→ 主题
→ 与前后章连接
→ 来源
```

兼容旧链接的短文件仍保留，但主导航不再把它们当正式正文。

## 事实等级

- **【官】**：游戏内文本、任务、官方版本资料直接确认。
- **【证】**：多个已实装文本能稳定拼合出的事实。
- **【推】**：有较强证据，但后续仍可能反转的解释。
- **【未】**：剧情明确抛出、当前尚未解释。

### 两条硬规则

1. **角色后来反转，不删除早先行为。** 例如叶释渊后来确认有保护妹妹的动机，也不代表他与莎拉同行、隐瞒计划和擅自决定自我牺牲没有发生。
2. **瘴气、梦、记忆重构有情报价值，但不是客观录像。** 2.3之后尤其需要区分“看见过”与“历史确定发生过”。

## 当前主线结构

### 第一季｜新艾利都：从城市案件走向始主

1.0首先建立法厄同、狡兔屋和新艾利都社会；远景案显示企业能利用空洞牺牲边缘居民；白祇篇第一次留下牲鬼级异常样本；维多利亚篇继续追珀尔曼与莎拉。1.2外环把卡萝尔·阿娜与兄妹旧都调查正式推到台前。1.3窃取星见雅数据，1.4回收为布林格/妖刀/精炼计划，并让卡萝尔旧案与“始主”第一次直接连上。1.6–1.7把牲鬼从神秘怪物升级为可通过人体实验制造、提取核心、交易利用的技术体系。

### 第二季｜卫非地：从牲鬼实验走到结使

2.0洛尔用“缓解水”把真实医疗需求转化为实验入口；2.1追到儿童实验Project New Leaf；2.2揭出军方/企业身份与赞颂会监督者重叠；2.3用梦和瘴气处理个人创伤，同时抓到叶释渊/莎拉继续深入始主的线索；2.4–2.5围绕青溟剑完成叶氏兄妹主线，始主反向利用莎拉、瘴气、矿物与Sunbringer力量制造结使。2.7–2.8回到外环，并把危险从“别人被改造成怪物”转到法厄同自己身上：Thaumiel触发主角失控，病因最终指向赫利俄斯，罗斯凯利法成为第三季入口。

### 第三季｜罗斯凯利法：治疗自己，也重新审判历史

3.0建立空域机密特区、罗塞塔数据、邦布公民社会与记忆处理制度；赫利俄斯旧同学Trivia、Serpico等让主角失去的过去重新变成人际问题。3.1通过初代虚狩蕾米埃尔，把2.5的“结使”接回百年前黑墙战争、业核、日耀者与虚狩历史。当前仍未解决Serpico真实状态、日耀者历史分化、主角体内两股力量准确来源等核心谜团。
