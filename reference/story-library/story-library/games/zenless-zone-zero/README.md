## 资料可信度

一手优先：游戏内主线与独家视界、绝区零官网版本公告；完整剧情录屏用于核对章节顺序和过场。预告包装明确标注“与原作无关”的内容不得当剧情事实。

任何“角色自己说的话”都不自动等于客观事实；任何“预告里出现的画面”也不自动等于已经发生的剧情。资料库优先保留不确定性。
