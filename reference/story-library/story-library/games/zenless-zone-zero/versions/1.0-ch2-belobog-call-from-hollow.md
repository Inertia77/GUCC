## 0. 一页看懂

- **一句话**：白祇重工的工程危机把珂蕾妲与父亲霍尔斯留下的声誉、企业债务和旧空洞事故重新绑在一起；调查证明“工程事故”背后往往有人为操纵，而一个人的失踪不能被简单等同于背叛。
- **核心关系**：珂蕾妲真正继承的不是父亲的公司头衔，而是“是否愿意继续为别人负责”的问题。

## 1. 剧情发生前的局势

白祇重工在旧事故和前任负责人霍尔斯失踪后承受声誉与经营压力。年轻的珂蕾妲必须一边维持公司、一边面对父亲被外界视为逃跑者的评价。法厄同被卷入工程区空洞事件。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 白祇重工在施工中遭遇异常

工程机械和空洞环境共同制造高风险。公司成员对设备有极强情感联系，这不是笑点而已，而是工程团队把生计和身份都押在项目上。
### 2. 珂蕾妲的父亲问题重新浮出

霍尔斯过去的决定影响现在的公司信誉。珂蕾妲表面强硬，实际一直被“父亲是否抛弃公司和自己”困住。
### 3. 工程记录与现场事实逐渐冲突

调查让团队意识到旧事故不能只用“负责人失职”解释。机械、空洞和人为因素之间存在更复杂因果。
### 4. 白祇成员选择共同承担

本、安东、格莉丝等人的忠诚不是对企业logo，而是对共同工作的人。团队关系帮助珂蕾妲把继承从个人羞耻转成公共责任。
### 5. 霍尔斯形象被重新评价

主线没有把所有旧事一次解释完，却足以动摇“逃犯/骗子”的单一叙事，并把企业与旧都灾害更大秘密连接起来。

## 3. 主要人物弧线

### 珂蕾妲

从拼命证明自己不是父亲，到开始允许自己重新理解父亲；成长不是原谅一切，而是能基于新证据重写自己的判断。
### 格莉丝

把工程机械当近似生命伙伴的态度，让白祇线拥有“技术是否只是工具”的温度。
### 本与安东

代表企业内部的互助文化，证明白祇在资本逻辑之外还有工人共同体属性。

## 4. 本章新增 / 修正的世界观

- **空洞工程**：新艾利都能继续建设，依赖在高风险区域施工、开采、运输的组织。
- **工程记录与事故责任**：官方记录、企业叙事和现场事实可能不一致，后续旧都线继续扩大这种证据冲突。

## 5. 伏笔、回收与仍未解释的问题

- **霍尔斯失踪的完整原因**：第一季逐步补充，但在本章不应写成全部已解。
- **白祇事故与更大旧都阴谋的连接**：本章提供入口而非终局。

## 6. 主题与叙事作用

白祇篇最重要的是“继承不是复制上一代”。珂蕾妲需要继承责任，但不必继承外界给父亲的结论，也不必用父亲的方式管理公司。
