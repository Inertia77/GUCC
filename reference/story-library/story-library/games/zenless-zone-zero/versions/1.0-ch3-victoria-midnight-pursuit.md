## 0. 一页看懂

- **一句话**：维多利亚家政与法厄同在芭莱大厦相关空洞中追踪目标，优雅的“家政服务”外壳下是一支训练有素的高危异常处理团队；旧建筑与空洞重叠让城市记忆变成真正的危险空间。
- **长期意义**：莱卡恩的过去、维多利亚的雇主关系、旧都建筑与牲鬼/更高层阴谋在这里开始留下可追踪接口。

## 1. 剧情发生前的局势

前三章逐渐把故事从六分街扩大到企业和大型空洞。维多利亚家政表面执行服务委托，成员却都有战斗与异常处理能力；他们对“主人/委托人”的服从也存在职业边界。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 进入芭莱大厦相关空洞

废弃建筑在空洞环境中被重构成压迫性迷宫。空间本身承载旧城市生活痕迹，使探索不仅是找路，也是在穿越灾难留下的城市尸骸。
### 2. 维多利亚成员逐步显露专业性

莱卡恩、丽娜、艾莲、可琳的工作方式各异，但团队协同高度成熟。所谓“家政”既是品牌，也是隐藏真实能力的社会身份。
### 3. 追踪目标与多方目的交叉

法厄同并不是唯一在空洞里找东西/找人的一方。不同委托方的信息差让同一地点同时承载多条行动线。
### 4. 莱卡恩表现出对旧关系的回避

他的过去没有在1.0一次说完，但对某些人物/事件的态度说明维多利亚团队成员各自背负比当前工作更长的历史。
### 5. 危楼事件阶段性结束

团队救出目标并离开，但“旧建筑为什么被特定势力反复利用”“谁在追逐更高价值异常资源”等问题继续进入后续。

## 3. 主要人物弧线

### 冯·莱卡恩

以完美管家身份压住过去；其与雨果等旧关系在1.6–1.7才真正展开。
### 丽娜

温柔服务者与高危战斗者并存，代表维多利亚“礼貌不等于无害”。
### 艾莲

高中生日常与专业代理人工作并置，是游戏“灾后日常化”的典型人物。

## 4. 本章新增 / 修正的世界观

## 6. 主题与叙事作用

第三章把“职业扮演”推到极致：最像在演角色的一群人，反而在危险中表现得非常真实。优雅制服、礼仪和称呼都是社会面具，但人与人之间的忠诚不能仅用面具解释。
