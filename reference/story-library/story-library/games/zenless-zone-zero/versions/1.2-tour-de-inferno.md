## 0. 一页看懂

- **一句话**：外环的“霸主”制度、运输资源与机车文化把城市边缘秩序完整展开；凯撒必须在权力、团体和个人尊严之间证明自己，而庞培的悲剧揭示以太侵蚀可以被人类阴谋刻意推到最坏结果。
- **关键结果**：卡吕冬之子在外环站稳，法厄同得到重要旧都线索/人物接口；“人主动制造牲鬼”成为后续主线越来越重要的威胁模型。

## 1. 剧情发生前的局势

外环不像市中心依赖完整行政系统，运输车队、帮派和“霸主”声望构成另一套秩序。卡吕冬之子年轻而内部关系紧密，凯撒需要面对其他势力对其资格的质疑。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 法厄同来到外环并接触卡吕冬之子

这次旅行让玩家第一次系统看到新艾利都城市核心之外的资源运输与荒野社会。
### 2. 霸主之争从竞技升级为政治冲突

争夺并不只是比赛冠军，而关系到路线、资源、组织合法性和谁能代表外环。
### 3. 庞培与凯撒形成两代领导者对照

庞培拥有声望与经验，凯撒则在被视为年轻/不成熟的情况下证明自己。两人的关系让后续悲剧更具重量。
### 4. 卢修斯等人的操纵把对手推向以骸化

人为因素将以太侵蚀变成政治武器。庞培的“怪物化”不是他本人的道德堕落，而是他被利用后的身体灾难。
### 5. 凯撒完成火狱骑行并承担霸主位置

她赢得的不是单纯头衔，而是必须对整个外环共同体承担责任。
### 6. 法厄同获得通向更大阴谋的线索

外环故事与旧都/牲鬼相关暗线接轨，说明季节篇章并非互不相干的阵营单元剧。

## 3. 主要人物弧线

### 凯撒

从热血领头人变成理解“霸主是责任”的领导者。她的强大更多表现为愿意为同伴承担风险，而不是支配他们。
### 庞培

典型悲剧人物：他的最终怪物形态不能反推他原本人格邪恶。
### 露西 / 柏妮思 / 派派 / 莱特

共同构成卡吕冬“吵闹但互相托底”的关系网。

## 4. 本章新增 / 修正的世界观

- **外环秩序**：新艾利都并非单中心城市国家，边缘地区有自己的经济和权威结构。
- **牲鬼/人为侵蚀前兆**：人类可以利用以太环境把他人推向高阶异化，这成为1.4以后核心阴谋线。

## 5. 伏笔、回收与仍未解释的问题

- **卢修斯背后关系**：个人阴谋与更大组织是否相连需后续证据。
- **庞培事件与布林格事件的技术连续性**：可比较但不能在无明确证据时写成同一实验批次。

## 6. 主题与叙事作用

外环篇讨论“领导资格从哪里来”。凯撒不是因血统或头衔天然正确，而是在最危险时仍愿意保护共同体，因此获得认可。
