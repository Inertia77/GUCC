# 1.3｜虚拟杀机 / Virtual Revenge

> 游戏：绝区零  
> 版本：1.3  
> 类型：特别剧集 / 对空六课线  
> 实装状态：已实装  
> 资料校对日期：2026-08-25  
> 剧透等级：全剧透

## 0. 一页看懂

1.3当时看像一篇独立的“对空六课被黑客困进虚拟系统”特别剧集；真正到1.4之后才知道，它其实是莎拉计划的**数据采集前置**。

Null_Face 对柳、雅和对空六课的攻击并不只为了制造网络恐怖事件。后续揭示，他受莎拉一方利用/雇佣，重点收集星见雅的深层感官、生物与战斗数据。为什么非得是雅？因为星见家与妖刀“无尾”之间存在特殊血脉限制，正常情况下外人无法轻易复制她的使用条件；而1.4幕后者正需要绕开这些限制。

因此1.3最重要的阅读方式是：**先记录当时角色知道的“虚拟袭击”，再单独记录1.4回看后确认的“这是窃取雅数据”。** 不要反向写成柳从一开始就知道莎拉目的。

## 1. 对空六课的组织状态

对空六课是处理高风险空洞事务的精英单位，星见雅既是核心战力，也是拥有特殊家系与武器体系的人。

月城柳在队伍里的位置尤其关键：她未必是火力最高的人，却承担大量现场判断、协调和在队友失常时维持组织运作的任务。

所以让“数据、感知与现实判断本身”成为战场，实际上正好把柳推到最适合的主角位置。

## 2. Null_Face 的攻击为什么危险

虚拟系统的威胁不只是“电脑中病毒”。当战斗者的意识、感官和行动数据都进入可操控环境时，攻击者可以：

- 伪造空间与敌人；
- 利用成员彼此认知制造误判；
- 记录非常细的战斗反应；
- 在成员认为自己只是在逃生时持续采样。

这使得“成功脱困”与“没有被偷走东西”成为两回事。

## 3. 主线事件链

### 3.1 对空六课进入异常虚拟事件

柳等人发现信息系统/虚拟环境遭到攻击。最初目标很直接：确认成员状态、恢复控制、找到幕后入侵者。

### 3.2 现实与虚拟的边界被主动模糊

Null_Face 不断利用虚假信息迫使成员作出判断。对战斗精英而言，最危险的不是看不见敌人，而是**看见的敌人可能是系统故意给你的。**

### 3.3 柳成为维持团队“现实锚”的人

柳的强项是把分散信息重新组合成可验证判断。她需要不断分清：

- 哪些是队友真实反应；
- 哪些是对方根据行为模型制造的诱导；
- 哪些风险即使可能是假的也不能忽略。

### 3.4 团队脱困，但攻击者并非一无所获

对空六课最终解决眼前虚拟危机。按1.3当时视角，这可以算任务成功。

但1.4回看后必须追加：Null_Face 已经完成了对雅高价值数据的采集，这些数据被用于更深计划。

## 4. 星见雅为什么成为目标

雅不是因为“全服最强所以被研究”这么简单。

她背后的星见家、妖刀无尾以及血脉约束共同构成特殊权限。幕后者如果想让其他个体突破这套限制，就需要非常具体的身体/感官/使用者数据，而不是网上战斗录像。

因此Null_Face的虚拟入侵本质上像一次**无创但极深的生物与行为扫描**。

## 5. 柳的人物弧线

1.3让柳从“雅身边可靠副手”变成真正独立的决策者。

她所面对的问题不是能否替雅击败强敌，而是：当最可靠的数据来源都可能被伪造时，自己还凭什么下判断？

答案来自她对队友行为、任务原则和可验证事实的理解。这让柳的角色核心非常明确：她是对空六课的组织理性。

## 6. 后续回看：莎拉的长线思维

【证】1.4揭示Null_Face行动与莎拉针对雅/无尾的计划有关。

这说明莎拉并不总直接制造大灾难。她会先做：

1. 情报收集；
2. 条件验证；
3. 找到绕过限制的方法；
4. 再把政治、执法和实验条件同时推到位。

这与她在远景、珀尔曼、布林格等事件中的风格一致。

## 7. 容易误读

### “1.3是无关主线的VR番外”——后来看不是

它是1.4妖刀/雅计划的数据准备阶段。

### “Null_Face目标是击败雅”——重点不在胜负

只要采集到需要的数据，即使对空六课最终脱困，幕后者也能达到部分目的。

### “柳知道自己被拿去做1.4计划”——当时并不知道

资料库要把后见之明与角色当时认知分开。

## 8. 主题

**信息战里，活下来不一定等于赢。**

对空六课击退了眼前攻击，但直到下一章才发现真正被夺走的是可复制、可利用的个人数据。
