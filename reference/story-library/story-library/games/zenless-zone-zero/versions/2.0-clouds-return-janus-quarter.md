# 2.0｜云霞同归处 / 卫非地开篇

> 版本：2.0  
> 定位：第二季第一章

> 资料校对日期：2026-08-25

## 0. 一页看懂

2.0的真正转折，是法厄同第一次从“追查赞颂会留下的案件”进入**赞颂会正在持续经营的实验区**。

市长一方委托铃与哲前往卫非地半岛调查莱姆尼安空洞异常，同时一张与卡萝尔·阿娜有关的旧照片把私人旧都线直接带到这里。兄妹在仪玄门下登记、接触云岿山体系后，逐渐发现瓷偶/瓷实业（Porcelumex）相关劳资冲突和“缓解水”并非单纯地方社会问题：洛尔医生以“降低侵蚀”为名给工人发药，药物却会让目标更容易被以太/瘴气推向异常转化。

Paulo等人的遭遇证明，所谓医疗救济其实是实验筛选和制造牲鬼/仪式材料的手段。洛尔最终被确认与赞颂会有关，并向莎拉、Mevorakh等更高层汇报。法厄同还在异常中看见/听见与卡萝尔有关的幻象信息——“倾听、理解、真相”——但【未】这种显现究竟是卡萝尔本人、始主诱导、环境记忆还是别的机制，当时不能直接写死。

2.0由此确立第二季核心：**卫非地的瘴气不是单纯新地图机制，而是敌人可以用来放大愿望、痛苦和人体转化的介质。**

## 1. 法厄同为什么来卫非地

第一季结束后，兄妹已经知道赞颂会在进行牲鬼相关人体实验，但仍缺乏上游网络。

市长方面提供的新任务同时满足两个目标：

- 公共任务：调查莱姆尼安空洞及卫非地异常；
- 私人目标：追查照片中卡萝尔相关线索。

所以第二季不是突然换地图，而是第一季“卡萝尔—始主—人体实验”线自然向更接近源头的地区延伸。

## 2. 为什么要拜入云岿山/仪玄体系

卫非地有自己的地方组织、空洞经验和武学/术法体系。法厄同不能只靠新艾利都的绳匠名声通行。

仪玄与云岿山提供两种帮助：

1. **在地身份与关系网**：让兄妹能进入地方事务核心。
2. **理解瘴气的新知识**：第二季敌人并不只使用标准以太侵蚀，传统空洞经验不足以解释全部现象。

仪玄因此不只是“第二季导师角色”，而是世界观知识接口。

## 3. 地方矛盾：工人为什么会相信“缓解水”

瓷实业/相关产业造成的劳动压力、环境风险和不信任，让工人非常需要一个能立刻缓解以太侵蚀的方法。

洛尔正是利用了这种真实需求。

这点很重要：如果药物只是“邪教毒药”，受害者显得愚蠢；实际更接近：

- 官方/企业保护不足；
- 工人已经承受长期身体风险；
- 洛尔以医生身份提供看似有效的解决方案；
- 对绝望者来说，拒绝药物反而像拒绝唯一希望。

赞颂会最危险的地方，就是把真实社会痛苦变成实验入口。

## 4. “缓解水”的真正作用

【证】洛尔宣称药物可缓解侵蚀，但实际会让部分人更容易进入异常状态。

Paulo等案例表明：受害者并不是自然病情恶化，而是被有意识挑选/处理。

这与第一季牲鬼实验形成技术延续：

- 第一季确认可以人为把人体推向极端以太状态；
- 2.0开始出现更适合批量接触普通人的药物/医疗渠道；
- 瘴气又进一步放大精神和物理变化。

## 5. 主线事件链

### 5.1 进入卫非地并取得地方身份

法厄同接触仪玄、云岿山及本地势力，开始调查莱姆尼安空洞异常。

### 5.2 工人抗议与企业矛盾浮现

地方对瓷实业等大型组织存在明显不满。这个现实冲突为洛尔提供了“站在受害者一边”的可信外观。

### 5.3 洛尔分发缓解水

药物被包装为医疗援助，受害者主动服用。

### 5.4 侵蚀恶化与人体异变

包括Paulo在内的受害者出现严重异常，团队开始怀疑药物与赞颂会实验存在联系。

### 5.5 城内基地/实验线被发现

调查证明敌人并非路过卫非地，而是在这里经营长期据点、筛选受试者并准备更大的仪式。

### 5.6 洛尔与上级联系暴露

洛尔向莎拉/Mevorakh等更高层汇报，说明第二季敌人有明确组织层级。

### 5.7 基地撤入空洞，追查转入更深区域

赞颂会在暴露后撤离/转移，并没有因一个据点被破坏就结束。

### 5.8 卡萝尔幻象出现

法厄同在异常状态中获得与卡萝尔有关的信息：“Listen / Understand / truth”类提示。

这里必须标成【未】解释机制，而不是直接写“卡萝尔灵魂在和主角说话”。

## 6. 莎拉与Mevorakh：敌方层级开始清楚

莎拉从第一季起就不断跨事件行动；2.0进一步证明她不是独立犯罪者。

Mevorakh则代表更高/另一层指挥接口。之后2.2会揭示其与Isolde身份、军方/瓷实业体系的复杂关系。

这让第二季的敌人结构从“莎拉+邪教徒”升级成：

> 赞颂会信仰/实验网络 + 企业设施 + 军事/行政关系 + 空洞仪式。

## 7. 瘴气为什么是第二季核心概念

瘴气能影响感知、情绪、记忆和实体战斗环境。更关键的是，它会与人的执念/愿望发生共振。

因此第二季多次出现：

- 过去创伤被具象化；
- 已死/旧时代人物似乎重新出现；
- 个体愿望被敌人利用；
- “看到的东西”既可能有真实信息，也可能被加工。

资料库从这里开始必须特别区分：**瘴气显现有信息价值 ≠ 显现内容全部是客观录像。**

## 8. 容易误读

### “工人喝假药是因为被骗得太蠢”——错误

这是敌人利用真实制度缺口和健康焦虑设计的社会工程。

### “卡萝尔幻象=卡萝尔本人确认活着”——不能下这个结论

显现来源未被完全证实。

### “2.0只是拜师+新地图开场”——远远不止

它建立了第二季完整实验机制和敌方组织层级。

## 9. 主题

2.0的核心是：**当一个社会真正缺少解决方案时，伪装成解决方案的恶意最容易进入。**
