## 0. 一页看懂

- **一句话**：法厄同为理解1.7显现的异常力量，前往卫非地拜入仪玄门下；云岿山、随便观、澄辉坪、莱姆尼安空洞与“称颂会司教”把第二季的地域、修行体系和新敌对线同时建立。
- **关键变化**：兄妹第一次不只是用HDD解决别人的问题，而把“自己的身体/力量是什么”放进主线调查核心。

## 1. 剧情发生前的局势

1.7后，主角能力出现异常。卫非地又是辉瓷产地、莱姆尼安空洞观测与开发前线，拥有与市中心不同的本地组织。仪玄既是云岿山门主，也是被市长认可的虚狩级调查员，因此成为最有资格帮助兄妹理解力量的人之一。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 法厄同启程卫非地

从六分街离开并非旅游，而是为解决主角能力谜团。卫非地承担“新地图+主角研究”的双重功能。
### 2. 澄辉坪与随便观建立新日常

兄妹拜入仪玄门下，认识橘福福、潘引壶等人。新阵营不是临时战友，而逐渐成为类似第一季狡兔屋的长期关系网。
### 3. 莱姆尼安空洞危机暴露

当地繁荣依赖辉瓷与空洞开发，因此任何异常都会同时打击经济、居民安全与城市基础设施。
### 4. 称颂会司教等敌对因素浮现

第一季未清干净的组织性异常以新地区形式继续。敌人不只是“外来的坏人”，而会利用当地信仰、资源和灾害结构。
### 5. 仪玄以虚狩级能力参与关键战斗

她展示压倒性实力，也明确说明第二季并不是主角突然自己觉醒后一路无师自通。
### 6. 玄鸟归巢 / 与你同在等段落完成阶段性救援

当地当前灾兆得到控制，但“往昔祸影之末，今朝灾兆之始”明确提示第二季真正危机才刚开始。

## 3. 主要人物弧线

### 仪玄

既是强者也是师父。她对兄妹的价值在于能判断力量与风险，而不是替他们做所有选择。
### 橘福福

作为大师姐承担云岿山内部的人情与实践层面，让组织不只剩门主权威。
### 哲 / 铃

从秘密调查者变成“需要被研究/训练的人”，主客体位置首次明显反转。

## 4. 本章新增 / 修正的世界观

- **卫非地**：索思区隔海地区，历史使命与莱姆尼安空洞监测有关；辉瓷产业塑造经济。
- **云岿山 / 随便观**：修行体系与实际空洞调查结合，不应简单写成玄学门派。
- **称颂会延续**：第一季阴谋并未因1.7结束。

## 5. 伏笔、回收与仍未解释的问题

- **主角力量来源**：2.0只开启研究。
- **仪玄与旧都陷落的“约定”**：官方2.0文案直接暗示她与旧都人物/事件存在旧约，需后续逐条回收。

## 6. 主题与叙事作用

2.0把“修行”写成理解自身风险的过程：力量不是奖励，而是必须知道来源、代价和边界的责任。
