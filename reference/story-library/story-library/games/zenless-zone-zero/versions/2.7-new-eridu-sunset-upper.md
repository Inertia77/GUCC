## 0. 一页看懂

- **一句话**：第二季尾音把“英雄不死于往昔”反转成“往昔可能致英雄于死地”；南宫羽、希希芙等新角色与旧英雄/旧制度线汇合，证明公共记忆如果被操纵，同样能成为武器。
- **结构功能**：上篇负责让多个第二季阵营重新合流，把危机从卫非地局部推回整个新艾利都。

## 1. 剧情发生前的局势

2.5后第二季主危机看似稳定，2.6又恢复日常。但历史并未真正停止作用。官方2.7文案明确使用“而如今，往昔却致英雄于死地”，说明本章不是新反派随机登场，而是旧历史的反扑。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 旧英雄/旧事件叙事被重新激活

城市依赖英雄神话维持信心，但当历史被选择性讲述时，英雄本人也可能被过去吞噬。
### 2. 南宫羽等调查者切入

新的专业角色带来不同证据和方法，让法厄同不必只靠旧朋友圈解决所有问题。
### 3. 多阵营重新集结

对空六课、治安、云岿山、旧朋友等关系网在尾音阶段具有再次合流的条件。
### 4. 危机从个人记忆扩展到城市记忆

第二季前半的梦是个人/地区层面，到尾音时“新艾利都如何记住过去”本身成为冲突。
### 5. 上篇在日落前留下未完成局面

标题明确是上篇，关键真相和最终选择留给2.8。

## 3. 主要人物弧线

### 南宫羽

以理性/调查能力介入英雄叙事，提供不是“相信传说”而是“重构证据”的路径。
### 希希芙

更直接的生存/捕食式角色气质，与城市英雄话语形成反差。

## 4. 本章新增 / 修正的世界观

- **城市公共记忆**：纪念、英雄称号和旧事件档案可以影响当代政治与身份。
