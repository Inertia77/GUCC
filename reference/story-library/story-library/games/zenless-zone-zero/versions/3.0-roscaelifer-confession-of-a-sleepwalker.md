## 0. 一页看懂

- **一句话**：法厄同抵达独立于新艾利都市区的空域机密特区罗斯凯利法/天之算枢；这里为了持续产出“罗塞塔数据”而存在，数据、人格、奇迹芯片和“另一个自己”把主线从历史调查推进到身份复制/存续问题。
- **章节结构**：前往罗斯凯利法 → 天之算枢 → 对「症」诊疗 → 泄露奇点 → 拨开迷雾 → 拂去尘埃的天使。
- **核心问题**：如果一个系统能够保存、模拟甚至重构人的信息，“记得你”与“你仍然活着”是不是同一回事？

## 1. 剧情发生前的局势

2.8远行计划后，兄妹主动追索罗斯凯利法。官方确认该地是为维持罗塞塔数据长期稳定产出而存在的空域机密特区，也称“天之算枢”。3.0因此天然把数据治理、人格和城市旧史捆在一起。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 前往罗斯凯利法

主角离开熟悉的新艾利都城市生活，进入一个更加封闭、以科研/数据目标为存在理由的特区。
### 2. 天之算枢展示制度逻辑

城市并不是先有居民再有产业，而是为了罗塞塔数据目的被组织起来；这会改变居民、研究者和管理者对“人”的看法。
### 3. 对「症」诊疗把异常人格/身体问题医疗化

维琳娜等角色介入后，主线开始追问某些异常究竟是疾病、数据故障、人格分裂还是被人为制造。不同命名会决定处理伦理。
### 4. 泄露奇点让封闭系统失去边界

机密特区最大的安全神话被打破：数据只要能泄露，就会被复制、篡改、交换或武器化。
### 5. 拨开迷雾重组人物证词

多个角色对过去的记忆/身份理解并不一致。资料库必须把“本人相信什么”和“系统记录什么”分开。
### 6. 拂去尘埃的天使完成第一章阶段性救援

危机被控制，但标题“某个梦游者的自白”仍保留“另一个自己”与真实主体的长期问题。

## 3. 主要人物弧线

### 维琳娜

第三季第一章的重要医疗/异常研究接口；她面对的不只是“治好病人”，而是先判断谁拥有定义病症的权力。
### 诺姆

与罗斯凯利法本地生活和数据秩序连接，帮助主线不只从实验室视角看城市。
### 佩洛伊斯 / 主角代理人形态

主角从幕后绳匠进一步获得可战斗化表现，必须与“兄妹本体身份”分层记录，避免把系统表现简化成突然换职业。

## 4. 本章新增 / 修正的世界观

- **罗塞塔数据**：罗斯凯利法建立的核心目的之一；具体本体、采集方式和用途必须按后续文本细化。
- **天之算枢**：不是普通城市别称，而是围绕机密数据目标构建的特区制度。
- **人格/数据边界**：3.0开始把“另一个自己”变成客观技术问题。

## 5. 伏笔、回收与仍未解释的问题

- **梦游者是谁/“另一个自己”如何定义**：人物叙述与系统记录存在层级差异。
- **Helios遗产与罗斯凯利法的准确连接**：3.0继续推进但不能把所有技术都自动归Helios。
- **罗塞塔数据最终用途**：第三季后续关键。

## 6. 主题与叙事作用

3.0把第一季“身份秘密”、第二季“梦与记忆”升级成硬问题：如果记忆能被技术保存，身份还需要身体吗？如果复制了一套记忆，复制出来的是你、你的孩子，还是一个新的人？
