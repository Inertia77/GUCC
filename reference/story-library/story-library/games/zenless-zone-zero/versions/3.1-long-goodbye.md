## 0. 一页看懂

- **一句话**：初代虚狩蕾米埃尔与希格莉德加入第三季，把罗斯凯利法的数据/身份问题推向“一个传奇人物怎样被保存、召回、利用或真正告别”。
- **可核对章节段落**：帷幕之外的来客 → 回流区的嗯呢帮 → 舞伴的磨合期 → 在沉重而湿透的羽翼之下 → 被遗忘者的追忆 → 与你共赴罪渊 → 共犯圆舞曲 / 漫长的告别。
- **关键主题**：告别不是把过去删除，而是停止要求过去继续替现在工作。

## 1. 剧情发生前的局势

3.0已经建立罗斯凯利法是围绕罗塞塔数据运行的机密特区。3.1官方直接让“初代虚狩”蕾米埃尔进入现时故事；一位本应属于历史的人怎样出现，天然要求玩家区分本体、记录、延续、再现和社会记忆。

## 2. 主线流程：按因果而不是按“打了谁”来记

### 1. 帷幕之外的来客

外来人物/力量进入罗斯凯利法，让封闭特区无法继续只按内部规则解释异常。蕾米埃尔的出现本身就是历史闯入现在。
### 2. 回流区的嗯呢帮

故事回到城市底层与邦布行动，说明宏大虚狩线仍建立在具体地区和小型关系上。
### 3. 舞伴的磨合期

“舞伴”强调合作需要节奏匹配。新旧强者、主角和当地行动者不能只靠战力叠加，必须解决目标与信息差。
### 4. 在沉重而湿透的羽翼之下

羽翼意象对应承担、坠落与保护。角色开始正面面对蕾米埃尔/相关人物背负的历史重量。
### 5. 被遗忘者的追忆

第三季最关键证据段之一：谁被历史记录、谁被系统删除、谁仍能记得，直接决定人物身份与责任。
### 6. 与你共赴罪渊

角色不再把危险和罪责交给单一牺牲者承担，而选择共同进入最坏情境。与第一季“没有谁该成为代价”形成强烈回声。
### 7. 共犯圆舞曲与漫长的告别

最终收束不是恢复一个完美过去，而是让多方共同承担选择后果，给某段历史真正结束/转化的可能。

## 3. 主要人物弧线

### 蕾米埃尔

作为初代虚狩，她既是历史英雄，也可能被后人投射、调用和重新解释。人物核心是能否从“公共遗产”重新成为有选择的人。
### 希格莉德

以骑士/战斗者姿态进入，但其价值不只保护强者，而在于与他人共同承担节奏和现实后果。
### 哲 / 铃

第三季越来越像主动参与者而非纯导航者；他们也必须面对“自己的旧身份是否同样会被别人保存成工具”。

## 4. 本章新增 / 修正的世界观

- **虚狩历史的技术保存**：3.1将“历史英雄”与罗斯凯利法数据技术放在同一舞台，必须逐条区分记忆、记录与实体。
- **被遗忘者**：遗忘可能是社会、系统、个人三种层面，不应混写。

## 5. 伏笔、回收与仍未解释的问题

- **蕾米埃尔现时存在的精确机制**：应以3.1文本为准，不用“复活”一个词粗暴覆盖所有可能。
- **罗塞塔数据与虚狩遗产**：后续是否能普遍保存/重构其他人物仍未知。
- **3.2下一章的敌我格局**：截至2026-08-25尚未实装；不得用测试服/前瞻反写3.1结论。

## 6. 主题与叙事作用

“漫长的告别”之所以漫长，是因为告别一个人往往不难，难的是告别一个社会已经依赖很久的神话、使命和自我解释。
